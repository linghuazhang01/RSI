## 研究问题
RLHF 的奖励模型从人类偏好训练、并在训练中冻结，受限于人类水平且不能随 LLM 一起提升。作者问：能否让同一个语言模型通过 LLM-as-a-Judge 给自己的生成打分、构造偏好数据并迭代 DPO 训练自己，使指令遵循能力和奖励建模能力都在迭代中提升？

## 方法细节
- **模型**：Llama 2 70B 预训练 base（M0）。M1 = 在人工种子数据 IFT（Open Assistant 3200 条高质量首轮对话）+ EFT（1630 条 LLM-as-a-Judge 训练样本）上 SFT。
- **EFT 数据构造**：用 Open Assistant 的人类排序，由 SFT 基线生成评判理由和 1–5 分，只保留分数排序与人类排序一致的样本，并重采样平衡分数分布（p.5）。即种子评判数据依赖人类排序 + 同一模型家族。
- **谁生成训练数据**：
  - **新 prompt**：主实验中由一个**固定的外部模型 Llama 2-Chat 70B** 用 8-shot Self-Instruct 生成（p.3 脚注 1，p.6 第 3.1.3 节），**不是**被训练的模型。附录 A.5 仅做了人工检查：M1–M3 也能通过 in-context 生成新指令（30 个例子），但未用于训练。
  - **候选回答**：被训练的当前模型 M_t 采样 N=4 个回答（T=0.7, p=0.9）。
- **谁当评判/给奖励**：**同一个 M_t**，用图 2 的"加分式 5 分制"LLM-as-a-Judge prompt 给每个回答打分，采样 3 次取平均；取最高分和最低分组成偏好对（同分则丢弃）。
- **被训练的模型**：M_t → M_{t+1}，同一模型序列。生成回答、评判、被训练的是同一 checkpoint（prompt 除外）。
- **谁决定超参/训练方案/写训练代码**：**人类固定**（SFT lr 5.5e-6→1.1e-6 cosine、batch 16、dropout 0.1；DPO lr 1e-6→1e-7、β=0.1）。**early stopping 的 checkpoint 选择用 Claude 2** 在 253 条验证样本上与前一个 checkpoint 做 pairwise 比较（p.6）——即一个外部更强模型参与了训练过程中的 checkpoint 选择决策。
- **更新方式**：M1 为 SFT；M2、M3 为 DPO（Iterative DPO）。文中无 LoRA 字样。【推断】全参数微调（70B）。
- **轮次 / 递归**：共 3 次迭代（M1 SFT，M2、M3 两次 DPO）。AIFT(M1) 3964 对训练 M2，AIFT(M2) 6942 对训练 M3。被训练后的模型在下一轮**同时担任回答生成者和评判者**（自我奖励），但**不担任出题者**（prompt 来自固定的 Llama 2-Chat 70B）。

## 数据集与评测
- 种子：Open Assistant（IFT 3200 条；EFT 1630 训练 / 541 评估）。
- 指令遵循：256 条 IFT 测试 prompt 上 GPT-4 两两对比（两种顺序，不一致算平局）；AlpacaEval 2.0（805 prompt，相对 GPT-4 Turbo 的胜率，GPT-4 评审）；MT-Bench（GPT-4 打 10 分制）；作者盲评人类评估（50 条）。
- NLP benchmark：ARC-Easy/Challenge、HellaSwag、SIQA、PIQA、GSM8K、MMLU、OBQA、NQ（多选题按对数概率选项；shot 数未写明）。
- 奖励建模：在 541 条 Open Assistant 评估集上与人类排序的 pairwise accuracy、exact match、Spearman、Kendall τ、5 分回答为人类最佳的比例。
- 细粒度分析：用 GPT-4（gpt-4-1106-preview）把 AlpacaEval 指令分为 20 类、复杂度和期望长度。

## 关键实验与数字
- **图 3（p.7）GPT-4 两两对比**：M1 vs SFT 30.5 / 38.7 / 30.9（胜/平/负，基本持平）；M2 vs SFT 49.2 vs 14.5；M3 vs SFT 62.5 vs 9.8；M2 vs M1 55.5 vs 11.7；M3 vs M2 47.7 vs 12.5。
- **表 1（p.8）AlpacaEval 2.0 胜率**：M1 9.94% → M2 15.38% → M3 20.44%；超过 Claude 2（17.19%）、Gemini Pro（16.85%）、GPT-4 0613（15.76%）。
- **图 5（p.9）人类评估**：M3 vs SFT 66.0 vs 18.0；M1 vs SFT 28.0 vs 46.0。
- **表 2 / 表 10（p.9, p.23）MT-Bench**：SFT 6.85，M1 6.78，M2 7.01，M3 7.25；数学/代码/推理只从 3.83 升到 4.17。
- **表 3 / 表 9（p.9, p.23）NLP benchmark**：大体持平或下降，如 ARC-Challenge M1 57.51 → M3 53.13；GSM8K M1 60.27 → M3 57.70；NQ 35.48 → 31.86。作者称为"alignment tax"。
- **表 4（p.10）奖励建模能力**：pairwise acc SFT 65.1% → M1 78.7% → M2 80.4% → M3 81.7%；Spearman 0.253 → 0.279 → 0.331 → 0.349；但 5-best % M2 44.3 → M3 43.2 小幅下降，exact match M2=M3=14.3。即评判能力提升幅度逐轮变小。
- **长度增加（p.8）**：AlpacaEval 上生成平均长度 M1 1092 → M2 1552 → M3 2552，作者承认可能影响相对胜率。
- **附录 A.3（p.18–20，图 8）**：不用 EFT 种子数据时，模型常常不能按格式打分、分数趋于 4，有效偏好对极少（541、429 对），增益明显更小。
- **附录 A.4（p.22）**：只把自评 5 分样本加入 SFT（11254 条）无改进（29% vs 30%），偏好对才有效。
- **表 5（p.18）**：不同评判 prompt 差异巨大（多选式 26.6% vs 加分式 65.1% pairwise acc）。
- **饱和/崩塌**：只跑了 3 轮，未观察到崩塌；但奖励建模指标的增量从 M1→M2 到 M2→M3 已变小，NLP benchmark 逐轮下降，作者自己在结论中推测"在现实场景中可能会饱和"。

## 作者自己声明的局限
- 结果是初步的；只在单一设置下跑了 3 轮，需要研究更多轮次与不同能力模型的"scaling laws"（p.12）。
- 生成长度增加，长度与估计质量的相关性需要深入理解。
- 需研究是否会发生 reward hacking 以及在何种情况下。
- 训练奖励和最终评测（GPT-4）都是 LLM，虽然模型不同，仍需更深入分析。
- 缺少安全评估与安全训练（p.12–13）。
- 数学和推理类任务提升有限，归因于 Open Assistant 种子 prompt 中推理任务偏少（p.7、p.10）。

## 方法问题与替代解释
- 【推断】"无外部模型"并不严格：prompt 由外部固定的 Llama 2-Chat 70B 生成；early stopping 由 Claude 2 选 checkpoint；EFT 种子依赖人类排序。这些都是训练环路中的外部信号。
- 【推断】AlpacaEval/MT-Bench 增益与长度显著上升高度相关，GPT-4 评审有长度偏好，一部分增益可能是风格/长度效应；人类评估（作者本人盲评、50 条）规模较小。
- 【推断】奖励建模能力的提升（78.7→81.7）幅度有限，可能主要来自一般指令遵循能力提升而非专门的评判训练（作者自己也如此假设）。
- 【猜测】同一模型既生成又评判，可能产生自我偏好（偏好自己风格的回答），长度增加可能是此偏好的表现。
- 单次运行，无方差。

## 与 core claims（B1–B4）的关系
- **B1**：**部分覆盖**。同一 checkpoint 生成候选回答并给自己打分构造偏好数据（"自己决定哪些数据用于训练"）；但 prompt 由外部固定模型生成；超参、训练方案（DPO 配置）、训练代码全部由人类固定；checkpoint 选择由 Claude 2 决定；不生成适配器权重。
- **B2**：**部分覆盖**。DPO 更新作用于同一模型并提升指令遵循（AlpacaEval、MT-Bench）；但【推断】为全参数微调，**无 LoRA/适配器**；并且标准 NLP benchmark 上有下降。
- **B3**：**部分覆盖**。有 3 轮显式递归：M_t 训练后成为下一轮的回答生成者 + 评判者，作者展示了指令遵循和奖励建模能力共同提升（表 4、图 3）——这是"编辑/评判能力与任务性能共同提升"最直接的先例。但这里的"编辑能力"仅指打分/偏好判断能力，不包括决定训练配置或写训练代码；只有 3 轮，增益已有变小迹象。
- **B4**：**不完全覆盖**。训练奖励来自同一模型，无更大的外部奖励模型；但 (a) prompt 生成用外部 Llama 2-Chat 70B（同规模，非更大，但属于外部模型）；(b) early stopping 用 Claude 2（更强的外部模型）参与训练决策；(c) 评测用 GPT-4。按 B4 的严格定义（无更强外部模型参与决策），(b) 构成违反。
