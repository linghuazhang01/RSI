## 研究问题
无标签 RL 方法仍需要已有的问题集；自挑战方法多依赖代码执行器来保证任务可行可验证。作者问：在没有任何外部任务和标签、也没有执行器 oracle 的数学/通用推理领域，模型能否从零自生成课程并自我进化？

## 方法细节
- **模型**：Qwen3-4B-Base、Qwen3-8B-Base、OctoThinker-3B、OctoThinker-8B（OctoThinker 基于 Llama-3.1 继续训练）；迭代分析还用了 Qwen3-0.6B-Base、Qwen3-1.7B-Base（图 3）。均为预训练 base 模型。
- **两个角色、两个独立模型**：Challenger Q_θ 与 Solver S_φ **都从同一个 base 模型初始化**，但**分开优化**（p.2、p.3）。因此第一轮之后，出题者和解题者是**两个不同的 checkpoint**。附录 D 的 Single-R-Zero 消融（共享参数、单一模型兼任两角色）表现更差（表 6）。
- **谁出题**：Challenger（经 GRPO 训练）。奖励 = max(0, 不确定性奖励 − 重复惩罚)。不确定性奖励 = 1 − 2|p̂ − 1/2|，其中 p̂ 为冻结 Solver 的 m=10 次采样对多数投票答案的一致率；重复惩罚基于批内 BLEU 距离的层次聚类，簇越大惩罚越大（p.3–4，附录 B.4）；格式不符直接奖励 0。
- **谁给标签 / 当评判**：Solver 自身的多数投票产生伪标签；只保留 10 个回答中 3–7 个与多数一致的问题（δ=0.25）（p.4）。Solver 训练奖励为是否匹配伪标签的二值奖励。无外部验证器，无代码执行器。
- **谁决定超参/训练方案/写训练代码**：**全部由人类固定**（附录 B.1：Solver lr 1e-6、batch 128、KL 1e-2、15 步/迭代、5 rollouts；Challenger lr 1e-6、5 步/迭代、4 rollouts；N=8000 候选问题等）。模型不参与。
- **更新方式**：两个角色都用 GRPO；基于 EasyR1 代码库，BF16。文中无 LoRA 字样。【推断】全参数 RL 更新。
- **轮次 / 递归**：每次迭代 = 先训练 Challenger（对冻结 Solver）→ 用 Challenger 生成 8000 题并过滤 → 训练 Solver（对冻结 Challenger）。主结果为 **3 次迭代**（Solver 共 45 步）；迭代分析到 4 次（Step 60）。下一轮 Challenger 以更新后的 Solver 为奖励依据，Solver 也在新 Challenger 的题上训练——两个模型交替共进化。注意：被训练后的 Solver **不**担任下一轮出题者（出题者是另一个 checkpoint）；Solver 的多数投票则担任下一轮的"评判/标签源"。
- **外部更大模型**：训练环路中**没有**。但 **GPT-4o 被用作 benchmark 评测的答案判定器**（附录 B.3、C：数学 benchmark 用 GPT-4o 语义比对答案），并在分析中作为 oracle 给自生成题打真值（表 5）；表 7 的伪标签准确率由 Gemini 标注。这些都在训练环路之外。

## 数据集与评测
- 训练：0 外部数据（自生成数学题；附录 H 有去掉"数学"限定的变体）。协同实验用 math12k（hiyouga/math12k）作人类标注数据。
- 数学：AMC、Minerva、MATH-500、GSM8K、OlympiadBench、AIME-2024、AIME-2025。AMC/AIME 报告 mean@32，其余 greedy 准确率；答案由 GPT-4o 判定。
- 通用推理：MMLU-Pro、SuperGPQA、BBEH（沿用 General-Reasoner 设定，greedy，EM）。
- 表格结果为 Solver 训练 45 步后的结果；图中每 15 步评测一次。

## 关键实验与数字
- **表 1（p.5）数学**：Qwen3-4B-Base 平均 42.57 → R-Zero 49.93（+7.36；摘要称 +6.49）；Qwen3-8B 48.64 → 53.72；OctoThinker-3B 26.64 → 29.32；OctoThinker-8B 36.41 → 38.52。与 Absolute Zero 对比：4B 上 46.42 vs 49.93，8B 上 52.68 vs 53.72。"未训练 Challenger"基线（R-Zero(challenger)）4B 为 45.01。
- **表 2（p.6）通用**：Qwen3-4B 26.34 → 31.15；8B 31.98 → 34.50；OctoThinker-3B 7.47 → 11.12（Absolute Zero 在此为 16.03，更高）；OctoThinker-8B 11.70 → 23.00。
- **表 3（p.6）消融（4B）**：完整 49.07/31.15；去掉重复惩罚 45.76/28.73；去掉过滤 47.35/26.69。
- **图 3（p.7）迭代缩放——明确崩塌**：0.6B 在第 1 次迭代（Step 15，27.39）达峰后下降；1.7B 在 Step 30（39.20）达峰；4B 在 Step 45（49.07）达峰、Step 60 降至 46.52。作者结论：模型越大崩塌越晚，但都无法避免。
- **图 4 / 表 4（p.8）协同监督数据**：R-Zero 作为 mid-training 后再用标注数据 GRPO，4B 比只用标注数据高 +2.35，8B 高 +3.69；混合训练优于单独任一，但不如先 R-Zero 再监督。
- **表 5（p.8）题目难度与伪标签质量**：以 GPT-4o 为真值，第 1/2/3 轮自生成题的伪标签准确率 79% → 69% → 63%；固定的 Step-15 Solver 在三轮题上的准确率 59 → 53 → 47，说明题目变难。
- **表 6（p.17）共享参数消融**：两模型 R-Zero 峰值 49.12（Step 45），伪标签准确率 71.0 → 56.2 → 48.8 → 42.2；Single-R-Zero 峰值 47.31（Step 15）后立即下降到 43.89，伪标签准确率 63.4 → 46.6 → 32.6 → 33.8。作者推测同源出题/解题导致"内部偏差带来的过度自信"。
- **表 7（p.17）**：崩塌开始时并无统一的伪标签准确率阈值（0.6B 在 70.6% 时就开始下降，4B 可以容忍 48.8%）；作者认为除标签噪声外还有自合成数据导致的 model collapse（多样性丧失、偏差放大）。
- **表 8（p.20）去掉数学限定**：8B 上通用 benchmark 略升（如 SuperGPQA 32.29 vs 31.38）。
- **内部数字不一致**：表 1 中 4B R-Zero 平均为 49.93，而表 3、图 3、表 6 为 49.07/49.12；正文称 8B 基线 49.18→54.69，而表 1 为 48.64→53.72；表 8 中 Qwen3-4B MMLU-Pro 基线 37.38 与表 2 的 50.58 不同。复核时需留意。

## 作者自己声明的局限
- 核心机制依赖可客观验证正确性的领域；创意写作、对话、偏好类开放任务难以应用（p.9–10）。
- 当前的标签/验证策略未必能推广到所有任务类型。
- 迭代若干轮后性能崩塌（第 4.2 节、附录 E），是框架固有的不稳定性。
- 伪标签准确率随难度上升而系统性下降，是潜在瓶颈（第 4.4 节）。

## 方法问题与替代解释
- 【推断】每轮 Solver 只训练 15 步、Challenger 5 步，总计 45 步 GRPO；相当大的增益可能来自 RL 对 Qwen3 base 已有推理格式的"激活"（R-Zero(challenger) 基线用未训练 Challenger 已拿到约 +2.4 点）。
- 【推断】评测用 GPT-4o 判断答案正确性，对不同方法一致适用，但引入了外部模型评测偏差（不影响训练环路）。
- 【推断】表间数字不一致，削弱了精确增益的可信度；"+6.49"等摘要数字与表格不完全对应。
- 【猜测】重复惩罚只基于表层 BLEU，可能无法阻止语义层面的同质化，这或许与后期崩塌（多样性丧失）有关。
- 单次运行，无方差/种子报告。

## 与 core claims（B1–B4）的关系
- **B1**：**部分覆盖，且不是"同一 checkpoint"**。训练数据（题目+伪标签）完全由模型自身体系生成（Challenger 出题、Solver 多数投票给标签），但出题者与被训练者是同一 base 初始化的**两个分开优化的模型**；作者的共享参数消融（Single-R-Zero）表现更差。超参、训练配置、训练代码均由人类固定；不生成适配器权重。
- **B2**：**部分覆盖**。更新作用于 Solver 并提升下游数学/通用推理；但为 GRPO 全参数更新（【推断】），**无 LoRA/适配器**。
- **B3**：**部分覆盖**。有离散多轮递归（3–4 轮），Challenger 与 Solver 共进化、题目难度逐轮上升；但被训练的 Solver 不成为下一轮出题者（只成为下一轮标签源/奖励来源）；"编辑能力"仅指出题能力，不含决定训练方案。并且给出了明确的**崩塌**证据：0.6B 第 1 轮、1.7B 第 2 轮、4B 第 3 轮后达峰下降（图 3）。
- **B4**：**训练环路内覆盖**。无更大外部模型参与数据生成、训练决策或训练奖励；无代码执行器。但评测阶段用 GPT-4o 判答案、分析阶段用 GPT-4o/Gemini 作 oracle——不属于训练环路。
