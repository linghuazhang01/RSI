## 研究问题
在图像复原扩散 UNet（去模糊、超分、去噪、修复）上，LLM 能否不用梯度、不用配对数据、不做微调，直接改权重来提升复原质量；以及这种做法是否需要超级智能。

## 方法细节（全部是设想）
- **编辑者**：泛指的“frontier LLM / GPT-6-class LLM”（第 5 节 p.5），没有指定具体模型。伪代码里只有 llm.complete(prompt) 返回 JSON（Listing 2，p.6）。
- **被编辑者**：复原扩散 UNet 的权重，包括输出层 1×1 卷积的 bias、decoder 的高频滤波器范数、skip-connection 的缩放、转置卷积权重（第 4.2 节，表 1 p.3–4）。编辑总量上限是参数的 0.1%。**编辑者（LLM）与被编辑者（UNet）是两个完全不同的模型，不涉及 LoRA 或 adapter**（第 9.2 节只是把 WSP 和 LoRA/FT 做了定性对比）。
- **编辑方式**：LLM 输出 JSON 格式的 {layer, slice, delta}，由 sandbox 写入权重（Listing 1，p.5–6）。按设想，LLM 看到的是分块（每次 5–10 层）的压缩统计量：权重直方图（均值、方差、稀疏度）、top-k 大值、反馈集上的激活幅度（第 4.1 节，第 6.1 节）。
- **诊断信息**：上面这些层统计量，加上在反馈集（32–64 对图像）上的 PSNR/LPIPS。forward 预算在文中前后不一致：摘要和第 4.1 节写 200 次，第 6.1 节写 30–50 次。
- **验收**：在反馈集上 PSNR 提升至少 0.1 dB 且“没有新伪影”才接受；最终在留出测试集上评估（第 6.1 节）。
- **递归**：猜想 C3（他们自己的编号，不是我们的 C3）是“诊断 → 编辑 → 评估 → 再诊断”的多轮循环，每一轮都从上一轮改好的 UNet 出发（第 4.3 节，Listing 2）。**改进的是被编辑的 UNet，LLM 编辑者本身不变，被编辑模型也不担任编辑者**。作者把这个循环称为“最小 RSI”，同时承认它不是自主的自我改进系统（第 9.1 节）。
- **对照**：没有。只做了 WSP、LoRA、全量 FT 的定性对比表（表 3，p.7）。

## 数据集与评测、模型规模
- 没有真实实验。设想的基准：注入集中型缺陷（色偏、棋盘格伪影、边缘光晕）作为正例，自然的分布式缺陷（过度平滑、幻觉纹理、域差异）作为负例（第 9.3 节）。设想有一组 20 个存在质量缺陷的模型（第 4.1 节的可证伪条件）。模型规模只提到约 100M 参数的 UNet 放不进上下文（第 8 节）。

## 关键数字（全部是猜想，不是结果）
- C1：30 次 forward 内把问题定位到不超过 5 层（第 4.1 节，p.3）。
- C2：PSNR 提升至少 0.2 dB，编辑参数少于 0.1%（第 4.2 节；表 2 写 +0.2 到 0.5 dB，p.4）。
- C3：5–10 轮后到达平台，总提升 +0.5 到 1.5 dB（第 4.3 节，p.4，第 198 行）。
- 每个猜想都给了可证伪条件（第 4.1–4.3 节）。

## 作者自己声明的局限
- 规模：UNet 放不进上下文，只能看压缩统计（第 8 节）。
- 分布式缺陷没法靠稀疏编辑修好。
- 通道置换对称让权重解释有歧义。
- 编辑可能在分布外数据上产生副作用。
- LLM 可能偏向编辑后面的层。
- 精确回归任务的反馈有噪声：PSNR 差值小，扩散采样随机，像素指标和感知不一致，去噪链在不同步数上效果不同（第 7 节）。

## 方法问题与替代解释
- 【推断】没有任何实证，所有数字都是作者的假设，作为新颖性证据只能算“想法已被公开提出”，不能算“已经做出来”。
- 【推断】文中前后矛盾：forward 预算一处写 200，一处写 20–50 或 30–50。
- 【推断】Listing 1 每次提出编辑都会消耗预算并用反馈集评估，又以反馈集提升 ≥0.1 dB 作为接受条件，在 32–64 对图像上有明显的选择性过拟合风险，作者只在“OOD side effects”里一笔带过。
- 【猜测】由一个 LLM 共同署名、没有实验，提示这可能是快速生成的立场稿，学术分量有限。

## 与 core claims 的关系
- **C1（同一 checkpoint 自编辑其 LoRA）**：**未覆盖**。LLM 编辑另一个视觉模型（UNet）的基座权重，不是自编辑，也没有 adapter。
- **C2（同评测预算下胜过 no-edit、merge 规则、非 LLM 搜索）**：**未覆盖**。没有实验，也没有基线。
- **C3（被编辑模型担任下一轮编辑者，测 E_t）**：**未覆盖**。确实提出了“多轮诊断—编辑”的递归循环，并把它称为最小 RSI，但改进对象是被编辑模型，编辑者固定，也没有测量编辑者技能是否随代际提升；而且只是设想。
- **C4（持续多任务、adapter 空间遗忘控制、不用更强的外部模型）**：**未覆盖**。单任务（复原质量），没有持续学习和遗忘控制，依赖外部 frontier LLM。
- 总体：这是一篇概念性立场文章，和 B' 的交集只在“LLM 在权重空间做多轮诊断式编辑、由外部指标验收”这一层面，而且没有实验。可以作为 related work 引用，但它构不成 C1–C4 的先例。
