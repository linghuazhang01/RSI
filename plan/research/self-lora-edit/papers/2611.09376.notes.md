## 研究问题
把 Takehi et al. 的 weight-space programming 搬到机器人基础策略：一个通用 LLM 能否通过阅读权重、用 CPU Python 工作区和有预算的模拟器反馈，**不用梯度、不用新示范**，直接改权重来修复机器人策略的失败；同时考察编辑者是否会拒绝自己检查不通过的编辑。

## 方法细节
- **编辑者 LLM**：GPT-6 Astra（闭源前沿模型）（p1 摘要、p2）。
- **被编辑模型**：
  - 主实验：openpi 发布的 π0.5（pi05_libero，3.62B 参数：SigLIP 视觉 + PaliGemma 式 VLM 前缀 + flow-matching 动作专家）（p3 §3.1）。成功的编辑只改 **token embedding 表的行**（C 方案 65 行，132,768 个标量，占 0.00367%）（p4 §3.3）。
  - 其他：FastWAM（改文本条件 MLP 与 Q/K 参数，308 个张量，附录 B），以及 π0.5 上的 LIBERO-PRO（缩小 5 行 SigLIP 位置嵌入）、LIBERO-RECOVER 等。
  - **编辑者与被编辑者完全不同模型**（GPT-6 Astra vs π0.5/FastWAM），不是同一 checkpoint，不是自编辑。无 LoRA/adapter，直接替换原模型张量中的值。
- **编辑方式**：编辑者在持久 CPU Python 内核中读张量、做静态线性代数、写替换张量；禁止梯度、训练循环、迭代损失拟合、在内核中执行目标网络（p2 §2）。π0.5 C 方案的公式为把源 token 行向任务锚 token（或其质心）插值：E'_i = (1−α_i)E_i + α_i·mean(E_T)，α∈[0.5,1.0]（p4 式 1，全部 65 行见附录 F Table S9）。FastWAM 首个方案是"编译"一个上下文检测门（SVD 正交投影方向 + 复用低能量 MLP 神经元 + 重分配 Q/K 坐标）（附录 B，算法 1）。
- **诊断信息**：张量名/形状、原始权重读权限、tokenizer、独立的 forward 工具（跑模拟器 episode、回放已存输入做动作/激活探针），每个会话 40–50 次 forward 请求；一次 Python 执行上限 900s / 96GB（p2、附录 D）。练习/held-out 变体按 SHA-256 哈希奇偶划分；held-out 结果不返回编辑者（p2）。
- **多轮/递归**：每个会话内部是多步智能体式迭代（读→探针→改→验证→保留/回退）。π0.5 三个语言会话彼此独立、不继承笔记。FastWAM 三个后续会话继承首会话笔记与候选（p2、附录 D）。**被编辑后的模型从不成为编辑者**（编辑者是 GPT-6 Astra，被编辑者是机器人策略），无递归自改进。
- **基线比较**：
  - 随机方向、同范数编辑同样 65 行：85.2%（7/15，p=0.134），不提升（Table 3，p4）。
  - "完全替换到编辑者发现的目标"（editor-informed 字典控制）：90.5%，与编辑者 C 的直接比较 20 胜 9 负，p=0.0614，不显著（Table 3、p4 §3.4）。
  - **未与梯度训练（如 LoRA 微调）、人工构造词典、提示改写比较**——作者明确承认（p8 §7）。未与非 LLM 搜索（进化/随机搜索系数等）在同预算下比较。

## 数据集与评测、模型规模
- LIBERO 及 LIBERO-Plus（Language Instructions 等 7 类扰动）、LIBERO-PRO、LIBERO-RECOVER，全部模拟。
- 主评测：765 个 held-out 语言改写变体（全部 held-out 语言 split），外加 360 个其他六类扰动的样本；seed 7；配对比较，报告 (g−l)/n、配对正态区间、精确 McNemar 检验，三个主要效应做 Holm 校正（p2）。
- 规模：被编辑模型 3.62B（π0.5）；FastWAM 视频专家宽 3072、动作专家宽 1024、各 30 层（附录 B.1）。

## 关键实验与数字
- Table 1（p3）：三个独立会话 A/B/C 在 765 held-out 上都提升：86.3→89.4（18 行，32/8，p=1.82e-4）、→88.0（20 行，18/5，p=0.0106）、→92.0（65 行，48/4，p=1.31e-10）（第 170 行）。
- Table 2（p4）：局部性。C 在含被编辑 token 的 335 条指令上 74.3→87.5，其余 430 条 0/0 无任何结果变化；A、B 同样 untouched 部分 0/0。
- Figure 3（p5）：增益集中在难度等级 5（描述替换名称）：59.8→78.2%；等级 5 占 22.7% 样本却贡献 C 净修复的 72.7%（p3）。
- Table 3（p4）：控制实验（随机方向 85.2%、完全替换 90.5%、编辑者 92.0%）（第 211、213 行）。
- Table 4 / S2（p5、p12）：B 的回放因果检验，仅改范数 ρ≈1.004，仅改方向 ρ=0.340，最终 B ρ=0.367，说明方向而非范数承载效应。
- Table 5（p5）：B 的练习验证按种子，seed 23 显著提升（14/0），seed 73 净减 2（2/4），即不是对所有种子都稳健。
- Table 6（p7）：16 个会话总表。语言 3 个全部保留且显著；其余 13 个中 12 个拒绝/回退，唯一保留的 FastWAM follow-up C 不显著（48.0→48.7，p=0.542）。两个被拒绝的存档候选反而有名义正效应（FastWAM 首个 suffix +3.6pp p=0.00187；PRO A 58.5→60.0 p=0.0448）。
- Table S1（p11）：更早的 200 episode held-out 样本上三方案都不显著（C 181→185，p=0.289）。
- §2.1 / 附录 E（p3、p15）：复现 Takehi 的 Qwen3.5-0.8B MATH-500 编辑，单采样 49.4%（原报告 48.1%）；100 题子集原始 9/100、编辑后 57/100。
- §5 / Figure 5（p6、p8）：独立发现——LIBERO-Plus 指令中的场景元数据使 FastWAM 成功率 70.0%→48.6%，π0.5 两种格式都是 88.6%。
- §4（p6）：RECOVER 中操纵相关量（夹爪重开比例 5%→15%）不等于修复（练习 213→208 成功）。

## 作者自己声明的局限（§7 p8，附录 D）
- 编辑效果窄：只修词汇层面的指令落地，一个词在某任务是有用同义词、在别处可能歧义（4 个回归即此类）。
- 编辑者告知的字典替换控制已能解释大部分增益；未证明优于人工独立构建的词典、提示改写或 LoRA 等梯度微调。
- 障碍/能力区分只是假设而非已证明的边界；视觉扰动、恢复、任务变化在测试预算下无保留且被独立确认的修复，不代表不存在合适编辑。
- 全部在模拟中、两个发布 checkpoint；三个主会话共享 held-out 集合与种子，独立性只在搜索层面；闭环渲染微小差异会造成个别不一致。
- 编辑者消耗观测、激活和模拟器结果，并非广义"无数据"；只报告请求次数，无完整 API 成本。
- 12/13 拒绝率不是失败分类器的准确率。

## 方法问题与替代解释
- 【推断】核心成功是"把同义词 embedding 行插值到已知锚词"，这是一个低维、可解释、近似查表的操作；字典控制已解释大部分增益，LLM 的独特贡献主要在"发现词典"，而这一发现成本未与其它发现手段（如人工、自动同义词库、embedding 近邻搜索）对比。
- 【推断】未与同预算的非 LLM 搜索（如在 embedding 行上做随机/进化搜索、或基于练习集的简单梯度/最小二乘）比较，所以"LLM 理解"是否必要无法判定；随机方向控制只有一个实现，不是多种子平均（作者承认，p4）。
- 【推断】200 样本初评不显著而 765 全集显著，虽候选未改动，但评估规模是在看到弱结果后扩大的，存在一定程度的分析自由度（作者已披露）。
- 【猜测】成功集中在 embedding 行这类"语义上直接可读"的参数，说明 LLM 权重编辑在"参数与符号一一对应"处最可行；对分布式、无符号锚点的参数（如视觉、动作专家）基本失败，这对编辑 LoRA 低秩矩阵的可行性是一个警示。

## 与 core claims 的关系
- **C1（同一 checkpoint 自编辑自己训练的 LoRA，代码、免训练）**：部分相关但不覆盖。有"LLM 读诊断信息→写代码→在权重空间免训练编辑"这一形式，但编辑者 GPT-6 Astra 是外部模型，被编辑的是另一个机器人策略的原始权重（embedding 行/MLP/QK），不是自身、不是 LoRA adapter，也没有先梯度训练再事后编辑的流程。
- **C2（同评估预算胜过 no-edit / TIES/DARE/task arithmetic / 非 LLM 搜索）**：部分。胜过 no-edit（显著）与随机方向同范数控制（单次）；但与编辑者告知的完全替换控制差异不显著；无模型合并规则基线、无非 LLM 搜索、无梯度/LoRA 基线（作者明确承认未测）。
- **C3（递归，被编辑模型成为下一轮编辑者，测编辑技能 E_t 跨代变化）**：不覆盖。编辑者固定为 GPT-6 Astra；FastWAM follow-up 只是继承笔记的同一编辑者继续搜索。
- **C4（持续多任务、遗忘控制、无更强外部模型、固定外部评估）**：部分。有固定外部 held-out 评估、保留/回退决策、"untouched 指令 0 变化"的局部性可视为一种遗忘控制；但不是持续多任务学习、无 adapter 栈，且恰恰使用了更强的外部闭源 LLM。
- **对"LLM 能否有意义地编辑权重"可行性的证据**：**正面但范围很窄**。正面：前沿 LLM 在工具 + 小前向预算下能在 3.62B 模型中找到稀疏、局部、可复现（3/3 会话）的权重编辑，显著优于随机方向。负面/限定：成功仅在词汇 embedding 这种符号锚定的参数；其它 13 个会话基本无可确认收益；大部分增益可由简单词典替换解释；无与梯度微调的比较。对 B' 的启示：LLM 编辑应与"非 LLM 搜索/简单规则"在同预算下对照，否则难以证明 LLM 的增益来自理解；"拒绝不受支持的编辑"+外部验证的接受机制与 B' 的 dev/dev2 接受门有相似之处。
