## 研究问题
现有合并方法把一个**任务 LoRA**（指令格式）和一个**领域 LoRA**（领域知识）当作对等的两方，所有层用同样的权重。作者用探针做诊断，发现越深的层领域 adapter 越占主导，浅层保留更多任务信号。由此提出一个免训练的合并算法，按层、按投影类型给出非对称的权重，并在 SVD 分量层面过滤两者冲突的方向。

## 方法细节
- **被合并的对象**：两个 rank-16 的 LoRA（q/k/v/o_proj），共享同一个基座。输出仍是一个标准 rank-r LoRA（p3、p5）。
- **诊断信号（校准探针）**：准备领域探针 P_d 和通用探针 P_g，各 32 条输入。通过冻结的基座取出各层的平均隐状态 h，计算 r_ℓ = ‖ΔW_D h‖ / ‖ΔW_T h‖，再用 s_ℓ = r_ℓ(P_d) / r_ℓ(P_g) 做校准。命题 1 证明 s_ℓ 对任一 adapter 的标量缩放不变（p4）。
- **操作 1：逐层、逐模块门控**：α = σ(β(τ_m − s_ℓ))，β = 5。τ_m 对 q、k 取 1.0，v 取 1.2，o 取 1.5，目的是让 o_proj 保持偏向任务以保住答案格式（p5）。
- **操作 2：SVD 分量过滤**：分别对 ΔW_T 和 ΔW_D 做 SVD。overlap_i 是 U 侧和 V 侧余弦的加权最大值（λ = 0.5）。overlap < δ = 0.10 的分量保留，其余丢弃；按作者统计，大约丢掉 2.5% 的分量（p5、p8）。
- **操作 3：逐分量加权求和后截断回 rank r**（式 7–8）。
- **谁做决策**：固定的手工规则，超参是人工设定加小范围扫描（表 2，p7）。没有 LLM，也没有学习器。
- **预算与成本**：两次探针前向加 SVD，在 A100 上对 7B 模型合并一次约 31 分钟（表 8，p13）。**不做任何候选搜索或迭代评估。**
- **所需数据**：两组探针各 32 条，均为无标签输入。超参扫描所用的评估集，文中没有说明是 dev 还是 test。

## 数据集、评测与模型规模
- 语言：Llama-2-7b。任务 LoRA 在 Alpaca-cleaned 上训练；领域 LoRA 先在 PubMed 摘要上做 CLM，再在 PubMedQA 上做 SFT（p6）。评测集为 MedMCQA、MedQA、SciQ、ARC-C、MMLU-CS、MMLU-Sci，每个 500 条，MMLU-CS 全集只有 100 条、MMLU-Sci 只有 144 条。采用 3-shot、受限解码到选项 token，报告 top-1（p6–7）。
- 视觉：ViT-L/16。任务 LoRA 在 ImageNet-1k 的 50K 子集上训练，领域 LoRA 在 PathMNIST 上训练。评测集为 PathMNIST、DermaMNIST、EuroSAT、ImageNet、CIFAR-100、DTD（p6–7）。
- 基线：Base、Task only、Domain only，以及 Linear、TIES、DARE-Linear、DARE-TIES、Task Arithmetic、Magnitude Pruning、SVD Merge。所有合并基线固定用 0.5/0.5 权重，TIES/DARE 的 density 在 {0.3, 0.5, 0.7} 中网格搜索，DARE 跑 3 个种子（p7）。

## 关键实验与数字
- **表 3（p9）语言**：TaDA 平均 0.452，DARE-TIES 0.416，TIES 0.408，Linear 0.408，Task Arithmetic 0.379，Task only 0.404，Base 0.391。六个基准全部第一，例如 MMLU-CS 0.380，DARE-TIES 0.310、Base 0.350。
- **表 4（p10）视觉**：TaDA 平均 85.9，DARE-TIES 85.6，TIES 85.2，TA 83.6，SVD Merge 85.0，Task only 84.3。只在 3/6 个基准上第一。
- **图 2（p11）**：逐层 α 热图。Llama 上大部分层偏向领域，浅层更平衡。s_ℓ 均值 1.31、标准差 0.97（p11）。
- **表 5（p12）探针规模**：mean std(α) 在 N=8 时为 0.096，N=32 时为 0.026，N=64 时为 0.021。
- **表 6（p12）用错探针**：拿 Wikipedia 当领域探针时 α 全部塌缩到 0.5，退化为简单平均。
- **表 7（p13）消融（视觉）**：去掉探针门控（α=0.5）得 84.7；固定 α=0.7 得 84.9；固定 α=0.3 得 84.8；去掉模块 τ 得 85.5；去掉过滤得 85.4；随机过滤得 85.5；完整版 85.9。也就是说，探针门控贡献约 1.2pp，SVD 过滤只有 0.4–0.5pp。
- **表 8（p13）**：总耗时约 31 分钟，推理零开销。

## 作者自己声明的局限（p14）
- 需要用户提供领域探针输入。
- 7B 模型合并一次约 31 分钟。
- 只测了两对 task/domain adapter（各一种模态）。
- 未来工作：合并多于两个 adapter，以及推广到其他 PEFT 形式。

## 方法问题与替代解释
- 【推断】文中没有独立的 dev 集。表 2 的超参扫描、正文提到的"早期 TaDA 原型"在 MedQA 上的迭代（p8），看起来都是在报告用的评测集上完成的，存在 test 调参的嫌疑。
- 【推断】基线一律固定 0.5/0.5 权重，没有给它们做系数搜索；而 TaDA 本身就是一种逐层的系数设定。"按层设权重胜过不搜系数的基线"这种比较并不公平。一个按层搜索系数的基线（例如 LoRAHub 式或 CMA-ES）缺席。
- 【推断】表 7 中完整版 TaDA 的 CIFAR 是 84.4，表 4 中是 84.8；两表平均值都写 85.9，存在内部不一致。
- 【推断】语言评测样本量小（MMLU-CS 只有 100 条），+3pp 大约就是 3 道题，又没有置信区间。表 3 中 TaDA 的数字也只有一次运行。
- 【猜测】门控主要在决定"深层多给领域、o_proj 多给任务"。一个简单的按深度线性插值的手工规则，可能就能拿到大部分收益，但文中没有这条对照。
- 【推断】各层 overlap 最大值只有 0.162，说明两个 LoRA 的子空间几乎正交，所以 SVD 过滤只丢掉约 2.5% 的分量，作用自然有限。

## 与 core claims 的关系
- **C1**：**未覆盖。** 决策由固定的手工算法做出，诊断（逐层激活范数比、SVD 分量重叠）和编辑（逐层/逐模块缩放、SVD 分量丢弃、rank 截断）都写死在算法里，不是模型自己调用工具、写代码。不过，它使用的诊断和操作，与 B' 中 LLM 可调用的工具和算子高度重合，可以看作"人类专家写的诊断加编辑规则"。
- **C2**：可以作为"人类合并规则"一类的强基线：它比 TIES/DARE 更新、更有针对性，而且已经是逐层、非对称的方案。它本身不做搜索，评估预算接近零。
- **C3**：**未覆盖。** 没有递归，没有代际，也没有编辑者能力的测量。
- **C4**：**部分相关但未覆盖。** 把"新 adapter 与旧 adapter 合并，并保住旧能力"可以类比为任务 adapter 与领域 adapter 合并（Task only 一类基准相当于在测旧能力保留）。但它没有持续多轮设定，没有遗忘曲线，也没有用正交化来减少遗忘。
- **作为 C2 基线如何复现**：
  1. 把旧 adapter（或 adapter 栈之和）当作"任务/旧能力"一侧，把新训练的 raw LoRA 当作"领域/新任务"一侧。
  2. P_d 取新任务训练集中 32 条输入，P_g 取通用文本 32 条（可以用 Wikipedia）。
  3. 按式 1–8 实现：β=5；τ_m 对 q/k/v/o 取 1.0/1.2/1.5；δ=0.10；λ=0.5；最后截断回 rank r。如果 adapter 还覆盖 MLP 层，需要自己补 τ（文中没有给出），并在论文中说明。
  4. 没有官方代码，需要自行实现，并在 dev 上检查是否复现出"深层偏领域"的模式。它只需 1 次候选评估，可以作为零搜索成本的点基线；也可以再加一个"在 dev 上扫 τ/β"的版本，评估次数与 LLM 编辑者对齐。
