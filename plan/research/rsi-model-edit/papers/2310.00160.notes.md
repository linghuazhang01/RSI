# 2310.00160 Self-Specialization 阅读笔记

## 元信息
- 标题：Self-Specialization: Uncovering Latent Expertise within Large Language Models
- 作者：Junmo Kang, Hongyin Luo, Yada Zhu, Jacob Hansen, James Glass, David Cox, Alan Ritter, Rogerio Feris, Leonid Karlinsky（Georgia Tech / MIT / MIT-IBM Watson AI Lab）
- 日期/版本：arXiv v2，2024-06-05（发表于 Findings of ACL 2024）
- 阅读范围：全文 26 页（p.1–26），正文、Limitations、附录 A–C、Table 5–14 全部读完。抽取文本：`src_2310.00160/2310.00160.pages.md`

## 研究问题
通用的 self-alignment（Self-Instruct、Dromedary 这类：模型从少量人工种子出发，自己生成指令数据来对齐自己）在专业领域（生物医学、金融）提升很小。论文问的是：能不能把 self-alignment 从“通用指令跟随”改成“领域专精”，用很少的领域种子，从基座模型里“挖出”潜在的领域能力，得到一个轻量的领域专家模块。

## 方法细节
- **模型**：都是预训练基座，没有做过指令微调。主实验在生物医学上用 MPT-30B；金融用 LLaMA-2 7B；另外还验证了 Falcon-40B、LLaMA-2 7B（生物医学），附录用 Gemma-7B 做了 MMLU。
- **流程**（Fig.2，p.3；§3，p.2–4）：
  1. 种子：人工挑的领域种子 (instruction, context, response)，生物医学 80 条（从 BoX 的 32 个任务里每个最多取 5 条），金融 90 条（从 10 个基准训练集里取）。这些种子在推理时也被用作 ICL 示例（p.4）。
  2. 指令生成：基座 M_base 用 Self-Instruct 风格的 prompt（领域化改写版，Table 10，p.22），以 3 条随机种子作为上下文示例，生成新的 (instruction, input) 对；采样参数 top-p 0.98、temperature 1.0（p.16–17）。
  3. 回答生成：还是同一个 M_base，用“你是生物医学专家”的 prompt 生成回答。可选地接 BM25 检索 PubMed（约 3000 万篇摘要），对 top-k 文档做边缘化：p(y|x)=∏_i Σ_j p_ret(d_j|x)·p_lm(y_i|x,d_j,y_<i)（p.4）。
  4. 触发专精：拿自己生成的数据（默认 5K 条）对 M_base 做 QLoRA（4-bit，rank 8，alpha 16，挂在所有模块，lr 3e-4，3 个 epoch，batch 32），单张 A100 训几个小时，可训练参数约占 0.28%（p.5–6，p.17）。
  5. 可选的迭代：用训练好的 M_aligned 重新生成指令和回答，然后再训练（§3.5，p.4）。
- **谁生成、谁修改谁的权重**：数据由同一个基座 LLM 自己生成，训练的也是它自己的 LoRA。但“训练”这一步由外部固定流水线完成：标准 QLoRA 微调，超参由人设定。LLM 只负责产出文本数据，不决定 LoRA 的配置、超参、训练代码，也不决定要不要训练或者训到什么程度。
- **人工输入**：领域选择（生物医学/金融/体育）由人定；80/90 条种子由人从现有标注数据集里挑；prompt 模板是人写的；超参是人定的；检索语料（PubMed）也是人选的。数据不做自动过滤（p.9）。
- **修改对象**：QLoRA 适配器（ΔW）；基座权重冻结，并做 4-bit 量化。
- **推理效率/压缩**：4-bit 量化只是 QLoRA 训练时用来省显存的标准手段，不是研究目标，也不是由模型自己决定的。论文没有任何关于推理加速、剪枝或压缩的研究。
- **多轮递归**：有一个可选的迭代版本。第 1 轮训好的模型会当作下一轮的数据生成者（Table 4 报告的是“w/ Iterative Process”，看起来就是 2 轮）。但作者在 p.7 明确说，再往后的迭代基本看不到有意义的提升。

## 关键实验与数字
- Table 1（p.2）：LLaMA-65B 在生物医学 10 个数据集上 5-shot 平均 F1 为 43.87；Alpaca-65B 46.39（+2.52），Dromedary-65B 45.10（+1.23）。动机是通用对齐对领域帮助有限。
- Table 2（p.5）：生物医学（MPT-30B）平均 F1：0-shot 25.15→36.63，1-shot 26.65→42.29，5-shot 30.18→48.41。金融（LLaMA-2 7B）：0-shot 19.34→33.87，1-shot 31.05→37.82，5-shot 33.14→46.00。ConvFinQA 下降（例如 0-shot 15.74→5.25）。
- 正文 p.5 脚注：去掉 BioASQ-Yesno 这个离群点后，5-shot 是 32.55→43.21（附录 C.3，p.19 还给了 0/1-shot 的数字）。
- Fig.3（p.6）：自专精的 MPT-30B（5-shot 平均 48.41）超过 LLaMA-65B（43.87）、Alpaca-65B（46.39）、Dromedary-65B（45.10），也超过 MPT-30B-Instruct。
- Table 3（p.7）：检索消融，0-shot 平均 F1：top-5 文档 34.57，top-1 文档 29.65，不检索 33.72，基座 25.15。
- Table 4（p.7）：迭代消融，0-shot 平均 F1：加迭代 36.63，单轮自专精 34.57，基座 25.15。作者称后续迭代“很少有意义的提升”（p.7）。
- Fig.4（p.7）：LLaMA-2 7B 自专精后与 MedLLaMA-13B、PMC-LLaMA-13B 相当或更好（p=0.006 / 0.01，k=5）；用自专精数据再训 MedLLaMA 还能提升（p=0.001）。
- Fig.5（p.7）：数据量从 0 加到 10K，约 5K 时进入平台期。
- Table 7（p.18）：与全监督 SOTA（14 万条以上标注）相比，平均 52.19 对 63.23，NER 差距很大。
- Table 9（p.19）：Gemma-7B 自专精后 MMLU 64.0（100 条标注、5K 合成），Humpback-65B 是 59.0。
- 污染检查：8-gram 重叠阈值 70%，没有发现显著重叠，并人工抽查了 200 条（p.9）。

## 作者自己声明的局限（p.9，附录 C）
- ICL 敏感：示例变多时，有时性能反而下降（作者认为这是 ICL 的固有问题）。
- 训练时不用示例，生成时先同时生成指令和输入、再生成回答，这些策略的替代方案未探索。
- 没做自动过滤；人工过滤也没带来明显提升。
- 有数据污染和偏差传播的风险。
- 与全监督 SOTA 仍有差距，NER 尤其明显（附录 C.4）。
- 迭代很快饱和（p.7）。
- 体育等其他领域只做了定性的案例研究（附录 C.1）。

## 方法问题与替代解释
- 【推断】BioASQ-Yesno 从 8.80 涨到 95.20，主要贡献可能来自格式和指令跟随能力（基座输出常常不在标签空间内），而不是领域知识。作者自己在 C.3 承认基座在这个数据集上低于随机水平。所以平均分的提升有一部分是“学会按格式回答”。
- 【推断】种子来自评测基准的训练集，而且在推理时还被当作 ICL 示例，于是种子与测试分布高度对齐。Fig.5 显示前 100 条（主要就是种子）带来最大的跳升，这说明种子本身的作用很大。
- 【猜测】迭代只在 2 轮内有效，可能是因为自生成数据很快多样性坍缩，或者错误在自举中被放大。论文没有做分析。
- 【推断】所有结果都是单次运行（p.17），只有 LLaMA-2 7B 的部分实验报告了方差。

## 与每个 core claim 的关系
- **C1（模型自己决定并执行对自身权重的压缩，目标是推理效率）**：没有覆盖。论文没有剪枝、量化或推理效率方面的目标；QLoRA 的 4-bit 是人设定的训练省显存手段，模型不参与决定。
- **C2（模型自己为下游任务产出 LoRA 并应用到自己身上）**：部分覆盖，而且是最接近的先例之一。同一个 LLM 自己生成训练数据（指令、输入、回答），再用这些数据训练出自己的 LoRA 并挂回自己身上。但 LoRA 的超参、训练代码、何时训练、种子和目标领域都由人或固定流水线决定；模型不生成超参、不写训练代码，也不直接生成权重。所以它覆盖的是“自产数据→自训 LoRA”这条路线，不覆盖“模型自主决定适配策略和配置”。
- **C3（递归：被编辑后的模型成为下一轮的编辑者，编辑能力与模型共同提升）**：弱覆盖。有可选的迭代，训练后的模型成为下一轮的数据生成者，但实际只做了大约 2 轮，作者说再迭代基本无益。论文也没有衡量“编辑能力”本身是否提升（只看下游 F1），没有多轮曲线，也没有研究编辑者自身的改进。
- **C4（自我改进作用在权重层面：压缩、adapter、合并）**：部分覆盖。自我改进的落点是 LoRA adapter（权重层面），而不是 prompt 或 harness。但动作空间只有“用自生成数据做 SFT 训练 LoRA”这一种固定操作，没有压缩或合并，也没有让模型在多种权重操作之间做选择。
