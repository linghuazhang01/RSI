## 研究问题
传统后训练是一次性且静态的，多个 LoRA 专家参数多、容易过拟合，组合起来也困难。论文希望让 LLM 在推理时根据输入任务自适应地调整自己的权重，并为此提出一个兼顾组合性和可扩展性的框架。

## 方法细节
- **SVF（Singular Value Fine-tuning）**（§3.2，p.4–5）：对每个权重矩阵做 SVD，W=UΣV^T；只学习一个向量 z∈R^r，W'=U(Σ⊗diag(z))V^T，也就是只缩放奇异值。每个矩阵只需要 r=min(m,n) 个参数。
- **用 RL 训练**（式 1，p.5）：J(θ_z)=E[log π_W'(ŷ|x)·r(ŷ,y)]−λ·KL(π_W'‖π_W)，奖励取 ±1（答对或答错），用 REINFORCE 优化。lr 2e-3，batch 256，从 {0, 0.1, 0.2, 0.3} 中按验证集选 KL 系数 λ（附录 A.1，Table 6，p.15–16）。训练数据是带标准答案的公开数据集：GSM8K、MBPP-pro、ARC-Easy、TextVQA。每个数据集训练出一个“专家向量” z_k。
- **两遍推理自适应**（p.6）：第一遍观察输入并确定 z'，第二遍用 W' 作答。三种策略：
  - A）Prompt：用人写的分类 prompt（Fig.3）让 LLM 自己把问题分到 code/math/reasoning/others 中的一类，再选对应的 z_k（others 用原始权重）。
  - B）分类专家：再用 SVF 训练一个任务分类向量 z^c，第一遍加载 z^c 来分类。
  - C）Few-shot：z'=Σα_k z_k，用 CEM 在 10 条留出的测试样本上搜索 α，最多 100 代，平局时取平均对数似然最高者；每个任务只搜一次（附录 A.4，p.15）。
- **模型**：LLaMA3-8B-Instruct、Mistral-7B-Instruct-v0.3、LLaMA3-70B-Instruct（都是指令模型）；VLM 用 LLaMA3-LLaVA-NeXT-8B。对 70B 和 VLM 只在一半的层上做 SVF。
- **谁生成、谁修改谁的权重**：专家向量由外部 RL 训练流水线在人选定的带标签数据集上得到，不是模型自己产出数据或决定训练。推理时“自适应”的意思是：模型自己在第一遍里分类（A/B），或者由外部 CEM 搜索器决定混合系数（C），然后把选出或混合出的 z 应用到自己的权重上。所以“self”指的是在推理时根据输入调制自身权重，而不是由模型撰写修改方案。
- **人工输入**：训练任务和数据集（GSM8K/MBPP/ARC-Easy/TextVQA）由人选；类别体系和分类 prompt 由人写；超参和 KL 系数通过扫描确定；CEM 的超参由人设定；few-shot 的 10 条样本来自目标任务的测试集并带标签（用来打分）。
- **修改对象**：每个权重矩阵奇异值上的缩放向量 z。U、V 冻结，属于满秩的乘性调制。
- **推理效率/压缩**：SVF 不压缩模型，W' 和原矩阵同尺寸，没有降秩、剪枝或量化。效率只体现在可训练参数少（例如 0.58M 对 LoRA 的 6.82M–35.13M），以及对两遍推理开销的讨论：Table 3 给出第一遍时间占第二遍的 13%–47%；附录 D 讨论了 CEM 的一次性开销。附录 C 的 PCA 用来说明 top-r 截断会丢信息，这是反对截断低秩的论据，与压缩方向相反。
- **多轮递归**：没有。专家向量训练一次之后固定；自适应发生在每个任务或每个样本的推理时，不会产生新专家，也不会让模型改进自己的编辑能力。作者在 p.8 推测框架可以支持“终身/持续提升”，但没有做实验。

## 关键实验与数字
- Table 1（p.7）：SVF 微调。LLaMA3-8B：GSM8K 75.89→79.15（LoRA 77.18）；MBPP-Pro 64.65→66.67（LoRA 67.68）；ARC-Easy 88.59→89.56。Mistral-7B：GSM8K 42.83→49.74（LoRA 44.66）。LLaMA3-70B：GSM8K 85.29→88.32，而 LoRA 降到 77.26。
- Fig.5（p.7–8）：VLM 上用 SVF 后 TextVQA 提升超过 39%（正文 p.8 的说法）。
- Table 2（p.8）：在未见任务上的自适应。LLaMA3-8B：MATH 24.54→25.47（Few-shot），HumanEval 60.98→62.99，ARC-Challenge 80.63→82.61；LoRA 在 HumanEval 上掉到 52.44。Mistral-7B：Few-shot 后 HumanEval 43.29→47.40，ARC-C 71.76→75.47；Prompt 策略在 MATH 上下降（13.02→11.86）。LLaMA3-70B Prompt：MATH 40.64→40.44，HumanEval 78.66→79.88。
- Table 3（p.8）：两遍推理的时间（Prompt 策略）：MATH 第一遍 42.64s，第二遍 321.19s（13%）；ARC-Challenge 13.40s 对 28.51s（47%）。
- Table 4（p.10）：消融（LLaMA3-8B，GSM8K/MATH）。SVF 用策略梯度、作用于 MLP+attention，0.58M 参数，79.23/25.04；SVF 用 next-token 预测 60.50/18.52；LoRA 用策略梯度（6.82M）57.92/15.72（训练崩溃，见 Fig.9）；LoRA 用 next-token 预测 77.18/24.12。
- Table 5（p.11）：把 LLaMA 的 SVF 向量迁移到 Mistral。保持奇异值顺序时 HumanEval 45.12，打乱顺序后 40.24；跨模型 few-shot 自适应后 ARC-C 达到 75.64。
- Table 8（p.16）：ARC-C 上的 few-shot 规模。3-shot 82.18，10-shot 82.61，20-shot 82.61，优于 IA3。
- Fig.6（p.9）：分类混淆矩阵，对角线大多在 0.95 以上；LLaMA3-8B 的 Prompt 策略把 ARC-C 判对的比例只有 0.77。

## 作者自己声明的局限（p.10–11，§5；p.6；附录 D）
- SVF 专家的能力受限于基座模型已有的潜在成分（只能放大或缩小已有的奇异方向）；作者建议用模型合并来缓解。
- 领域数目扩大后，CEM 的一次性开销会增加；如果任务里的 prompt 很少，CEM 的开销就显得较大（附录 D，p.19）。
- 基座太弱时，RL 的奖励会很稀疏（p.6）。
- 跨模型迁移可能依赖两个模型的架构相似，不同规模之间能否迁移还是开放问题（p.10）。
- 70B 只在一半的层上做了 SVF（GPU 受限，p.8）。

## 方法问题与替代解释
- 【推断】在未见任务上的提升幅度很小（大多在 1–4%），而且 few-shot CEM 用目标任务带标签的 10 条测试样本做搜索，并在多种配置（逐层/逐向量、是否归一化）中按最终结果挑最好的一个来报告（附录 A.4 明确说因为没有验证集，报告的是最佳样本）。这存在选择偏差的风险。
- 【推断】LoRA 基线用的是 SFT（next-token），而 SVF 用的是 RL，目标函数不同；Table 4 有部分控制。70B 上 LoRA 掉得很厉害（GSM8K 85→77），可能是基线调参不充分。
- 【推断】“自适应”的大部分工作其实由人定义的类别体系和外部 CEM 完成；A/B 两种策略中模型做的只是分类决策。
- 【猜测】SVF 只缩放已有的奇异值，接近对已有能力的重新加权，因此对真正新的知识可能无效。作者也承认了这一点。

## 与每个 core claim 的关系
- **C1（模型自己压缩自身权重以提升推理效率）**：没有覆盖。SVF 是满秩的奇异值缩放，不降秩、不剪枝、不量化；论文讨论的效率是训练参数量和两遍推理的开销，不是压缩。不过，“在 SVD 空间里对自身权重做调制”这个技术手段，和基于 SVD 的压缩（截断奇异值）在操作层面相邻。【推断】
- **C2（模型自己产出 LoRA 并应用到自己身上）**：弱覆盖。适配器（z 向量）由外部 RL 流水线在人选的带标签数据集上训练，模型没有生成训练数据、超参或代码。推理时模型在第一遍里自己选择或混合已有专家并应用到自身权重上，这算“自选适配器、自应用”，不算“自产适配器”。CEM 混合系数也是外部搜索器给出的。
- **C3（递归：编辑后的模型成为下一轮编辑者）**：没有覆盖。专家集合是固定的，自适应只在单次推理内发生；调制后的模型不会去产出新专家或改进分类/编辑能力，也没有多轮实验。
- **C4（权重层面的动作空间：压缩、adapter、合并）**：部分覆盖。自适应的动作确实作用在权重上：选择或线性插值 SVF 向量，相当于在奇异值空间里做一种轻量的“合并”。但动作空间限定为在预训练好的 K 个专家向量上做选择或插值，没有压缩，也没有新建 adapter，并且由人定义的类别和外部 CEM 驱动。
