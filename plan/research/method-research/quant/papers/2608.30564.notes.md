# 2608.30564 Q-Strata（MoE 双层比特分配：块内代理 + 块间模型级目标）阅读笔记

## 1. 元信息
- 标题：Q-Strata: Hierarchical Bit Allocation for Mixed-Precision Quantization of Mixture-of-Experts LLMs
- 作者：Deokjae Lee, Sihun Chu, Hyun Oh Song（通讯）
- 机构：Seoul National University（CSE、IPAI）、Neural Processing Research Center
- 版本：arXiv:2608.30564v1，2026-08-31；会议未标注（版式为 ACL 系列）。代码：github.com/snu-mllab/Q-Strata（p.1）。
- 读的页范围：p.1–p.15 全文（正文 p.1–9，局限 p.10，参考文献 p.10–11，附录 A–E p.11–15）。

## 2. 做的是什么决策
- **对象**：MoE 中每个专家的三条 FFN 线性层（up/gate/down）各选一个量化器；共 N = 3LE 个分配单元（p.3）。注意力投影、路由门、embedding/LM head、DeepSeek 第 0 层稠密 MLP 固定 16-bit（Table 7，p.12）。
- **量化器集合 Q**：GPTQ，group-128 非对称，1/2/3/4 bit（有效位宽含 scale/zero 开销，1-bit=1.25、2-bit=2.25 等）（p.6, p.12）。所有方法在 Hadamard 旋转后量化（主表）。
- **预算**：专家权重平均位宽 τ（主表 2.25 / 2.00 / 1.75；Table 2 另有 2.75）。
- **粒度分层**：块内决定“哪个线性层用哪个比特”（inner），块间只决定“每个 MoE 块分多少预算 β_l”（outer）。
- 稠密模型扩展（§4.5、App.E）：Llama-2-7B，逐线性层，HQQ 2/3/4 bit g128。

## 3. 驱动决策的信息
- **块内代理（inner）**：块输出重建误差的可加近似（p.3）
  D_l(x_l) = Σ_{e,i} ‖ĥ_l^(e,i)(x_{l,e,i}) − h_l‖²，ĥ^(e,i)(q) 表示**只量化该线性层、块内其余保持全精度**时的块输出。即“孤立逐层测量 + 求和”。代价：每 (层, 量化器) 一次单块前向，复用一次全精度前向缓存的块输入。只在路由到该专家的 token 上非零，所以常用专家权重更大。
- **模型级目标（outer）**：校准集上量化模型与全精度模型下一 token 分布的 Jensen–Shannon 散度（JSD），MoE 实验用 top-1000 logits 近似（p.3, p.12）。全精度分布预先算好，每次评估 L = 组装后量化模型一次端到端前向。
- **数据**：WikiText-2 train，序列长 4096；inner 64 条序列，outer 32 条，最终 GPTQ 128 条（p.12）。稠密实验 2K / 8K token（p.15）。
- **成本**：
  - outer lazy greedy 全程扫一遍（覆盖所有预算）：Mixtral 1,909 次 L 评估、Qwen1.5-MoE 1,552、DeepSeek-V2-Lite 1,667；对应 eager 需 22,327 / 13,537 / 15,802；每步提交平均 R≈2.5–2.7 次评估（Table 6，p.12）。
  - GPU 时间（H100，覆盖所有预算的一次搜索）：Mixtral 23.0 h（Stage1 2.5 + Stage2 20.5）、Qwen1.5-MoE 23.5、DeepSeek-V2-Lite 35.5、Qwen3-30B-A3B 88.7（Table 14，p.15）。成本与校准集大小线性相关。最终 GPTQ 一次 <0.5 h。
  - 稠密 Llama-2-7B（Table 5）：One-shot ILP 449 次查询、lazy greedy 1,378、AMQ 10,474、eager greedy 70,345。

## 4. 决策过程
- **Inner**（Algorithm 1，p.4）：对每个块、预算网格 B 上每个 β（1.25 到 4.25，步长 0.125，K=25 级），解 MCKP（Gurobi ILP）得到块内最优分配 x*_l(β)，缓存成 Pareto 前沿 S_l。
- **Outer**（Algorithm 2，p.4–5）：从所有块最高预算出发，每步把“降一级后 L 增加最少”的块降一级，直到平均预算达到 τ（MoE 中每块参数相同，所以每步节省预算相同；稠密时改用 ΔL/(w_iΔ) 的 budgeted greedy，App.E）。用 Minoux 惰性评估 + 最小堆，只在缓存值过期时重算。一次自顶向下扫描得到所有预算的分配。
- **理论**：若 −L 在预算格上满足 DR-submodular，惰性 = 贪心精确（Remark 3.2）。论文不保证 L 满足，仅用 Fig.2 经验检验。

## 5. 关键结果
- **Table 1（p.6）**，Wiki2 PPL / 6 项零样本平均精度（PIQA、BoolQ、WinoGrande、ARC-e/c、HellaSwag）：
  - 2.25 bit：Mixtral Q-Strata 5.62 / 71.78 vs MxMoE 5.69 / 71.70；Qwen1.5-MoE 7.98 / 62.93 vs 8.07 / 61.93；DSv2-Lite 6.74 / 63.75 vs 6.78 / 64.04（MxMoE 精度略高 0.3）。BF16 分别为 3.88 / 6.79 / 5.92。
  - 2.00 bit：Mixtral 6.90 vs MxMoE 8.03；Qwen 8.97 vs 9.06；DSv2 7.41 vs 7.46。
  - 1.75 bit：Mixtral 12.14 vs 25.20（精度 52.51 vs 44.58）；Qwen 11.84 vs 12.49；DSv2 9.35 vs 9.90。
  - GEMQ（共享协议、无路由微调）普遍最差，如 Mixtral 2.25 bit 9.39。
  - MxMoE = Q-Strata 去掉 outer（每块均匀预算），所以 GPTQ→MxMoE 是 inner 收益，MxMoE→Q-Strata 是 outer（块间模型级）收益；后者**随预算收紧而变大**（p.7）。
- **Table 4（p.8）**：恢复 GEMQ 路由微调（RFT），有/无旋转共 18 对，Q-Strata 全胜。
- **Table 9（p.13）** 2.0 bit 下 MMLU / GSM8K（5-shot）：Mixtral Q-Strata 42.7 / 3.7 vs MxMoE 38.2 / 0.8 vs 均匀 GPTQ 24.8 / 0.1（BF16 70.3 / 63.5）；Qwen 41.6 / 6.0 vs 34.4 / 4.1；DSv2 41.5 / 8.1 vs 35.8 / 8.4。【推断】绝对能力损失仍巨大（GSM8K 几乎归零），2-bit 区间只是“相对更好”。
- **Table 13（p.15）** Qwen3-30B-A3B：2.25 bit 8.56 vs MxMoE 8.73；1.75 bit 10.23 vs 10.48。
- **Table 15（p.15）**：GemLite kernel，H100 batch=1，同预算下 Q-Strata 与 GEMQ 解码速度差 ≈1%；模型 5.2–6.3× 压缩、解码约 1.46× 加速。
- **稠密 Llama-2-7B（Table 5，p.8；Fig.3，p.9）**：lazy greedy JSD 在 3.5/3.0/2.5 bit 为 0.0228/0.0549/0.1569，略优于 AMQ（0.0229/0.0550/0.1572），查询数 1,378 vs 10,474；eager 0.0224/0.0539/0.1568（70,345 次）。8K token 下用 6.9× 更少查询匹配或超过 AMQ。

## 6. 隔离各信号价值的消融
- **代理 vs 真实指标相关性（Table 8，p.13，最关键）**：DeepSeek-V2-Lite，32 个随机、同为 2.0 bit 的逐专家比特分配，各自 GPTQ 后测 Wiki2 test PPL：
  - 校准集 JSD（模型级、组合评估）与 test PPL 的 Spearman ρ = **0.98（无旋转）/ 0.99（有旋转）**；
  - GEMQ 的梯度加权**可加代理** ρ = **0.42 / 0.28**。
  这是三篇中最直接的“可加孤立代理排序能力差、模型级组合评估几乎完美”的证据。
- **Outer 阶段消融（Table 2，p.7，Mixtral，inner 固定）**，JSD / PPL：
  - 2.75 bit：Uniform（=MxMoE）121.2 / 4.72；**One-shot ILP**（每块单独降级、其余块保持最高预算测得的边际之和 = 可加代理）108.2 / 4.64；Ascending lazy greedy 243.9 / 5.62；Q-Strata 107.2 / 4.61。
  - 2.25 bit：234.3 / 5.69；231.6 / 5.64；733.6 / 13.22；229.6 / 5.62。
  - 1.75 bit：1036.5 / 25.20；823.4 / 13.72；1195.9 / 32.76；749.4 / 12.14。
  - 解读：**可加的 One-shot ILP 在 2.25–2.75 bit 几乎追平组合贪心（JSD 差 <1%，PPL 差 0.02–0.03），只在 1.75 bit 落后明显（JSD 差 74，PPL 13.72 vs 12.14）**。“自底向上”的 ascending greedy 甚至差于均匀。
- **Inner 剪枝是否丢解（Table 3，p.7，DSv2-Lite）**：无 inner 阶段、对每个 (专家, 线性层, 比特) 单元从顶配单独测 ΔJSD 再全局 ILP（约 15.4k 次端到端评估，>8× Q-Strata 全搜索）：2.25 bit 109.6 / 6.74；2.00 184.4 / 7.41；1.75 410.6 / 10.03。块级 One-shot ILP：112.5 / 6.75；190.9 / 7.44；419.2 / 9.92。Q-Strata：111.9 / 6.74；190.0 / 7.41；364.0 / 9.35。
  - 解读：(i) inner 代理剪枝几乎不损失（与无剪枝 cell-ILP 差 ≤4% JSD）；(ii) 即使是逐单元**孤立测量的模型级 ΔJSD**（比 Hessian 代理贵得多、更"真实"），可加组合在 ≥2.0 bit 也与组合贪心持平，1.75 bit 才落后（410.6 vs 364.0）。
- **稠密 Llama-2-7B 可加 vs 组合（Table 5）**：One-shot ILP JSD 0.0233 / 0.0587 / 0.1984 vs lazy greedy 0.0228 / 0.0549 / 0.1569（3.5 / 3.0 / 2.5 bit）。【推断】相对差约 2% / 7% / 26%，**非可加性在 3.5 bit 几乎可忽略，在 2.5 bit 显著**。
- **校准子集稳定性（Table 11，p.14）**：三种随机种子，Qwen1.5-MoE PPL 差 ≤0.08。
- **路由分布代表性（Table 10）**：校准-测试路由 TV 距离 0.009–0.032，比到均匀分布近 3–5 倍。
- **旋转（Table 12, D.5）**：1-bit 时旋转效果因模型而异（Mixtral 152.5→2024.4 变差，Qwen 124495→64229 变好）；1.75–2.0 bit 时搜索结果把 25–59% 专家线性层放到 1 bit。

## 7. 关于可加性/交互的证据
- 核心论断：块内用孤立逐层代理排序可靠，块间存在耦合，只有模型级目标能反映（p.2–3）。
- **直接证据**：
  1. Table 8：可加梯度代理 ρ=0.42/0.28 vs 模型级 JSD ρ=0.98/0.99（同预算随机分配，2.0 bit）。
  2. Table 2 / Table 3 / Table 5：基于“其余部分保持高精度时测得的孤立边际”的可加 ILP 与组合贪心的差距随预算收紧而放大：≥2.25 bit（MoE）或 3.5 bit（稠密）时差距 ≤2%，1.75 bit（MoE）或 2.5 bit（稠密）时差 10–26%。
  3. Fig.2（p.5，App.A）：DSv2-Lite 上沿随机下降路径，某块降一级的边际损失随整体压缩加深**近单调增大**（超可加 / DR-submodular 方向）。这正是孤立测量（在高精度上下文中测）会**低估**低预算下真实边际的机制。
- 【推断】综合来看：在本文的设定中，非可加性主要表现为“越压越脆”的单调放大，而非复杂的符号翻转交互；因此**按当前上下文重新测边际**（greedy 每步重测）就足以捕获，不需要 pairwise 矩阵。
- 注意：这些对比中“可加”基线用的仍是**模型级 JSD 的孤立测量**（不是 Hessian/权重统计），可加性在 ≥2.25 bit 也基本够用；真正差的是梯度类可加代理（Table 8）。

## 8. 作者声明的局限
- outer 每步需一次组装模型前向，评估数多于“拟合一次可加代理再闭式求解”的方法；虽可摊销且随块数 L 而非 3LE 增长，但搜索时比纯代理分配更重（p.10）。
- L 不保证 DR-submodular，惰性评估是启发式（p.5）。
- 服务栈未针对异构比特优化（p.15）。

## 9. 批判
- 【推断】所有主实验都在 1.75–2.75 bit 极低区间（专家权重），3–4 bit 区间只有稠密 Llama-2-7B 的 3.0/3.5 bit JSD（Table 5），且那里可加 One-shot ILP 与组合贪心仅差 2–7%，没有报告 3–4 bit 下的 PPL/下游差距。**收益在 3–4 bit 是否存在基本未验证**，现有数据暗示很小。
- 【推断】Table 8 的 ρ 比较是“模型级 JSD（在校准集上直接测组合）”对“GEMQ 梯度可加代理”，两者成本差异巨大；没有给出“孤立模型级 JSD 之和”的 ρ，这才是区分“可加性”与“代理质量”的关键对照。Table 3 的 cell-ILP 部分回答了这一点（≥2 bit 时几乎持平）。
- 【推断】只量化专家 FFN、注意力 16-bit，比特分配空间比稠密模型的全模块分配窄；且有效位宽只针对专家权重。
- 【推断】主表的 MoE 方法都在 Hadamard 旋转后量化，而 GEMQ 在无旋转设置——虽然 Table 4 做了补充对比，但主表跨方法比较存在协议差异。
- 【推断】Table 9 中 2.0 bit 的 GSM8K 绝对值（3.7–8.1 vs BF16 16.5–63.5）显示这一区间不可部署，结论的实用意义取决于能否推广到 3–4 bit。
- 评测包含 PPL + 6 项零样本 + MMLU/GSM8K，比 CoopQ 完整；校准子集稳定性和路由代表性检查到位。

## 10. 对本项目（27B 自量化 agent 的工具/诊断设计）的启示
- **最该给 agent 的信号：组合配置的模型级 JSD/KL**（在固定校准集上对“当前整套配置”一次前向），它对最终 PPL 的同预算排序 ρ≈0.98；而梯度可加代理只有 0.28–0.42。对应工具：evaluate_config(config) → 校准集 KL/JSD（便宜的内部评估器，区别于昂贵的外部评测器）。
- **两层结构可直接借鉴**：块/层内用便宜的孤立代理（输出重建误差）缓存 Pareto 前沿，跨层只决定每层预算并用模型级目标贪心降级。27B 稠密模型（约 64 层 × 7 线性层）可类比为“每层一个预算级 + 层内 7 个模块按代理分配”。
- **成本参考**：每次 outer 评估 = 32 条 × 4096 token 的一次前向；全程约 1.5k–1.9k 次评估、23–36 H100 小时（14–47B MoE）。稠密 7B 上 lazy greedy 1,378 次查询即可匹配 AMQ 10k 次。给 agent 的预算可设在“~10³ 次组合评估”量级，并提供“降一级后的 ΔKL”查询。
- **“从高往低降”而不是“从低往高升”**：ascending greedy 比均匀还差（Table 2）。若 agent 迭代修改配置，应从高精度出发逐步降级，并在每步按当前上下文重测边际。
- **何时需要交互诊断**：在 ≥3.5 bit（稠密）/≥2.25 bit（MoE 专家）时，可加的孤立模型级 ΔKL + 背包几乎等价于组合搜索；仅在极低预算下组合评估才显著更好。若本项目平均预算 ~3–4 bit，profile(module,bits)→ΔKL 的孤立工具 + 背包基本足够，组合评估作为最终校验/微调。
- **惰性重算**：利用“边际随压缩单调增”的性质，agent 可缓存旧的 ΔKL 作为下界，只在被选中时重测——工具可返回“该值测量时的上下文/步数”以便 agent 判断是否过期。
