# HAWQ-V2: Hessian Aware trace-Weighted Quantization 阅读笔记（1911.03852）

## 1. 元信息
- 标题：HAWQ-V2: Hessian Aware trace-Weighted Quantization of Neural Networks
- 作者：Zhen Dong, Zhewei Yao, Yaohui Cai*, Daiyaan Arfeen*, Amir Gholami, Michael W. Mahoney, Kurt Keutzer
- 机构：UC Berkeley；北京大学（Yaohui Cai）
- 版本：**arXiv:1911.03852v1，2019-11-10，cs.CV**（p.1）。正式版发表于 NeurIPS 2020（依据 OWQ 参考文献 "NeurIPS, 33: 18518–18529"，见 2306.02272 pages.md p.9）。**本笔记只读了 v1**；NeurIPS 版可能增加了消融实验（例如 trace 与 top eigenvalue 的直接比较），但我没有读到，也无法核实。
- 阅读范围：p.1–p.13 全文（正文 p.1–10，参考文献 p.10–11，附录 A–C p.12–13）。
- 领域：CNN（Inception-V3、ResNet50、SqueezeNext、RetinaNet），量化感知微调（QAT）场景；不是 LLM PTQ。

## 2. 做的是什么决策
- **逐层（block）权重比特分配**：每个 block 的比特取自如 {1,2,4,8}（p.6 例子），在给定模型大小约束下选取。
- **逐层激活比特分配**（§2.2，p.5–6），在 RetinaNet 上验证。
- 决策粒度：layer/block 级。不决策量化器类型（统一线性量化 + 可截断范围，附录 A，p.12）、group 或校准集。
- 选定比特后做**量化感知微调**（STE，附录 A）。最终精度依赖 QAT，而不是 PTQ。

## 3. 驱动决策的信息
### 3.1 信号与公式
- **相对敏感度：平均 Hessian trace** Tr(H_i)/n_i（Lemma 1，Eq.2.5，p.4），H_i 为**任务损失**对第 i 层参数的 Hessian（子采样 mini-batch，p.3）。
- 理论依据（Assumption 1 + Lemma 1，p.3–4）：假设模型在局部极小（梯度为 0、H 半正定），并假设量化（QAT 后）扰动在 Hessian 各特征向量方向上**等幅**分布：ΔW_i* = α_bit Σ_k v_k^i（Eq.2.3）。在此假设下 ΔWᵀHΔW = α² Σλ = (‖ΔW‖²/n)·Tr(H)，因此在扰动范数相同时，平均 trace 更小的层损失增量更小。
- 反驳 top eigenvalue 的玩具例子（p.3）：F1=100x²+y² 与 F2=100x²+99y² 的最大特征值都是 200，但 F2 显然更敏感。
- **绝对排序指标 Ω（Eq.2.11，p.7）**：Ω = Σ_{i=1}^{L} Ω_i = Σ_i Tr(H_i)·‖Q(W_i) − W_i‖²₂，其中文中说明 Tr(H_i) 指"平均 Hessian trace"（即 Tr/n）。Q(W_i)−W_i 为该层在候选比特下的**原始量化扰动**。
- **Hutchinson 迹估计**（Eq.2.6–2.7，p.4–5）：Tr(H) ≈ (1/m) Σ z_iᵀ H z_i，z 服从 Rademacher 或 N(0,1)；只需 Hessian-向量积（matrix-free），无需显式构造 H。
- **激活 Hessian 迹**（§2.2，p.5–6）：H_{a_j} 对不同输入是块对角的（Eq.2.9：不同样本的梯度互不依赖），所以可以逐样本计算 z_iᵀ H_{a_j}(x_i) z_i 再求平均（Eq.2.10），从而解决可变输入尺寸（COCO）与超大维度的问题。

### 3.2 数据与样本数
- Hessian 在**训练集上的 mini-batch**（带标签）上计算（p.3）。
- Figure 5（p.7，ResNet50 block 21）：数据点数超过 **512** 后迹估计收敛；**50 步 Hutchinson** 即足够、方差低。
- 激活迹（Figure 7，p.13）：用 **128 个数据点 × 50 步 Hutchinson**。

### 3.3 成本
- ResNet50 全部 54 个 block 的 Hessian trace：**4 GPU 上 30 分钟（平均每 block 33s）**（p.2、p.7）。
- 每次 Hutchinson 步需要一次 Hessian-向量积【推断：约相当于 2 次反向传播的计算量，需要二阶自动微分（double backprop）的内存】。
- Ω 的计算可以忽略不计：单 CPU 上算 10³ 个候选不到 1 秒（脚注 3，p.7）。
- 主要成本在后续的量化感知微调，论文未给出 QAT 的时长。

## 4. 决策过程
1. 对每层算平均 Hessian trace，排序（p.4–5）。
2. **单调约束剪枝搜索空间**：trace 更高的层比特不得低于 trace 更低的层（附录 B，p.12）。在此约束下，有序层划分成 j 组，属于整数划分问题，|B| = Σ_j C(m,j)·C(L−1, j−1)。ResNet50 用 {1,2,4,8} 时从 4^50 ≈ 1.3×10³⁰ 降到 |B| = 2.3×10⁴（p.6）。
3. **"Pareto frontier" 选取**（§2.3，p.6–7；Figure 4）：对 B 中每个候选算 Ω 与模型大小；给定目标大小，选 Ω 最小的候选。【推断：本质上是在单调约束下穷举 + 预算约束最小化可加代理，不是真正的多目标 Pareto 优化；Figure 4 画的是 Ω–size 散点和下包络】。
4. 用选定配置做 QAT 微调。作者承认这在理论上不保证最优（p.7）。

## 5. 关键结果
- **Inception-V3 / ImageNet（Table 1，p.8）**：Baseline 77.45；Direct（2MP/4MP，无 Hessian）69.76 @5.74MB；HAWQ 75.52 @7.57MB；**HAWQ-V2 75.68 @7.57MB**。
- **ResNet50 / ImageNet（Table 2，p.8）**：Baseline 77.39；HAQ（RL）75.30 @9.22MB；HAWQ 75.48 @7.96MB；**HAWQ-V2 75.76 @7.99MB**。
- **SqueezeNext（Table 3，p.9）**：Baseline 69.38；Direct 65.39 @1.12MB；HAWQ 68.02 @1.09MB；**HAWQ-V2 68.38 @1.07MB**。
- **RetinaNet / COCO（Table 4，p.9）**：Baseline 35.6；Direct 4/4 31.5；FQN 4/4 32.5；HAWQ-V2 w3MP/a4 34.1；w3MP/a4MP 34.4；w3MP/a6 34.8（大小均为 17.90MB；A-Comp 分别为 8.00×/7.62×/5.33×）。
- Figure 2（p.4）、Figure 6（p.12）：不同 block 的平均 trace 相差数个数量级（例如 Inception-V3 block 4 为 8.8e−2，block 16 为 3.6e−4），loss landscape 可视化与之定性一致。

## 6. 隔离各信号价值的消融
- **trace vs top eigenvalue（HAWQ-V1）**：v1 中**没有**"只换敏感度指标、其他保持不变"的受控消融。唯一证据是 HAWQ（top eigenvalue + 手动选比特）与 HAWQ-V2（trace + Ω 自动选）的端到端对比：Inception-V3 +0.16（75.52→75.68，同 7.57MB）；ResNet50 +0.28（75.48→75.76，但 V2 大小 7.99 > 7.96MB）；SqueezeNext +0.36（68.02→68.38，1.09→1.07MB）。指标变化和选择流程变化**混在一起**，没有方差或多种子结果。
- **Ω 代理层面的比较**：Figure 4（p.6）显示在 Inception-V3 上，同样大小下 HAWQ-V2 选出的配置 Ω 比 HAWQ-V1、Direct 都低。但这是用 Ω 评价 Ω 的最小化结果，属于循环论证，不是对指标的验证【推断】。
- **随机/其他排序基线**：v1 中**没有**随机排序、逆序或均匀分配加同一流程的消融。"Direct"（无 Hessian 的 MP 设置）是唯一非 Hessian 基线，但 Table 1 中 Direct 的模型更小（5.74 vs 7.57MB），没有做大小匹配；Table 3 中大致匹配（1.12 vs 1.07MB），差距 65.39 vs 68.38。
- **代理与真实指标的相关性**：未报告 Ω 与最终精度跨配置的相关性。
- **Hutchinson 收敛**：Figure 5、Figure 7 右，作为成本/精度权衡的消融（数据点数、步数）。
- **激活混合精度**：Table 4 中 a4 → a4MP → a6：34.1 → 34.4 → 34.8，说明 Hessian 引导的激活 MP 在略增激活存储的情况下接近 6-bit 的效果。

## 7. 关于可加性/交互的证据
- **隐含可加性假设**：Ω = Σ_i Ω_i（Eq.2.11）把总损失增量写成各层独立二阶项之和，等价于假设**层间 Hessian 交叉块为零**（块对角近似），并忽略高阶项与层间误差传播。
- Lemma 1 只比较**单层**扰动（一次只量化一层），没有处理多层同时量化。
- **论文没有验证可加性**：没有比较 ΣΩ_i 与联合量化后实际损失增量，也没有报告 Ω 排名与最终精度的秩相关。
- 另外，Assumption 1 中的扰动指 QAT **微调后**的扰动 ΔW*，而 Ω 用的是原始舍入扰动 ‖Q(W)−W‖²，两者不一致；作者的理由仅是直觉（"二阶扰动最小的配置应在 QAT 后泛化好"，p.7）。

## 8. 作者声明的局限
- Ω 最小的选择"不能理论保证最优表现"（p.7）。
- 即使 trace 排序也只给相对敏感度，需要 Pareto/Ω 流程才能得到具体比特；|B| 对更深网络（如 ResNet152）仍很大（p.6）。
- 未来工作：训练中引入二阶信息以获得更平坦的极小值；训练数据不可得（隐私）时的扩展（p.10）。

## 9. 批判
- 【推断】Assumption 1（扰动在所有特征方向等幅）非常强，是"trace 优于 top eigenvalue"结论的全部来源。实际量化噪声更接近与参数坐标对齐的近似均匀噪声；在该噪声模型下，期望 E[ΔWᵀHΔW] = σ²·Tr(H) 也成立，所以 trace 有另一种更自然的辩护，但论文没有给出。
- 【推断】top eigenvalue vs trace 的经验优势很小（0.16–0.36 个百分点）且有混杂，在没有多种子的情况下不足以证明 trace 指标本身更好。
- 【推断】"Pareto frontier"在实践中就是"单调约束下穷举 + 最小化可加代理"。单调约束本身可能排除最优解（例如一个 trace 高但参数很少的层，按 Ω 应该给更多比特，单调约束恰好同意；但反过来，trace 略低而参数极多、量化误差大的层可能被不合理地限制）。
- 【推断】Hessian 是在**带标签的训练损失**上算的；对 LLM 可以换成下一 token 交叉熵或与 FP 模型之间的 KL（Fisher）。但对 27B 模型做逐层 50 步 HVP × 512 序列，成本远高于 CNN（需要二阶反向和完整激活存储）。
- 【推断】结果依赖 QAT 微调；PTQ 场景（GPTQ/AWQ 不微调）下 Ω 的可预测性没有被检验。
- 【推断】Table 2 中 HAWQ-V2 的模型比 HAWQ 略大（7.99 vs 7.96MB），并非严格同预算。

## 10. 对本项目（27B 自量化 agent 的工具/诊断设计）的启示
1. **"敏感度 × 量化误差"的可分解代理（Ω_i = s_i·‖ΔW_i‖²）是最经典的逐层分配骨架**：s_i 用平均 Hessian trace（或 Fisher/KL 曲率的对角近似），‖ΔW_i‖² 对每个 (bits, quantizer) 都便宜可算。可以给 agent 提供 `omega(module, bits, quantizer)` 工具作为廉价预筛，再用昂贵的 `profile → ΔKL` 复核。
2. **可加性必须由工具帮 agent 验证，而不是默认成立**：HAWQ-V2 完全没有验证 ΣΩ_i 能否预测联合配置（OWQ 的 Table 13 甚至给出了 K/Q 强交互的反例）。建议提供"组合预测 vs 实测"的校验工具：预测 ΣΔKL_i，再实测组合 ΔKL，返回残差。
3. **trace 估计成本可控但不便宜**：50 步 Hutchinson、约 512 样本即可收敛（CNN 上）。对 27B 模型，可以按模块一次性用同一个 Rademacher 向量并行估计所有层的 trace（一次 HVP 覆盖全模型）【推断】，再缓存为静态诊断，不要放进 agent 的在线循环。
4. **单调约束 + 穷举是非常强的搜索空间剪枝**（4^50 → 2.3×10⁴），适合作为 agent 的"安全默认"或可调用的求解器；但应允许 agent 违反单调约束（例如参数量差异大时）。
5. 激活敏感度可以逐样本块对角地算（Eq.2.10）；对仅权重量化的本项目不直接需要，但同样的逐样本平均技巧可用于以较低内存估计 KL 曲率。
