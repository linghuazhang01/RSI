# HIGGS / Linearity Theorem（arXiv 2411.17525）阅读笔记

## 1. 元信息
- 标题：Pushing the Limits of Large Language Model Quantization via the Linearity Theorem
- 作者：Vladimir Malinovskii†, Andrei Panferov†（共同一作）, Ivan Ilin, Han Guo, Peter Richtárik, Dan Alistarh
- 机构：Yandex / HSE University；ISTA；KAUST GenAI CoE；MIT；NeuralMagic
- 版本：arXiv 2411.17525v1（2024-11-26）。抽取文本中**没有标注会议**（不在此处断言会议）。
- 读的页范围：p.1–p.29 全文（正文 p.1–10，参考文献 p.10–12，附录 A–I p.13–29）。附录 D 的证明读了 D.2 和 D.4 的结论推导。

## 2. 做的是什么决策
- 两个应用（p.1–2）：
  1. **HIGGS**：无需数据的量化格式。先对权重做随机 Hadamard 变换（RHT），再用对高斯分布 MSE 最优的（向量）网格取整。决定的是网格（n 个点，维度 p）和 scale group size g（Algorithm 1–2, p.6）。
  2. **动态 HIGGS**：逐层比特宽度分配。每个线性层从有限的量化器集合 {Q_1..Q_J}（不同比特 / 网格）中选一个，满足平均比特 ≤ b_max（式 5, p.7）。
- 粒度：逐线性层（论文中的 "layer" 即每个权重矩阵）。
- 动态版本的候选限定为 FLUTE 内核支持的网格（p∈{1,2}，b∈{2,3,4}）和 CH8（约束为均匀的 8 bit 网格）（p.6–7；附录 H, p.23）。
- 不决定校准数据（数据无关版本），也不在 GPTQ/AWQ/RTN 之间选择；GPTQ+HIGGS 作为单独扩展出现（Table 2）。

## 3. 驱动决策的信息
### 3.1 线性定理（Theorem 1, p.4–5）
- 定义逐层**相对权重误差** t_l² = E‖Ŵ_l − W_l*‖²_F / ‖W_l*‖²_F（式 3）。
- 结论：当所有 t_l 都足够小时，E[PPL(Ŵ)] ≈ PPL(W*) + Σ_l α_l · t_l²（式 4）。α_l 只依赖于该层的预训练权重（以及 Hessian），**与量化方法无关**（"universal"）。
- 假设：
  - A1：预训练权重是 PPL 的局部极小点（若压缩是无偏的 E[Ŵ]=W*，则不需要 A1）（p.4）。
  - A2：PPL 在 w* 附近三阶连续可导。
  - A3：D*∇²φ D* ≈ Z，其中 D* = diag(‖W_l‖_F I)，Z 是逐层标量 × 单位阵的块对角阵。即**按层范数缩放后的 Hessian 近似块对角，且每块近似各向同性**。正是这一条让跨层交叉项消失、结果可加（附录 D.4，式 17）。
- 推导：二阶 Taylor 展开，一阶项因局部最优而为零，二阶项在 A3 下拆成各层之和，α_l = z_l · M_{2,l}/2（p.16–17）。
- A3 的实验支持：**只在 OPT-125M 上**，对小参数子集（每层 25–768 个参数）求 Hessian，可视化看到对角占优结构（附录 E, Fig.4–5, p.17–21）。没有在 Llama 级模型上验证。

### 3.2 α_l 的计算（Algorithm 3, p.7–8；附录 B.2）
- 不用真实量化器，而是用**高斯噪声注入**：G_l(W,t) = W + t‖W‖_F/√(d_in·d_out)·Σ，Σ 为 i.i.d. N(0,1)，使 t_l² = t² 可以精确控制（式 9–10）。
- 对每层 l、每个噪声水平 t_j（j=1..J）：只扰动第 l 层，测 Δ_{l,j} = PPL(W*(l,t_j)) − PPL(W*)；然后过原点线性回归 Δ ≈ α_l·t_j² 得到 α_l。
- J = 15 个噪声水平，从"线性适用区间"中均匀采样，作者称已足够准确（p.8, 行 521）。
- 数据依赖版本：在 WikiText-2 train 的 287k token 上测 PPL（p.10, 行 658）。
- **数据无关版本**：把 PPL 换成原模型与扰动模型在**随机采样 token** 上的 KL 散度，每次评估使用 287k 个不共享的随机 token（p.8, 行 521–525）。
- 成本：L × J 次整模型前向评估（每次 287k token）。论文没有报告 α 标定的 GPU 时间。【推断】Llama-3.1-8B 有 32 块 × 7 个线性层 = 224 层，即约 3360 次 287k-token 评估；27B 模型同理会是数千次评估，这是主要开销。
- t²_{l,j}（网格失真）：对每层用每个量化器实际量化一次，测相对误差，建立"逐层误差数据库"（p.8）。在 RHT 之后，t_l² 近似只依赖网格（≈ 标准正态到网格的逐元素 MSE），与权重无关（附录 F, p.22）。

## 4. 决策过程
- 式 5：min Σ_l α_l·t²_{l,j_l}，s.t. Σ_l b_{j_l}·d_l ≤ b_max·d。这是一个多选背包问题。论文用 Google OR-Tools 的 CP-SAT 求最优解（p.8, 行 508）；摘要和引言说成"可归约为动态规划/线性规划，LLM 规模秒级求解"（p.2）。
- 即**闭式代理 + 精确组合优化**，没有任何端到端搜索或对组合配置的验证评估。

## 5. 关键结果
- **线性预测 vs 实际（均匀 HIGGS）**：Fig.1（p.2）：Llama-3.1-8B 在 2–8 bit 范围内的预测 PPL 与实测 PPL，竖线标出定理适用的下限。正文说定理在 **3–8 bit** 范围预测效果很好（p.1, 行 56）；§6.1 说 **b > 3.0 时预测接近实测，更低比特处发散**（p.9, 行 576）。所用网格：Pareto 前沿上 1≤p≤5、9≤n≤4096。
- **动态配置的预测 vs 实际**：Fig.3（p.9）：Llama-3.1-8B 的 WikiText-2 PPL 增量随预算 b_max（约 2–6 bit，对数纵轴）变化，虚线为线性模型预测。**只有图，没有数值误差、相关系数或残差表**；抽取文本也看不到曲线数值。
- **均匀 HIGGS vs 无数据格式（Table 3, p.9, Llama-3.1-8B）**，Wiki2 / MMLU：
  - 3.25 bit：NF 7.683/55.82；AF 8.056/53.15；HQQ 7.317/56.39；HIGGS p=4 6.643/59.88；GPTQ 7.133/58.37；**HIGGS 动态数据无关 6.388/61.62**
  - 4.02 bit：NF 6.225/62.65；HIGGS p=3 5.981/62.83；GPTQ 6.238/62.96；HIGGS 动态数据无关（4.00 bit）5.910/63.86
  - 4.25 bit：差距收窄（NF 5.964，HIGGS 动态数据无关 5.831）。
- **动态 HIGGS vs GPTQ/AWQ（Table 4, p.10）**，Wiki2 / MMLU：
  - 3.25：GPTQ 7.133/58.37；动态数据无关 6.388/61.62；动态（Wiki2 标定）6.359/61.37
  - 4.02：GPTQ 6.238/62.96；AWQ 6.228/62.88；动态数据无关（4.00）5.910/63.86；动态 5.870/63.69
  - 4.25：GPTQ 5.923/64.05；AWQ 5.905/63.83；动态数据无关 5.831/64.06；动态 5.802/64.26
- **GPTQ+HIGGS（Table 2, p.8, Llama-2-7B, Wiki2）**：≈2 bit 8.637（QTIP 6.82，AQLM 8.180）；≈3 bit 5.559（GPTQ 5.776）；≈4 bit 5.213（GPTQ 5.254）。
- 其他模型（Tables 7–11, p.25–29）：Llama-3.2-1B/3B、Llama-3.1-8B-Instruct、Llama-3.1-70B、Qwen2.5-7B。动态版本在 3.25 bit 一般最好。
- **反例**：在 70B 上（Table 10），4.00 bit 动态数据无关 Wiki2 3.133，**比均匀 HIGGS p=2（4.02）的 2.986 更差**；4.25 bit 动态数据无关 2.956，也比 p=3 均匀的 2.834 更差；而数据依赖动态版本（2.827 / 2.787）是最好的。8B-Instruct 4.25 bit 动态数据无关 6.783 也比 p=2 均匀 6.736 差。【推断】数据无关的 KL-on-随机 token 标定在大模型或高比特下会失准；另外均匀 p=3 网格不在动态版本的候选集中，比较并不完全对等。
- 70B 上 AF/NF 4.02 bit 崩溃（Wiki2 513.5 / 2084, p.28）；作者说明非动态设置下不量化第 1 块的 v_proj（Table 10 注）。这说明个别模块存在灾难性敏感。
- 内核：FLUTE 在 RTX 4090 上，Llama-3.1-8B batch 1 为 173/150/139 tok/s（2/3/4 bit），FP16 为 57（Table 1, p.8）；Hadamard 开销 ≤4%（Table 6, p.23）。

## 6. 隔离各信号价值的消融
- 动态（WikiText-2 PPL 标定 α）vs 动态数据无关（随机 token KL 标定 α）：8B 上差距很小（Table 4：3.25 bit 6.359 vs 6.388；MMLU 甚至数据无关更高，61.62 vs 61.37）。70B 上差距明显（4.00 bit 2.827 vs 3.133）。即**α 的标定数据来源在小模型上影响不大，在大模型上不可忽略**。
- 网格维度 p 的消融：p 越大误差越小（Fig.2, Table 3）。这验证了"最小化逐层 MSE 即最小化 PPL 增量"这一推论在均匀设置下的方向正确。
- 没有做的消融：α_l 用 Gaussian 噪声标定 vs 用真实量化器标定；线性预测对 GPTQ/AWQ（误差有结构、非各向同性）是否适用；α 与 Fisher/Hessian 迹之类便宜代理的相关性；逐层预测排序与下游任务（MMLU）的相关性。

## 7. 关于可加性/交互的证据
- **支持可加**：理论上来自 A3（缩放 Hessian 近似块对角 + 各层各向同性），推出跨层误差贡献线性可加；附录 C 称实验上把所有层都换成压缩版本时，PPL ≈ PPL* + Σα_l t_l²（式 13, p.14）。Fig.1（均匀）和 Fig.3（动态）给出可视化吻合。
- **适用边界**：定理要求 t_l "足够小"。实证上 b > 3 bit 时吻合，**约 3 bit 以下（2-bit 区间）发散**（p.9）。附录 C 里有一个未写完的脚注"Add some comment on how small it is"（p.14, 行 968），说明"多小算小"在文中**没有被定量给出**。
- 论文明确说该定理与 GPTQ/QuIP 这类数据感知的逐层 ‖WX − ŴX‖ 最小化**没有直接关系**（p.3, 行 144）。即它对"权重空间相对误差"成立，而 GPTQ 把误差推到低激活方向，其 t_l 与 PPL 的关系可能不同。
- 2 bit 下 GPTQ+HIGGS 明显落后 QTIP（8.637 vs 6.82），与"低比特时只控制逐层 MSE 不够"一致。【推断】

## 8. 作者声明的局限
- 尚未在 MoE 等其他架构上验证（p.10）。
- 依赖 Hadamard 变换实现权重非相干化，可能带来运行时开销（作者认为可以最小化或折叠进前一层）（p.10）。
- 定理只在逐层误差足够小（中等比特，约 3–8 bit）时适用，作者在摘要里也把非均匀最优解限定在"medium-bitwidth regime"（p.1）。

## 9. 批判
- A3 只在 OPT-125M 的极小参数子集上通过"看热力图"验证（附录 E），没有定量指标（如非对角质量占比），也没有在 Llama/Qwen 上验证。跨层交互（如残差流上的误差累积）正是 A3 忽略的部分。【推断】
- 线性预测的吻合度只以图展示，**没有给出 R²、平均绝对误差或排序相关**。对用作决策的代理来说，最关心的是"排序是否正确"，文中缺失。
- α_l 用各向同性高斯噪声标定。对 RHT + MSE 网格这类近似各向同性的误差合理，但对 GPTQ/AWQ/RTN（无 RHT）的结构化误差，α_l 是否仍然"与量化器无关"没有验证。【推断】对本项目很关键：本项目的量化器正是 GPTQ/AWQ/RTN。
- 标定成本（L×J 次整模型评估）没有报告；对 27B 模型而言不可忽视。
- 动态方法的候选集受 FLUTE 限制，与均匀 p=3/p=4 的比较不完全对等。
- 在 70B 上数据无关动态版本不如均匀，说明"随机 token KL"作为信号存在模型尺度相关的失效，作者没有讨论。
- 只测 PPL、5 个零样本任务和 MMLU；没有生成、推理、长上下文任务。PPL 改进与任务改进不总是同步（如 Table 3 中 3.25 bit HIGGS p=3 的 MMLU 60.11 高于 p=4 的 59.88，但 PPL 更差）。

## 10. 对本项目（27B 自量化 agent）的启示
- **可以给 agent 的便宜工具**：`profile(module, noise_t) → ΔKL`（高斯噪声注入），对每模块回归得到 α_l；再加 `measure_t2(module, bits, quantizer)`（只需权重，无需前向）。两者组合即可在**秒级**给出任意配置的预测损失 Σ α_l t_l²，并能直接用背包/CP-SAT 求最优。这比 EvoPress 式的纯搜索便宜几个数量级。
- **必须告诉 agent 的适用边界**：预测在 ≥3 bit（4/8 bit 档）区间可信；**涉及 2 bit 模块时线性预测会发散**。此时必须用端到端 KL（EvoPress 式）来验证或修正。
- **量化器差异**：HIGGS 定理以权重空间相对 MSE 为自变量。对 GPTQ/AWQ，建议给 agent 的 t_l 改为"该量化器实测的单模块 ΔKL"（即用真实量化器做 profile），而不是权重 MSE；否则会系统性误估 GPTQ 的收益。【推断】
- **信号来源**：α 用随机 token KL 标定在 8B 上几乎与用 WikiText PPL 等效，但 70B 上明显变差。对 27B，应提供使用真实校准文本（而不是随机 token）的 KL 版本，并允许 agent 检查二者是否一致。
- **混合策略**：线性模型 + 背包 DP 给出初始配置 → 在 2–3 bit 边界附近用少量端到端 KL 评估做局部交换（EvoPress 式）修正。这是两篇论文证据的自然组合。
- **灾难性模块检测**：70B 上第 1 块 v_proj 需要特殊处理，提示应提供"单模块极端敏感"诊断（例如单模块 2-bit ΔKL 远超线性外推），供 agent 强制保留高精度。
