# 2506.11442 ReVeal: Self-Evolving Code Agents via Reliable Self-Verification（ICLR 2026）

- 读的范围：正文 p1–10 全读；附录 C（memory）、Table 7–8（LCB V5 与显著性）读；其余附录略读。源：`src_2506.11442/2506.11442.pages.md`。
- **改进对象**：权重（多轮 RL，TAPO = turn-aware PPO，Verl）。同一模型在每轮生成代码、再自己写测试并调用执行工具验证，然后修改（p3–5）。
- **信号来源**：结果奖励 + 跨轮通过率提升奖励（用 ground-truth 测试）+ 验证奖励（自生成测试在**golden 解**上能通过的比例，式 3 p5）。训练时自生成测试要先通过 golden 解才会用来跑候选代码（p4）；**测试时完全自主，不用 golden**。所以训练信号依赖人工解与测试，"自演化"体现在测试时多轮自验证。
- **训练数据**：**TACO（26,443 题，LeetCode/Codeforces 等来源）**，过滤掉交互/图片题与 golden 解跑不过测试的题后，**11,151 题训练、509 题测试**（p5–6）。
- **每轮怎么用**：RL 训练时最多 3 个生成-验证轮次；基座 DAPO-Qwen-32B（数学 RL 过的模型）（p6）。
- **评测**：**LiveCodeBench V6（2025.02–2025.05）**与 CodeContests（p6）；附录另报 **LCB V5**（Table 7–8，含 mean±std 显著性）。测试时扩到 8/25 轮。**没有 HE/MBPP**。
- **是否不相交**：TACO 训练题截至较早（TACO 2023 发布），LCB V6 为 2025 年新题，按时间不相交；CodeContests 与 TACO 均含 Codeforces 题，**论文未讨论 TACO 与 CodeContests 的重叠**【推断：存在潜在重叠风险】。
- **关键数字（Table 1 p7）**：LCB V6：DAPO-Qwen-32B 31.1 → 单轮 RL 32.8 → ReVeal×25 38.7；CodeContests 18.5 → 21.0 → 33.6。ReVeal 的 ∆↓（对→错）为 0.0。
