## 改进对象
- trainer agent（Claude Sonnet 4.6）改**训练配方 + 训练侧诊断 harness**（奖励、过滤、数据选择、rollout 设置、优化器选择），产出 4B/9B 策略模型的 GRPO 训练版本（p4–5 §3.2–3.6）。改的是**另一个模型的权重**，trainer 自身不变。humans 负责搭建工作区、批准训练任务启动与版本晋升（Table 2 p5）。
- 4B/9B 策略模型的具体型号：抽取文本里没写（只在 p6 提到 Qwen3.5-4B 作数学判分器）。not stated。

## 不相交程度
- 训练数据：T（swe-rebench train → test split；TACO → LCB-v6，跨 benchmark，作者称 OOD）。
- **但版本取舍（keep/prune/merge）依据 "validation" 分数**，而附录给出的 validation 数值与 Table 3 报告的测试数值完全一致：SWE-9B v4 36.30、v8 38.16（p14 D.1）；Coding v9→v10 Avg@8 50.21→51.29（Table 8 p14），Table 3 Coding 最终值也是 51.29。E.1 说"所有报告数字使用同一 validation setup"（p16）。【推断】版本选择用的就是报告的 77 题 / 175 题评测集，选择层面属 **S**。论文没有单独的 dev split 说明。

## 关键数字（Table 3 p7）
- SWE BC%：4B 24.68→31.49；9B 30.19→38.16（人工 RL 基线 31.17 / 33.77）。
- Coding（LCB-v6 175 题）Avg@8：46.71→51.29，人工 RL 基线 50.71；与人工基线差异不显著（p>0.1，p6）。AutoResearch 只得 45.51，低于基座。
- Math：AIME24 77.50→84.17，AIME25 67.50→73.33，CNMO 75.00→81.94。

## 泛化 / hacking 证据
- **Git 泄漏**：SWE-9B v1 环境中模型能用 git log/show 看到参考 patch，validation 虚高到 48.80，清理后真实 31.04（p14 D.2，Table 10）。纯分数驱动的循环会把它当最佳版本晋升。
- 77 题评测集很小（1 题约 1.3 点），且每版本单 seed（p9 Limitations）。

## 评测是否含 HE(+)/MBPP(+)/LCB
- **含 LCB**（v6，175 题 AtCoder ABC 子集，较新题）。不含 HE/MBPP。
