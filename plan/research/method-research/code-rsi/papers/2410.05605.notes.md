# 2410.05605 CodeDPO: Aligning Code Models with Self Generated and Verified Source Code（ACL 2025）

- 读的范围：正文 p1–9 全读；附录 A、J（PageRank 打分细节）略读。源：`src_2410.05605/2410.05605.pages.md`。
- **改进对象**：权重（DPO，10 epoch，按最低验证 loss 选模型，lr 5e-6，p5–6）。
- **自我改进程度**：标题称 "self generated"，但**数据生成模型是 DeepSeekCoder-v2**（p5），而被训模型是 DeepSeekCoder-6.7B/1.3B、MagiCoder 系列、Phi-2、StarCoder2-7B 等——对大多数被训模型而言是**外部模型生成、自验证（代码×测试互验）**的数据，不是严格的"同一模型改进自己"。
- **训练/信号数据**：题目种子按 OSS-Instruct 方式从开源代码抽取概念生成（沿用 starcoder2-self-align 实现，p3）；每题由 DeepSeekCoder-v2 采 15 个解与测试（T=1.5），用 PageRank 式互验打分（T=10、d=0.85）得到正确性排名，再用可信测试测运行时间得到效率偏好（p4–5）。最终 **93k 正确性样本 + 21k 效率样本**（p5）。数据构造成本约 80 美元（p5）。
- **每轮怎么用**：一次性构造数据 → DPO。不是多轮。
- **评测**：**HumanEval、HumanEval+、MBPP、MBPP+**、DS-1000、**LiveCodeBench（按难度报告；版本/日期窗口未说明）**（p5、Table 4 p7）。
- **是否不相交**：训练题来自开源代码概念生成，与评测 benchmark 来源不同；未做去污染检查；作者说 DS-1000 几乎不在任何模型训练集中（p6）。
- **关键数字**：MagiCoder-S-DS-6.7B：HE 73.17→83.54，HE+ 68.29→76.22，MBPP+ 66.67→70.93（Table 1/2 p7）；LCB Easy/Medium/Hard 48.1/10.7/0.1 → 53.1/16.3/0.7（Table 4 p7）。
- 数据规模：训练数据从 25% 增到 75% 时 HumanEval 32.92→41.46（RQ5，p8），说明在该设置下数据量越多越好。
