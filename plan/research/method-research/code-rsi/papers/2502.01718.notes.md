# 2502.01718 AceCoder: Acing Coder RL via Automated Test-Case Synthesis（v4，2025-05）

- 读的范围：正文 p1–8 全读；附录 A（prompt、额外表）略读。源：`src_2502.01718/2502.01718.pages.md`。
- **改进对象**：权重（先训 reward model，再 Reinforce++ RL）。
- **是否属于"模型改进自己"**：**否 / 边缘**。题目改写和约 20 个测试由 **GPT-4o-mini** 生成，用 **Qwen2.5-Coder-32B-Instruct** 跑解过滤幻觉测试（p3–4）——都是外部模型；只有 RL rollouts 是策略自己的。放入表中作为"外部合成 RLVR 数据集"参照，不作 RSI 证据。
- **训练/信号数据**：**AceCode-87K**：种子 = Magicoder-Evol-Instruct-110K + Magicoder-OSS-Instruct-75K + StackPyFunction（仅 Python 函数/类，124,006 条），过滤后 **87,149 题、1.38M 测试**（Table 1 p4）。RL 用其中"难"的 25%（平均通过率低、方差高）（p5–6）。
- **每轮怎么用**：Reinforce++，rollout batch 256，每题 8 个程序，lr 5e-7，**1 episode**（p6）。奖励：RM 分数或二值"全部测试通过"。
- **评测**：HumanEval(+)、MBPP(+)、BigCodeBench（C/I，Full/Hard）、**LiveCodeBench V4**（p6）。
- **是否不相交**：训练题来自 Evol/OSS-Instruct/Stack 种子，与评测 benchmark 来源不同；论文**未做去污染检查**（全文无 decontam 字样）。
- **关键数字（Table 4 p6）**：Qwen2.5-Coder-7B-Base + Rule：HE 61.6→84.1，HE+ 53.0→78.0，MBPP+ 62.9→69.3，LCB V4 28.7→28.5；Qwen2.5-Coder-7B-Instruct 起点：HE+ 86.0→84.8（下降），LCB 34.2→34.9。
- 数据选择相关：Base 模型上 HE+ +25 而 LCB 不变——HE+ 的大幅提升很可能主要是格式/指令跟随被激活，而不是解题能力提升【推断】；对已指令微调模型几乎无增益。
