# 2410.24198 SelfCodeAlign: Self-Alignment for Code Generation（NeurIPS 2024）

- 读的范围：正文 p1–10 全读（§2 方法、§3 评测、§4 组件分析）；附录 B（种子收集、去污染，p18）读；few-shot 示例附录略读。源：`src_2410.24198/2410.24198.pages.md`。
- **改进对象**：权重（SFT）。**同一个基座模型**（CodeQwen1.5-7B）自己完成：从种子函数抽概念 → 生成指令 → 生成"回答 + 测试" → 沙箱执行，过滤被测试否定的回答（p3–4）。无教师模型、无人工标注。
- **训练/信号数据**：种子 = **The Stack V1 中带 docstring 的 Python 函数**，从 5M 过滤到 **250k**（类型检查、去 benchmark 条目、去近重复，p3）；最终得到 **74k 条指令-回答对**（摘要 p1）。附录 B：按"benchmark 题目的 prompt 或解的子串是否出现在种子函数中"做去污染（p18）。
- **每轮怎么用**：单轮数据生成 → SFT。自验证 = 模型自写测试，执行通过才保留，每条指令随机留一个通过的回答（p4）。
- **评测**：**HumanEval+、MBPP+**（EvalPlus）、**LiveCodeBench（2023-05 至 2024-02 共 400 题，按起始日期 2023-05/07/09 分别报告）**、EvoEval、EvalPerf、ClassEval、DS-1000、CanItEdit（p4–8）。
- **是否不相交**：种子来自 The Stack，与评测不同源，且做了子串去污染（p18）。LCB 起始日期往后推时分数几乎不变（23.4→22.4），作者据此认为污染风险低（p5 Table 2）。
- **关键数字**：SelfCodeAlign-CQ-7B HE+ 67.1、MBPP+ 65.2，基座 CodeQwen1.5-7B-Base 45.7/60.2，OctoPack 版 50.6/63.2（Table 1 p4）；LCB（2023-09 起）22.4（Table 2 p5）。
- **数据选择相关（Table 8 p8，37k 种子子集，HE+）**：模型能力相近时，**用自己生成的数据比用略强的教师数据更好**（StarCoder2-3B：自数据 35.4 vs Llama-3-8B 数据 34.1）；教师明显更强时（DeepSeek-Coder-33B 数据 → 42.1）蒸馏更好（p8）。种子选择、概念生成、执行过滤都各自有正贡献（p2）。
