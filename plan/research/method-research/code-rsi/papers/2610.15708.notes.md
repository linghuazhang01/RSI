## 改进对象
- 冻结 LLM 的 coding agent 不断改写**行为规格说明（代码文档）**：按规格生成代码 → 执行测试 → 按失败修改规格 → 用新规格再生成。多前沿树搜索（Pareto 状态选择、依赖约束的实体选择、按失败子集分化扩展）解决"输出耦合"（p1–6）。不改权重。

## 数据
- 评测与搜索都在 **DevEval+**：20 个 Python 模块、247 个实体、760 个测试用例；10 个模块来自 DevEval，其余来自 GitHub（p6；附录 H p33）。
- 搜索时只拿 **LLM 生成的测试**：LLM 提输入，在**参考实现**上运行得到期望输出（所以输出正确性有保证）；**最终用隐藏的真实测试评分**（p6 §4.1；附录 E p26）。
- 迁移：跨语言翻译（DevEval+-Java 子集）与新功能实现（p9–10）。
