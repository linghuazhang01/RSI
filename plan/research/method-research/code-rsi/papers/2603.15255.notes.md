# 2603.15255 SAGE: Multi-Agent Self-Evolution for LLM Reasoning（arXiv 2026-03）

- 读的范围：正文 p1–8 全读；附录 A（超参）、B（训练数据组成，p13）读；案例附录略读。源：`src_2603.15255/2603.15255.pages.md`。
- **改进对象**：权重（**LoRA rank 128、alpha 256**，lr 3e-6，Task-Relative REINFORCE++，每个模型 200 步，p6 与附录 A）。同一 backbone 实例化 Challenger / Planner / Solver / Critic 四个角色并联合训练（p3–4）。
- **训练/信号数据**：**500 条种子**（附录 B Table 5 p13）：MATH 156、GSM8K 148、**HumanEval 87**、**MBPP 109**。论文说这些来自 "official training splits"。Challenger 以种子为参考生成新题（代码题带单元测试），Critic 过滤，Solver 的正确性由外部验证器（标准答案或单元测试）判定（p3–5）。
- **每轮怎么用**：迭代地扩充题库 → 采样题目 → Planner/Solver 解 → 全体联合更新（Fig.2 p4，Algorithm p4）。
- **评测**（p6）：代码：**HumanEval+、MBPP+（EvalPlus，作者标为 ID）**、**LiveCodeBench v1–v5（2023-05 至 2025-02，标为 OOD）**；数学 GSM8K、MATH（ID）与 AIME24/25、AMC、OlympiadBench（OOD）。greedy pass@1。
- **是否不相交**：**有明显污染风险**。HumanEval 只有 164 道题且没有官方训练集【推断：87 条 HumanEval 种子只能来自其 164 题，与 HumanEval+ 评测题重叠】；MBPP 的 109 条若来自 train split 则与 MBPP+ 不重叠（论文未给题号）。作者自己把 HE+/MBPP+ 称为 ID。LCB v1–v5 与种子不重叠。
- **关键数字（Table 1 p6）**：Qwen-2.5-7B-Instruct：HE+ 73.2→76.2，MBPP+ 65.3→64.0（下降），LCB 17.5→26.4；Qwen-3-4B-Base：HE+ 76.8→75.6，MBPP+ 65.3→62.4，LCB 21.5→30.6。AZR 在同表中的 7B LCB 为 25.3。
- **消融（Table 3 p7，3B）**：不训 Critic 时 MBPP+ 62.4→53.7；不训 Challenger 或 Solver 时 LCB 16.9→9.0。
- 数据选择启示：自生成题以 benchmark 种子为模板时，HE+/MBPP+ 提升难以与污染区分；LCB 是更干净的指标。
