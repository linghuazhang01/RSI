- **改进对象**：策略模型权重（GRPO，80 步，附录 C.1 p13）；"自我进化"的是**奖励工具库**（agent 从 HuggingFace 检索 reward model 或写代码验证器，p3）。
- **是否属于"模型改进自己"**：**否 / 边缘**。奖励 agent 默认由 **GPT-5** 驱动（p5），策略模型是 Qwen3-8B 与 Llama-3.1-8B-Instruct；参考答案缺失时用 GPT-5 的推理输出补充（p4）。这是外部强模型构造奖励，不是自生成数据或自验证。放进表里仅因用户点名，结论中不当作 RSI 证据。
- **训练/信号数据（Table 1 p3）**：代码 = **LeetCode-Dataset（Xia et al., 2025）train 2,585 题 / test 223 题**，奖励为单元测试执行；数学 GSM8K 1,500 / MATH 1,500；翻译 FLORES-200 3,000；对话 UltraChat 2,500。训练前用 LLM 做质量过滤并对多个来源均匀下采样（p4）。
- **每轮怎么用**：多任务混合 GRPO，80 步（p13）；不是离散多轮。
- **评测**：代码 = LeetCode-Dataset test 223（ID）和 **MBPP 974 题（OOD，Table 1 标为 0 train）**；数学 GSM8K、MATH 500、AIME24/25；翻译 FLORES、WMT-24；UltraChat（Table 1–2）。**没有 HumanEval/HE+、MBPP+、LiveCodeBench**。注意它的 MBPP 用的是全部 974 题（含 MBPP train/val/test 全集）。
- **是否不相交**：LeetCode train/test 是同一数据集的 split；MBPP 作者标为不含训练数据（Table 2 标题 p6）。
- **关键数字（Table 2 p6）**：Qwen3-8B：LeetCode 6.28→23.31，MBPP 14.27→19.30；Llama-3.1-8B：LeetCode 11.21→11.66，MBPP 41.17→43.18。分类 reward model 基线在 Qwen3-8B 上 GSM8K 全部塌到 0（format hacking，p6）。
