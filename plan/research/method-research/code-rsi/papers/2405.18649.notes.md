# 2405.18649 LEDEX: Training LLMs to Better Self-Debug and Explain Code（NeurIPS 2024）

- 读的范围：正文 p1–10 全读；附录 A.4（其他 LLM 采集数据）略读。源：`src_2405.18649/2405.18649.pages.md`。
- **改进对象**：权重（SFT 两轮 epoch + PPO RL），目标是"解释错误代码并修复"的自调试能力（p3–5）。
- **自我改进程度**：主实验的解释和修复由 **GPT-3.5-Turbo / CodeLlama-34B** 生成（外部）；错误解由被训模型（StarCoder、CodeLlama）自己采样。**§4.3.2 做了真正的 self-bootstrap：CodeLlama-7B 自己生成解释与修复，再用于自己的 SFT 和 RL**（p8–9）。
- **训练/信号数据**（§2.1 p3，Table 1 p3）：**MBPP train 374 题、APPS train 5,000 题、CodeContests 6,627 题**；每题用被训模型采样 20 个解（T=1.0），用测试筛出错误解；修复必须重新通过测试才算正确。GPT-3.5 版本得到 13,735 条正确解释+修复（MBPP 2,203、APPS 6,419、CodeContests 5,113）。
  - SFT 用三者全部；**RL 只用 MBPP train 与 APPS train**（p5）。
- **每轮怎么用**：单轮数据采集 → SFT 2 epoch（lr 2e-5，batch 128）→ PPO（lr 2e-6，batch 64）（p5）。不是多轮迭代。
- **评测**：**MBPP（test）、HumanEval、MBPP+、HumanEval+**，每题采样 100 个初始解，失败者再修复一次（p5）。没有 LCB。
- **是否不相交**：MBPP train→MBPP test 为同 benchmark 不同 split；HumanEval 是不同 benchmark；未提去污染。
- **关键数字**：
  - CodeLlama-7B + LEDEX RL（GPT-3.5 数据）HE+ refine pass@1 50.04（Prompt 32.49）（Table 2 p6）。
  - Self-bootstrap（Table 8 p9）：SFT 相对 prompting 在 MBPP&HE 上 pass@1 +8.25，MBPP+&HE+ +5.33；**RL 在自生成数据上只再加 ≤0.78**，作者结论：自举数据下 RL 增益远小于用更强 LLM 的数据（p8）。
