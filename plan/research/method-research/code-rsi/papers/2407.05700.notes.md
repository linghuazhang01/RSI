# 2407.05700 InverseCoder: Self-improving Instruction-Tuned Code LLMs with Inverse-Instruct（AAAI 2025）

- 读的范围：正文 p1–7 全读（含 §6.1–6.8 分析）；附录略读。源：`src_2407.05700/2407.05700.pages.md`。
- **改进对象**：权重（SFT）。被训模型 M（WizardCoder-GPT4，即在 evol-codealpaca-v1 上微调过的 CodeLlama-Python-7B/13B、DeepSeek-Coder-6.7B）**自己把已有代码总结成新指令**，再自己打分选最佳指令，最后基座在"原数据 ∪ 自生成指令-代码对"上重新微调（§4 p3–4）。
- **训练/信号数据**：**evol-codealpaca-v1（111,183 条，GPT-4 Evol-Instruct 生成）**；按 Magicoder 做法**去掉含 HumanEval、MBPP、MultiPL-E、DS-1000 docstring 或解的数据**，新生成数据也做同样去污染（p4）。信号是模型自评（伪概率打分），**没有执行验证**。
- **每轮怎么用**：单轮。§6.7：把 InverseCoder 再当作 M 重复一轮，**没有显著提升**（p7）；§6.8：让模型自己生成新代码作回答时表现不稳定，作者归因为原模型自生成代码质量差（p7）。
- **评测**：**HumanEval(+)、MBPP(+)**（EvalPlus，greedy）、MultiPL-E、DS-1000（p5）。**没有 LCB**。
- **是否不相交**：做了显式去污染（p4）。
- **关键数字（Table 3 p5）**：DeepSeek-Coder-6.7B 系：WizardCoder-GPT4 HE 77.4 (HE+ 73.2) / MBPP 77.8 (MBPP+ 67.5) → InverseCoder 79.9 (76.8) / 78.6 (69.0)。CL-7B：HE+ 68.9→72.0。
- 数据选择相关：每条代码选多条自生成指令会降分（§6.6 p7）——自生成数据"质量 > 数量"。
