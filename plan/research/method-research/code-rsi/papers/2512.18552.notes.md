# 2512.18552 Self-play SWE-RL (SSR): Toward Training Superintelligent Software Agents through Self-Play SWE-RL（ICML 2026）

- 读的范围：正文 p1–9 全读；附录（训练超参 p15、评测噪声）读；其余附录（prompt、案例）略读。源：`src_2512.18552/2512.18552.pages.md`（PDF 文本为非 ASCII 混排，用 `grep -a` 读）。
- **改进对象**：权重。同一个 LLM（CWM-sft，32B，CWM 联合 RL 之前的 checkpoint）同时扮演 bug 注入者与 bug 修复者，共享权重在线 RL 更新（p6 脚注）。
- **训练/信号数据**：**只有带依赖的沙箱仓库 Docker 镜像**（与 CWM 使用的镜像相同，p3、p15）；不使用 issue 文本、已有测试、测试命令（p3）。注入者自己写 bug artifact（测试脚本、测试解析器、bug diff、弱化测试的 diff），修复者根据"测试 patch"而非自然语言 issue 来修；失败修复会变成高阶 bug（p3–6）。**镜像数量、仓库列表在本文未说明**（只说与 CWM 相同）。
- **每轮怎么用**：在线 RL，150 个 global step，约 2.5B token，global batch 16M token，group size 8，lr 3e-6（附录 p15）。
- **基线**："human-data" RL：同一批镜像，但给人写的 issue 和 P2P/F2P 测试（p6）。
- **评测**：**SWE-bench Verified 500 题**与 **SWE-Bench Pro public 731 题**，单次尝试，T=1.0（p6）。**没有 HE/MBPP/LCB**。
- **是否不相交**：训练镜像（CWM 的环境）与 SWE-bench Verified/Pro 是否有仓库重叠——**论文没有说明**。作者提到评测噪声约 2% paired SE（p15）。
- **关键数字**：摘要：SWE-bench Verified +10.4、SWE-Bench Pro +7.8（p1）；整个训练过程中 SSR 都高于 human-data 基线（Fig.8 p7）。消融：注入策略 "removal + history" 最好；朴素注入 prompt 会让 bug 塌成一行的浅层改动（p2、p8）。
- 对本项目：SWE 类自我改进的"训练数据"是**仓库环境**而非题集；对选择代码训练集的直接参考价值有限。
