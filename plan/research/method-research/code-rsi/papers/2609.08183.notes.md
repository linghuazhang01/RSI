# 2609.08183 NeoHorse-1 阅读笔记（代码 RSI 数据来源专题）

- 标题：NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness（NeoHorse Team，技术报告，arXiv v2 2026-10-14）
- 文件：`src_2609.08183/2609.08183.pages.md`。读了正文 p1–20（数据管线、能力导向分配 §3.5、SFT 课程、OPD、主结果、数据消融）。Jev 部分略读。

## 改进对象
- "harness 中介的 RSI"：部署的路由 harness 记录每轮的能力需求、服务档位和交互结果，转成训练样本；模型做三阶段 SFT 课程 + 路由引导的 on-policy distillation（**固定 teacher** 给 logits）；每轮在分层评测套件上评估当前 checkpoint，按缺陷画像调整下一轮数据配比（p8 §3.5）。权重更新，基座 Qwen3.5-4B / 9B。
- 自我改进成分较弱：数据来自部署轨迹，监督来自 teacher；作者自己称是"初始原型"（摘要）。

## 数据
- 训练：私有的路由 harness 部署轨迹，经结构校验、六维语义评估、去重与去污染（p6–8）。数据量只以"唯一监督 token（M）"在 Fig.7 对数轴上给出，总条数 not stated。没有使用 APPS/TACO/LCB 题库作为训练的说明。
- 迭代时的分层评测套件"经去污染筛选与训练不相交"（p8）；其组成 not stated。
- 数据消融的"development-suite average"用的是 LCB、HE、IFBench、BFCL V4、τ2-Bench 五个 benchmark（p17）——**与最终报告的评测是同一批 benchmark**。【推断】数据规模/来源的选择依据就是测试集分数，属 S 风险。

## 不相交程度
- 训练数据：G/X（部署轨迹）；选择/消融：**S 风险**（dev = 报告的 benchmark）。

## 关键数字
- Table 1 p14（4B）：Qwen3.5-4B → NeoHorse-1-4B：HumanEval 87.20→96.95；LCB v6 53.71→59.43；平均 58.94→64.87。
- Table 2 p15（9B）：HumanEval 92.68→98.17；**LCB v6 65.14→65.14（不变）**；IFBench 66.33→66.33；平均 65.60→69.04。
- Table 3 p17（4B 数据源对比）：Toucan 公共数据 vs 路由数据：LCB 49.14→53.14，HE 87.80→96.34。
- 【推断】HumanEval 已接近饱和（98.17），它的大幅提升区分度有限；9B 的 LCB 完全没动。

## 评测是否含 HE(+)/MBPP(+)/LCB
- **含 HumanEval（原版）和 LCB v6**（日期窗口 not stated）；不含 MBPP。
