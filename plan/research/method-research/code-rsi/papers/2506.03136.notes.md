# 2506.03136 CURE: Co-Evolving LLM Coder and Unit Tester via Reinforcement Learning（ReasonFlux-Coder）

- 读的范围：正文 p1–12 全读；附录 B–C（误差表、评测细节，p19–21）读；其余附录（prompt、案例）略读。源：`src_2506.03136/2506.03136.pages.md`。
- **改进对象**：权重。同一个 policy 同时生成代码与单元测试，RL 联合优化（§3.3 p6）。
- **信号来源**：coder 的奖励 = 通过**ground-truth 单元测试**的数量（式 3 p6）；tester 的奖励 = 由执行矩阵估计的"测试能否区分对错代码"（式 4）。所以 coder 侧仍依赖人工测试，tester 侧是自生成信号；**训练不需要 ground-truth 代码解**（p4）。
- **训练数据**：**CodeContests 中难度 ≤2 的题，随机切成 4.5k 训练 / 200 评测**（§4.1.1 p8）。
- **每轮怎么用**：在线 RL；每步每题 16 个代码 rollout + 16 个测试 rollout；lr 1e-6，KL 0.01；7B/14B 训 350 步，4B（long-CoT）训 50 步（p8）。
- **评测**：LiveBench、**MBPP 标准 test**、**LiveCodeBench v2（511 题）**、CodeContests 200 题自切 eval、CodeForces 随机 500 题（与 CodeContests 不重叠）（p8）。指标：UT 准确率、one-shot Code 准确率、BoN（16 code × 16 UT）。**没有 HumanEval**。
- **是否不相交**：CodeContests train/eval 是作者随机切分（同分布）；MBPP、LCB、LiveBench、CodeForces 为不同来源；CodeForces 声明与 CodeContests 不重叠（p8）。LCB v2（2023-05 至 2024-05 发布窗口，版本说明来自 LCB 本身；论文只写"version 2, 511 problems"）。
- **关键数字**（Table 1 p8）：Qwen2.5-7B-Instruct → ReasonFlux-Coder-7B：one-shot Code MBPP 66.3→70.2，LCB 26.9→31.2，CodeContests 21.2→25.9；UT 准确率提升更大（LCB 28.6→57.7）。14B：LCB Code 33.5→40.5。附录 Table 3（p19）给出 16 次运行的标准误。
- 数据选择相关：只用 4.5K 题即可得到提升（Fig.1 p1 标题）。
