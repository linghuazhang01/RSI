# 2409.12917 SCoRe: Training Language Models to Self-Correct via Reinforcement Learning（Google DeepMind，ICLR 2025）

- 读的范围：正文 p1–14 全读（方法、实验、消融）；附录 B（超参 Table 5）、C（prompt）读。源：`src_2409.12917/2409.12917.pages.md`。
- **改进对象**：权重（两阶段多轮在线 RL，只用模型自生成数据训练"第二次尝试改正第一次"）（p6–10）。代码实验微调 **Gemini 1.0 Pro**，数学用 Gemini 1.5 Flash（p11）。
- **训练/信号数据**：代码 = **"train on MBPP"**，奖励为是否通过全部测试（二值）（p11）。**论文没有说明用的是 MBPP 的哪个 split、多少题**。数学 = MATH train + 4,500 道 MATH test（按 Lightman et al.），在剩下的 MATH500 上评测（p11）。
- **每轮怎么用**：在线 RL；MBPP 配置 1,500 步、batch 128、lr 1e-5、采样温度 1.0（附录 Table 5）。**RL checkpoint 按"训练奖励最高"选择**（p11），没有独立验证集。
- **评测**：**HumanEval**（zero-shot，两次尝试，Acc@t1/Acc@t2/Δ）、**MBPP-R**（修复 PaLM 2 第一次错误程序的离线任务）（p11–12）。**没有 HE+/MBPP+/LCB**。
- **是否不相交**：训练 MBPP → 测试 HumanEval，不同 benchmark；MBPP-R 源自 MBPP 题目，与训练题可能重叠（论文未说明）。
- **关键数字（Table 3 p12）**：HumanEval Acc@t2 base 56.7% → SCoRe 64.6%，Δ(t1,t2) 3.0%→12.2%；MBPP-R 47.3%→60.6%。Pair-SFT 在 MBPP-R 上接近（59.8%），但在 HumanEval 自纠正上反而退化（Δ −1.8%），作者归因为缺少 on-policy 采样（p12）。
