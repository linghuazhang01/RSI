# 2610.33624 RSI Arena 阅读笔记（代码 RSI 数据来源专题）

- 标题：RSI Arena: Towards Recursive Self-Improvement with Human Feedback（Huang 等，arXiv 2026-10）
- 文件：`src_2610.33624/2610.33624.pages.md`（39 页）。读了正文 p1–12（规则、评测、结果）、附录 B（评测设置表 p27）、Table 6（Stage 1 分数 p28）、附录 I（训练数据中的 benchmark 条目检查 p32–33）、各 agent 配方卡（p34–39）略读。

## 改进对象
- 十个前沿模型作为训练 agent，各自在相同预算下 post-train **同一个基座**（NVIDIA Nemotron 3.5 Lightning 30B-A3B Base），自选数据、自写或改训练代码、自做内部评测；Stage 2 再用人类盲评反馈继续改（p1–3）。agent 改的是**另一个模型**的权重（LoRA 或全参，Table 11 p33），不是自身。属于"LLM 写训练配方"一类。

## 数据
- 训练数据：**agent 自选**，规则禁止用评测/benchmark 测试数据、禁止复制参考答案（p3）。没有指定目标 benchmark（p3）。配方卡里出现 Tülu 3、UltraChat、smoltalk、Magpie、NuminaMath、Nemotron post-training 与 code 数据等（p36）。没有统一的代码训练集；哪些 agent 用了哪个代码题库，正文没有汇总，not stated。
- 内部评测：各 agent 自建，有的用 MMLU-Pro、MATH-500、HumanEval、IFEval 的子集（p8 与配方卡 p37–39），例如某 agent 用 20 道 HumanEval 题做自检（配方卡）。
- 最终评测：20 个 benchmark，代码为 **LiveCodeBench v6（175 题，官方测试，pass@1）** 与 SciCode（65 题 288 步）（Table 1 p5，附录 B p27）。LCB v6 的日期窗口 not stated。
- 污染检查（附录 I p32–33）：对 20 个 benchmark 共 33,787 条做 8-gram 检索，在 agents 的 88 GB、3,700 万条记录中**未发现训练 benchmark 测试集**；发现的重叠来自公共数据集（WildBench/IFBench 提示经 Tülu 3、MMLU-Pro 189 条、AIME 2026 第 1 题）。一个 agent 自己在 HumanEval 等上发现并移除了重叠（p8）。

## 不相交程度
- 训练：agent 自选的训练型数据（**T/X**）；内部评测含 HumanEval 子集等（各 agent 自定）。最终评测对 agent 不可见（p3），属 **X**。

## 关键数字（Table 6 p28，Stage 1）
- LiveCodeBench v6：基座 19.4、NVIDIA Instruct 44.0；十个 agent 模型 14.9–33.1（Astra 29.7、MiMo 27.4、Grok 26.9、DeepSeek 14.9、GLM 16.6、Kimi 25.7、Gemini 28.0、Muse 33.1、MiniMax 26.3、Step 17.7）。所有 agent 都低于官方 Instruct。

## 评测是否含 HE(+)/MBPP(+)/LCB
- **最终评测含 LCB v6（175 题）**；HumanEval 只出现在部分 agent 的内部自检中，不是最终评测。
