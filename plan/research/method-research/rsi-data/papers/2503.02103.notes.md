## 改进对象
**模型权重**。STaR 式自改进：模型对训练题生成 CoT，按标准答案过滤，再在正确解上 SFT（p3）；迭代 3 轮。论文提出 IMM：每轮把自改进模型与原始基座做加权合并（α=0.5，并用 DARE 处理 delta），再进入下一轮（p5）。

## 过拟合 / 泛化差距证据（核心）
- **ID 涨、OOD 跌（Fig 2，p3）**：三个模型在 GSM8K 上自改进后 ID 提升，SAT_Math / MAWPS 下降。作者命名为"superficial self-improved reasoners"，归因于记忆而非真学会推理。
- **Table 4（p14）附加 OOD**：Qwen2.5-1.5B-I 第 1 轮 SFT 后 MathQA 62.5→24.9、MMLU-STEM 53.6→40.1、SVAMP 77.7→59、ASDiv 82.8→72.5；第 3 轮 MathQA 降到 12.8。
- **多轮迭代崩溃**：基线方法（STaR、数据混合、数据累积）在 ID 上第 1 或第 2 轮就出现 collapse（Fig 6，p7）。
- **机理**：自改进的权重变化集中在中间层，而对数学推理重要的是前后层；正规全量后训练（Qwen2.5-1.5B→Math，700B token）的变化集中在前后层（Fig 3/4，Table 1，p4–5）。附录 B.1：即使用 7.5k 条真实 MATH 训练数据，变化也偏向中间层，说明"小数据微调"本身就有这个问题（p13）。
- **按 ID 重要性加权合并会过拟合 ID**：IIMM 用 ID 数据算层重要性来定合并比例，ID 偶尔更好但 OOD 更差（B.5，p14–15）。
- **合并也不总是有效**：蒸馏设置中 Qwen2.5-1.5B 的 MAWPS 90.0→72.8（SFT）→24.5（合并后）（Table 2 p8，Table 7/8 p15）。
- C.7：作者观察到当模型在某数据集上已很强时，再用自生成正确解 SFT 更容易过拟合（p18–19）。

## 对我们两篇论文的启示
- 直接证据：**在 GSM8K/MATH 训练型数据上做自改进，同 benchmark 的 ID test 会涨，而相邻数学 benchmark 和 MMLU-STEM 会跌**。只用同 benchmark 的 test（或同 benchmark 搜索池）会把这种"表面提升"当成真改进。
- 因此 gate 和 final test 必须包含**不同 benchmark**（同领域 OOD + 跨领域保留集）。
- 方法上：相对基座的约束（合并/插值、限制 delta 大小）能缓解 OOD 回退，和我们"编辑幅度受限、保留集下降惩罚"的设计一致。
- 反面教材：α 在 OOD 测试集上选。我们的超参必须只在搜索/gate 集上选。
