## 2. 信号分类，以及证据各自说明了什么

每类信号回答四个问题：(a) 能否预测遗忘；(b) 能否预测目标增益；(c) 便宜吗；(d) 会不会误导。

### 2.1 只用权重（零数据）

**(1) 范数类：‖ΔW‖_F、‖ΔW‖/‖W0‖、逐元素 \|δ\|**
- (a) 能否预测遗忘：MaLoRA 的理论（Thm 3.2）说遗忘和适配都由 ‖BA‖_F/‖W_pre‖_F 控制，但只在线性分类器加近正交任务的设定下证明，LLM 上没有验证。Audit 论文把 ‖ΔW‖_F>1 当作"adapter 是否有效"的审计阈值，近零范数的 adapter 只造成 −0.3pp（App.H）。【推断】范数只是"量"，Intruder 论文的对照实验表明决定遗忘的是"方向"。
- (b) 能否预测目标增益：无直接证据。
- (c) 成本：几乎为零。
- (d) 误导风险：DARE 发现，只有 \|δ\| 小（约 ≤0.002）时丢弃才安全；遇到错基座、delta 很大时，丢 10% 就让 HumanEval 归零（p.8）。所以范数分位数适合当安全护栏，不适合当决策信号。

**(2) 奇异谱、能量与有效秩**
- PARA：全局奇异值阈值截断，丢掉尾部时精度在很宽范围内稳定，丢掉少数头部方向则崩溃。全局阈值优于逐层均匀截断（Tab.5）。Fisher-PARA 需要 50 个 batch 的梯度，结果与零数据的 PARA 接近持平（图 7）。目标增益约 +1 点（数学 60.8→61.8），【推断】可能来自去噪。
- TSV：保留 3% 的奇异分量只损失 1.5% 精度（p.3）。在多任务设定里，"低秩 + 正交化"组合有强交互：只做低秩 75.2，两者都做 92.3（Tab.4）。
- DG-Hard：全参 delta 按随机矩阵阈值截断，修复约 81% 的损伤，保留 97% 的目标增益。【推断】对 raw LoRA 来说秩 ≤ r，median(s)=0，DG 阈值为 0，相当于什么都不做。在 LoRA 上要改用 truncate_rank，k 交给评估器选。
- Intruder 论文：有效秩不足以解释 LoRA 和全参的差异（p.6）。LoRA Learns Less 也没有把谱指标和遗忘联系起来。
- 结论：谱信号用来"决定截掉什么"很可靠（尾部安全、头部危险），但不能直接预测遗忘量。效果好的规则（DG、PARA、SLoRA）用的都是"截哪些"这一几何信息，"截多少"仍要靠评估器或阈值。

**(3) 与基座子空间的对齐（intruder / Grassmann）——单个 LoRA 遗忘方面证据最强的零数据信号**
- Intruder 论文：
  - intruder 数与遗忘的相关性强：ρ=0.971 / 0.59；与目标精度不相关（ρ≈−0.34 / −0.32），p.7。
  - **因果对照**：把 intruder 的奇异值缩小可以减少遗忘；改为缩小相邻、奇异值相近的预训练方向，遗忘反而增加（p.8、p.20）。把 intruder 放大到 λ=1.5 则遗忘上升，精度不变。
  - 学习率越大、α 越小（固定 α=8 而不是 α=2r），intruder 越多（p.7）。
  - 持续学习中 intruder 会累积，低秩 LoRA 退化最快（p.8–9）。
- SLoRA 从另一侧得出一致结论：截断位置选在与基座主子空间最对齐的地方。保留最对齐方向得 58.90，保留最不对齐方向得 55.30（Tab.4）；参考基座比参考旧 LoRA 好。
- 局限：
  - Intruder 论文的"遗忘"主要是预训练 loss，持续学习实验用的是分类头，都不是 IFEval。
  - 低秩时代价大：r=16、λ=0.3 时 TA −15%。
  - λ 仍要用目标 dev 选。
- 成本：W0 的 SVD 每个矩阵算一次，可以缓存，之后每个新 LoRA 只需小 SVD。

**(4) 与旧 adapter 的重叠：余弦、主角度、STI、符号冲突**
- O-LoRA：训练时加正交约束带来约 +9 的平均精度。但它只保护旧 LoRA 任务，MMLU 仍从 37.5 掉到 33.6；度量没有归一化，缩小 ‖A_t‖ 就能降低惩罚。
- TSV：STI 只是诊断量，算法并不优化它。早期层的跨任务重叠更高。
- TIES：符号是剩下的主要差距（oracle 符号 +5.6）。翻转 top-20% 大值参数的符号是灾难性的，翻转底部 80% 几乎无影响（Fig.7）。
- Audit：增量正交投影只带来 +2pp（Tab.17），比审计效应（约 11pp）小一个数量级。
- SLoRA：以旧 LoRA 为参考的截断不如以基座为参考。
- 结论：重叠和符号信号能说明多任务之间的干扰，但关于"对基座能力的遗忘"，目前只有间接证据。

**(5) 相对变化 \|ΔW\|/\|W0\|（FAPM）**
- FAPM 是唯一有直接 LoRA 遗忘证据的逐元素信号：剪掉 3% 的 BA 元素，general 提升 2.5–5.0 点，task 下降 ≤0.8（Tab.2）。
- 消融：只按 magnitude 剪 90% 时 general 崩到 0.1289，FAPM 为 0.6285（Tab.7），说明相对变化项承载了信息。
- 风险：DG-Hard 论文重跑 FAPM（90%）得到 on-task 77.8、preserved −6.2（Tab.1），对设置非常敏感。另外，逐元素剪枝后 BA 不再低秩。

**(6) HT-SR α（AlphaLoRA）**
- 只在训练时用来分配专家，从未在事后验证过。各 HT-SR 指标之间的差异多数 <1 点，没有随机分配对照，也没有直接检验"α 能预测层的重要性"。
- 【推断】对秩 r 的 ΔW 拟合幂律不可靠。最多拿基座 W0 的逐层 α 当免费先验。

**(7) 结构先验：层深度、模块类型**
- 深度：LiNeS 中，把浅层缩小时目标保持，把深层缩小时目标受损（Fig.1）；linear、sqrt、quadratic 三种调度差不多（Tab.6）。AdaMerging 学到的系数也是浅层小、深层大（Fig.4）。反例：T5 上缩放 encoder 会损害目标（p.25）。LiNeS 没有 LLM 遗忘数字。
- 模块：DG-Hard 中只修 attention 会崩溃，MLP 是必需的，gate+up 保留 73–78% 的 delta（Tab.18）。LoRA Learns Less 中增益主要来自 MLP（p.11–12）。SLoRA 去噪后 q/v 的保留比例最低（图 6）。Audit 中重要性为负的 block 集中在 0–4 和 29–31 层，为正的集中在 10–19 层。
- 结论：免费、粗糙，可以当 agent 的先验，但方向因模型而异，需要 pilot 验证。

### 2.2 基于激活或梯度（无标签数据）

**(8) Gram 矩阵 XᵀX（RegMean）**
- 一次前向就能收集。16 个样本已能拿到大部分收益，约 N=100 个 batch 饱和。非对角元必须收缩：α=1 在 T5/DeBERTa 上崩溃（p.8）。
- 收益大：Emotion 38.73 vs Simple 21.31。但从没测过"基座 + 小 LoRA、保留基座行为"这种设定。
- 【推断】可以把"基座在保留集上的输出"当作合并成员之一，得到一个闭式的"保住旧分布输出"算子。

**(9) 逐层激活作用比 ‖ΔW h‖ / ‖W0 h‖（TaDA 类）**
- 32 条探针就够：N=8 时 std(α) 为 0.096，N=32 时为 0.026。
- 探针门控贡献约 +1.2pp，是 TaDA 各组件中最大的；探针用错（Wikipedia 当领域探针）会退化成平均。
- 【推断】在保留集输入上算这个比值，能直接回答"adapter 在哪些层干扰保留分布"。这是最接近遗忘的廉价激活信号，但目前还没有论文直接验证它与保留集下降的相关性。

**(10) 对角 Fisher**
- 比各向同性平均只多 0.5–1.3，常小于标准差。多任务合并中 Fisher 68.3 不如 RegMean 71.8（AdaMerging 表）。成本是每个样本一次反向。
- 结论：性价比低。

**(11) 无标签熵（AdaMerging）**
- 与 loss 的相关性为 0.87，整体只比有监督目标低 0–1.5。但在难任务上落后（DTD 59.1 vs 65.6），噪声下会牺牲单个任务（EuroSAT 49.1→30.8）。
- 【推断】对 IFEval 这类开放式生成，熵几乎没有意义。我们有有标签的评估器，不需要熵。
- AdaMerging 最可靠的结论其实是：逐层系数（80.1）远强于逐任务系数（71.1）。

**(12) token 层面信号**
- Deafening Silence：词表缺失度只能预测排序（跨模型 Spearman 0.60）。
- 【推断】对冻结输出头的 LoRA 基本不适用，但可以提示 code 比 math 风险更高。

### 2.3 基于数据（有标签 dev 或评测）

**(13) 全局系数 / λ 搜索**——几乎所有方法里影响最大的旋钮
- TIES 去掉 Scale 后降幅最大（−5.2 / −2.5）。
- MaLoRA 的 margin 加权和 TA 的差别在噪声内，【推断】全局 s 承担了主要作用。
- Fisher 的 λ 搜索占约 8.5 点。
- Sakana 发现权重和接近 2 时最好，逐层配置没有明显提升。
- Self-Developing 的最优算法【推断】相当于网格外的一个缩放系数。
- 结论："全局缩放的帕累托前沿"必须作为基线：agent 的价值在于超出这条前沿的部分。

**(14) 逐层 / 逐 block 消融差分**
- Audit：32 个 block 中 14 个为负，冻结 block 30 在 probe 上损失 16pp。但只在 n=50 的 probe 上测，没有做成编辑去检验测试集。
- Sakana：删除单层带来 8.0→10%。
- 成本：L 次评估，噪声大（n=200 时 SE 约 ±0.035）。

**(15) 小 dev 上的搜索与过拟合**
- WSP-Scope：9B 数学在 dev 上 +29.69，held-out 上 −0.35。
- Audit：坐标搜索在 probe 上 +8.5pp，测试集上不如 TA。
- EvoGM：MMLU-Pro val 0.429，test 0.224。
- LoraHub："best of 3"事后选择，相当于 oracle。
- 结论：dev 越小、候选越多，选择偏差越大，必须设 dev2 验收。

### 2.4 训练轨迹（checkpoint）

- LoRA Learns Less：
  - 目标性能先升后降：HumanEval 第 4 epoch 0.498，第 8 epoch 0.437。
  - 保留分随训练单调下降：0.659→0.552。
  - 所以较早的 checkpoint 常常在目标和保留两边都更好。这是本轮读到的最强、最便宜的单一杠杆。
- MagMax：在同一条训练轨迹上，magnitude 选择才有用。独立训练的任务向量上，max、随机、平均三者无差别（71.17 / 71.78 / 71.75）。
- Deafening Silence：向基座做均匀插值，得到平滑、可调的前沿（α=0.8 时恢复 41.0%）。选择性方向删除则恢复不到 5%；去掉漂移的残差部分反而让遗忘放大 1.6–2.4 倍（p.17–18），因为漂移和补偿共用同一个张量。

对照用的非 LLM 搜索器：
- LoraHub：5-shot CE + L1，CMA-ES 约 40 次评估。
- Sakana：1000 trials。
- EvoGM：生成器在 val 分数上训练。
- Audit：16 次评估的坐标搜索。
- Transformer²：CEM 在 10 条有标签样本上搜索。

这些搜索器的共同点是只看分数、不看诊断。没有任何一篇做过"LLM 加诊断"与"同预算非 LLM 搜索"的直接对比。

**跨工作的结论**
1. **唯一真正的"信息消融"是前向预算和诊断丰富度**：WSP Exp 8 的预算曲线和 Exp 7 加上注意力模式之后的变化。两者都说明，看得到行为（生成文本、截断、激活）比只看权重更关键。只看权重的读取会退化为记忆先验（2611.08070）。
2. **反馈形式**：成功的工作都是会话内多轮"候选 → 分数加样例 → 保留或回退"，并允许编辑者拒绝。Self-Developing 不给上下文内反馈，只靠 DPO，产出大量不可执行或重复的代码。
3. **共同失败模式**：
   - 小 dev 选择偏差（WSP-Scope 9B、Audit、EvoGM）；
   - 路径依赖与高方差；
   - 收益来自修格式或修循环，而不是能力（WSP、Self-Developing 中 MATH 从 0.5 到 8）；
   - 收益可以被简单控制解释（字典控制、网格外缩放）；
   - 没有同预算的非 LLM 搜索基线。
4. 没有任何工作让被编辑的模型编辑自己的 LoRA，也没有任何工作把遗忘或保留集写进 LLM 的反馈。这正是本项目的空位，也意味着没有现成证据告诉我们 LLM 能否利用保留类诊断。

## 4. 事后编辑在哪里真正有用：用数字估计上升空间

### 4.1 单任务目标增益（一个 LoRA，不涉及其他任务）
- PARA 截断（16→平均 4）：数学 +1.0（60.8→61.8，Gemma3-4B），常识 +1.7。
- Intruder 缩放：r=256、λ=0.5 时 TA +1.8%，同时遗忘 −25.2%（Tab.4）。
- WSP 系列：0.8B 上 +29 到 +40 点，主要是修思考循环；9B 上 dev 增益不迁移。
- 【推断】对训练正常的 8B LoRA，事后编辑带来的目标增益预期只有 0–2 点。大幅增益只会出现在"raw LoRA 有明显病态"的情况，例如过训练、格式崩溃、循环。LoRA Learns Less 显示目标性能在训练后期下降（0.498→0.437），这种情况下 checkpoint 插值或选择可以拿回约 6 点。

### 4.2 多任务干扰（合并多个任务向量）——上升空间最大，但参照的 TA 基线很弱
- 相对 TA：TSV-M +15（85.86 vs 70.79）、AdaMerging layer-wise +11、LiNeS +4.5、KnOTS +4.3（ViT）/ +2.9（Llama3-8B NLI）、TIES +2.5。
- 对比之下：Audit 在真实 LLM 公开 adapter 上发现 TA/TIES 已接近不合并基线，正交投影只多 +2pp；EvoGM 在多任务设定下打不过 Single Best（0.405 vs 0.380）。
- 本项目的持续学习序列（T1 知识、T2 数学、T3 代码）在后几代会进入这个区域，但每代只多一个 adapter，T 很小（TSV 在 T=1 时等于恒等）。

### 4.3 持续学习 / 对基座能力的遗忘——和本项目最相关
- 基础事实：LoRA 本身遗忘就少。Deafening Silence 中，LoRA r=16 冻结输出头时遗忘 0.121 nats，全参为 0.6285（Tab.A17）。LoRA Learns Less 数学 IFT 第 16 epoch 的源域保留分，LoRA 0.567 vs 全参 0.559，差别很小；代码遗忘比数学多。
- 事后编辑能拿回多少：
  - Intruder 缩放：遗忘 −25% 到 −33%，目标代价约 0（r=256）；低秩时代价大（r=16、λ=0.3 时 −15%）。
  - FAPM（LoRA 剪 3%）：general +2.5 / +5.0 点，task −0.4 / −0.8。
  - LiNeS（ViT LoRA）：control +2.5 到 +4.7，target ≤−0.3。
  - DG-Hard（全参，不适用于 raw LoRA）：修复 81%，保留 97% 目标。
  - 向基座均匀插值：遗忘恢复与学习损失大致成比例（α=0.8 时恢复 41.0%，学习损失落在 1.0–29.9% 区间内）。
  - 选择性方向删除：恢复 <5%。
  - MagMax：旧任务遗忘 25.7%→9.8%，代价是最新任务 −12 点。
  - SLoRA（持续学习，事后截断）：Llama3.1 上 Post 比 Seq +1.9，Pre（含顺序训练）+7.4；Qwen2.5-7B 上 Post +6.6。
- 【推断】本项目若用 rank 16–64、默认学习率在 math/code 上训 Qwen3-8B，raw LoRA 在 IFEval 和知识上的掉分可能只有几个点。IFEval 541 条 prompt 的标准误约为 2pp 量级，事后编辑能救回的部分（约 30–80% 的掉分）可能落在噪声里。上升空间主要取决于 raw LoRA 本身遗忘有多大：高学习率、高秩加小 α、代码、长训练都会让它更大。pilot 必须先把这一点量清楚。

## 5. 建议（以下是我的建议，不是文献结论）

### 5.1 预先算好、以表格形式给 agent 的诊断（一次性，零或极少数据）
每个 (layer, module) 一行，36 层 × 7 个模块约 252 行【推断：Qwen3-8B 的层数，待核】。附上全模型汇总和按层分组的汇总。
1. **ΔW 基础量**：‖BA‖_F、‖BA‖_F/‖W0‖_F，以及紧凑奇异值 σ_1..σ_r（用 PARA 的 QR+SVD，开销可忽略）、能量累计曲线、有效秩，全模型统一排序的奇异值分位。
2. **与基座的对齐 / intruder 分数**：BA 的每个奇异方向与 W0 top-K 奇异子空间的最大余弦，以及 SLoRA 的 φ_c 曲线。W0 的 SVD 每个基座只算一次并缓存（8B 规模单卡几分钟到几十分钟【推断】）。这是第 2 节中唯一有因果对照的遗忘信号。
3. **与历史 adapter / checkpoint 的关系**：归一化主角度（不要用 O-LoRA 的原始 ‖AᵀA‖），符号冲突率（TIES 式），和每个历史 adapter 的 ΔW 余弦。
4. **FAPM 相对变化质量**：每个模块中 \|ΔW\|/\|W0\| 落在高分位的比例。
5. **结构先验**：层深度、模块类型。在说明里告诉 agent 文献的方向（浅层可缩、MLP 承载遗忘），但注明"未在 Qwen 上验证"。
6. **激活作用比**（每个数据集一次前向，32–128 条输入即可）：每层每模块在目标 dev 输入和保留集输入上分别算 ‖ΔW h‖/‖W0 h‖，再给出两者之比，指出 adapter 在哪些位置主要作用于保留分布。这是我认为最该做 pilot 验证的信号【推断】。
7. **checkpoint 轨迹表**：每个保存点的目标 dev 分数、保留集代理分数（下文第 8 条的 KL）、和最终 LoRA 的余弦。

### 5.2 评估器反馈：每个候选返回什么
8. 目标 dev 的 Δ（附 bootstrap CI）、各保留集的 Δ（IFEval 按 prompt-level strict 计、IFBench、知识，各附 CI）、目标分数减 λ×保留下降的总分。另附一个便宜的连续代理：在固定保留 prompt 上算 base 与 candidate 的 teacher-forcing token KL。它比准确率稳定，可以在评估前先做筛选（WSP-Scope 的 TF 类探针与此相当）。
9. 行为统计：输出长度、截断比例、格式失败率，以及 2–3 个"编辑前对、编辑后错"的保留集样例 diff。WSP 系列表明，看得到行为才是关键。
10. 历史：所有候选的程序摘要、算子参数和得分组成一张表，外加剩余预算。dev2 和 test 永不回传（参照 Robots 不回传 held-out 的做法）。允许 agent 提交"保持原样"。

### 5.3 交给 agent 自己调用（按需付费）的诊断
- 逐 block 或逐模块组的消融差分（每次消耗一次评估预算）：把 4 层 × {attn, mlp} 作为一组，避免 L 次全量评测。
- RegMean 式的 Gram 闭式"保留输出"算子：作为算子提供，而不是作为诊断。需要预先收集保留集的 Gram，成本是一次前向。

### 5.4 不建议投入的信号
- HT-SR α（对秩 r 的 ΔW 不可靠，证据弱）。
- 无标签熵（对生成式 IF 任务会误导，而我们有有标签评估器）。
- 对 raw LoRA 用 DG 阈值（等于什么都不做）。
- DARE 随机丢弃（期望增益为零；只当作 TIES 的预处理保留）。
- 对角 Fisher（需要反向，收益小于方差）。
- 未加校验的选择性 project_out（Deafening Silence：会切断补偿，放大遗忘 1.6–2.4 倍）。若保留该算子，评估器必须单独看它的保留集结果。

### 5.5 agent 必须打败的强基线（在同评估预算下）
(a) 全局缩放 s 的帕累托前沿；(b) checkpoint 选择或插值；(c) LiNeS 深度线性缩放（2 参数网格）；(d) intruder 缩放 λ 网格；(e) truncate_rank 的 k 网格（PARA 全局阈值）；(f) 同预算的随机搜索或 CMA-ES（LoraHub / Sakana 式）；(g) Single Best / 不编辑。
文献中最有影响的变量一直是全局系数，所以必须报告 agent 在 (a) 之上多出的部分。

### 5.6 pilot 必须回答的问题
1. **遗忘量够不够大**：Qwen3-8B 上 math/code raw LoRA（几组 r、lr、步数）在 IFEval/IFBench/知识上掉多少，CI 有多宽？如果掉分小于 2×SE，就要调大训练强度，或者换用 token-KL 作为主保留指标，并如实说明。
2. **intruder / 对齐分数能否预测保留集下降**：在 Qwen 的不同 checkpoint、rank、lr 之间复现 ρ。如果复现不出来，就从预计算表中降级。
3. **激活作用比能否预测逐组消融差分**：如果能（例如 Spearman >0.6），就可以用一次前向替代 L 次评估。
4. **超出全局缩放前沿的部分有多大**：先只画"全局 s"和"checkpoint 插值"两条前沿，再看 LiNeS、intruder、truncate 能否超出。如果都不能，agent 的上升空间接近零，需要重新考虑任务设定。
5. **诊断消融**：同评估预算下比较四种条件——只有评估分数、加权重表（5.1 第 1–5 条）、再加激活与 checkpoint 表（第 6–7 条）、再加按需消融。这是文献中没有的、本项目可以贡献的信息消融。
6. **选择偏差**：候选数与 dev→dev2 落差的关系，参照 WSP-Scope 9B 和 Audit 的现象，定出每代的候选上限。
7. **模块定位**：Qwen3 LoRA 的遗忘主要在 MLP 还是 attention、浅层还是深层（对照 DG-Hard 和 LiNeS 的结论）。
8. **工具调用能力测量**：raw LoRA（math/code）会不会削弱模型写编辑程序和调用工具的能力？如果会，编辑者应该改用"挂旧 adapter 或基座"的版本，这一点要单独记录。
