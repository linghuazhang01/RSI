# FAPM：Mitigating Catastrophic Forgetting in LLMs with Forgetting-aware Pruning（2509.08255）

## 元信息
- 标题：Mitigating Catastrophic Forgetting in Large Language Models with Forgetting-aware Pruning
- 作者：Wei Huang*, Anda Cheng*, Yinggui Wang†（Ant Group）
- 版本：arXiv:2509.08255v1，2025-09-10（p1）；Spectral Unforgetting 引用为 EMNLP 2025。代码 github.com/secretflow/ACoLab/.../FAPM
- 阅读范围：全文 p1–p15（正文 p1–p8、Limitations p9、参考文献 p9–p10、附录 A–F p11–p15）。p1 的 Fig.1 与正文双栏混排，提取后文字交错但可读；Fig.2/5/6/8 的曲线只剩坐标，没有逐点数值。

## 研究问题
在不改训练过程、不用额外数据、不改模型结构的前提下，事后缓解全参数微调造成的灾难性遗忘，同时保住下游任务精度（p1–p2）。

## 做了什么 edit/merge 决策（post-hoc）
- **纯 post-hoc**：对 task vector ΔW = W_ft − W_pre 逐矩阵打分，把得分低的 90% 元素置零（即回退到预训练值），W_ft ← W_pre + ΔW⊙M（Alg.1, p11）。
- 稀疏率在所有模型和数据集上固定为 90%（B.1, p11）。
- LoRA 版本：把 W_loraB·W_loraA 当作 ΔW 进行剪枝，剪枝率改为 3%/10%/90%（p7, Table 2）。

## 驱动决策的信息
- **信号：绝对变化 |ΔW| 减去"相对变化" |ΔW|/|W_pre| 的惩罚项**。
  - S_i = |ΔW_i| − avg(|W_pre_i|) · |ΔW_i| / |W_pre_i|（Eq.1, p4），其中 avg 是对该矩阵 |W_pre| 取平均，作用是把两项拉到同一数量级（作者观察到 |ΔW|/|W_pre| 约为 1e−2，|ΔW| 约为 1e−4，p4–5）。
  - 【推断】可改写为 S = |ΔW|·(1 − avg|W_pre|/|W_pre|)：凡是 |W_pre| 小于该矩阵平均值的位置，得分为负，会被优先剪掉。所以 FAPM 实际上是"保留落在大幅值预训练权重上的大更新"。
- 理论动机：W_ft = W_pre·(1 + ΔW/W_pre)，作者认为相对改变量越大，越可能破坏已有知识（p3）。这是启发式论证，没有形式化证明。
- **数据需求**：无（只需两个 checkpoint，p5）。
- **代价**：逐元素运算加每个矩阵一次 top-k 阈值，O(#params)；没有前向、反向或 SVD。

## 决策方式
- 闭式打分 + 固定稀疏率。90% 的选择依据是对稀疏率的扫描（App. D, Fig.5/6, p12–13）：作者观察到 >90% 时下游精度明显下降，<90% 时遗忘逐渐增加，因此称 90% "可能是最优平衡"。**论文没有说明扫描是在验证集还是测试集上进行的**【推断：很可能直接看测试集上的下游与通用指标】。
- LoRA 的剪枝率（3%/10%/90%）没有给出选择依据（Table 2, p7）。

## 关键结果
- 设置：Llama3-8B、Qwen2-7B；全参数 SFT（lr 1e-5，batch 64，3 epoch，B.1 p11）；8 个下游任务；通用能力用 C-Eval、GSM8K、MMLU、HumanEval 四项的平均衡量（p5）。
- **全参数 SFT 的遗忘非常严重**（Table 1, p6）：Llama3-8B/RTE 的通用平均从 0.6204 降到 0.1403，GSM8K 从 0.7922 降到 0.075，HumanEval 降到 0.0。
- **FAPM**（Table 1, p6）：Llama3-8B/RTE：通用平均 0.6242（高于预训练的 0.6204），RTE 精度 0.897（FT 0.890）；WikiQA：0.6285 / 0.964（FT 0.966）；SQuAD：0.6063 / 0.637（FT 0.646）。
- 汇总（p6–7）：Llama3-8B 上 8 个下游任务平均，FAPM 0.814 vs Full SFT 0.816（下降 0.25%）；通用平均 0.6112 vs 预训练 0.6132（下降 0.33%）。
  - 注意：摘要写成"CF 只有 0.25%、下游精度保持 99.67%"（p1），与正文"下游下降 0.25%、通用下降 0.33%"的口径对不上，摘要把两个数的含义互换了。
- **LoRA 微调**（Table 2, p7，Llama3-8B）：
  - SQuAD：剪 0% 时通用 0.5954 / 任务 0.648；剪 3% 时 0.6204 / 0.644；剪 90% 时 0.6223 / 0.456
  - MedQA：剪 0% 时 0.5650 / 0.640；剪 3% 时 0.6154 / 0.632
  - 也就是说，对 LoRA 的 BA 只剪掉 3%，通用能力就基本回到预训练水平（预训练 0.6204），任务代价 0.4–0.8 点；剪 90% 则任务精度崩溃。
- **顺序微调**（Table 4/5, p8，Llama3-8B）：RTE→WikiQA 后，RTE 从 0.890 掉到 0.652，加 FAPM 后为 0.878；RTE→Winogrande 后，RTE 从 0.890 掉到 0.716，加 FAPM 后为 0.882。

## 消融（逐个隔离信号）
- **只用 |ΔW|（magnitude pruning）**：Fig.2（p3）显示在 Llama3-8B 的 RTE/MRPC 上，稀疏率 <90% 时遗忘严重，>90% 时任务精度下降，找不到同时兼顾两者的点。Table 7（p13，统一 90% 稀疏）：Llama/WikiQA 的通用平均，magnitude 0.1289 vs FAPM 0.6285；Llama/RTE：magnitude 0.4647 / 任务 0.901 vs FAPM 0.6242 / 0.897。**这组对比隔离了"相对变化惩罚项"的作用，效果非常大。**
- **只用相对变化 |ΔW|/|W_pre| 剪枝**（Table 3, p7，剪掉相对变化小的元素）：同等稀疏率下，通用能力比 magnitude 剪枝**更差**（Winogrande 50% 稀疏：0.3548 vs 0.5768），作者据此说明相对变化与遗忘强相关（大的相对变化 = 致遗忘的位置）。
- **Wanda（|W|·‖X‖，需要校准数据）**（Table 7, p13）：通用能力接近 FAPM，但下游任务平均下降 3.6%（p13），例如 Llama/Winogrande 任务精度 0.750 vs FAPM 0.824。
- 稀疏率扫描：Fig.5/6（p12），只有曲线。
- **缺失的消融**：没有按模块或按层的分析；没有与 WiSE-FT 在调过 α 的情况下比较（WiSE 的 α 设置未说明）；单 seed；没有 IFEval 一类指令遵循指标。

## 作者声明的局限（p9）
- 没有研究与现有（训练时）CF 方法的组合；FAPM 是后处理方法，与训练时方法如何协同是未来方向。

## 批判
- 【推断】全参数 SFT 之后 GSM8K 和 HumanEval 降到约 0（Table 1），更像是输出格式或对话能力的整体崩溃，而不是知识遗忘；在这种极端损伤下，"回退 90% 的元素"几乎等于回到预训练模型，自然能恢复通用能力。真正的考验是 FAPM 能否保住任务增益——在 Llama 的 RTE/WikiQA 上它做到了，但 Spectral Unforgetting 用同样 90% 的设定复现时，on-task ret. 只有 77.8、% preserved 为 −6.2（2605.20296 Table 1, p6）。两篇论文结论冲突，说明 FAPM 的效果高度依赖设置。
- 摘要与正文数字的口径不一致（见上）。
- 90% 稀疏率的选取依据不透明，很可能在测试集上挑选。
- 【推断】Eq.1 中当 |W_pre|→0 时惩罚项会爆炸，实现里应该有 ε 处理，论文未提及。

## 对我们项目的启示
- **最值得给 agent 的信号**：逐元素相对变化 |ΔW|/|W_0|，或 FAPM 组合分数 |ΔW|·(1 − avg|W_0|/|W_0|)。计算免费，不需要数据，可以按模块、按层统计分布，作为"哪些位置在冒险"的诊断。我们的 magnitude prune 算子应该支持"以 FAPM 分数代替纯幅值"这一选项。
- **对 LoRA 的直接证据**：剪掉 BA 中 FAPM 分数最低的 3%，通用能力就从 0.5954/0.5650 回到约 0.62，任务代价 ≤0.8 点（Table 2）。这正是我们的设置（LoRA + 合并后的 delta），而且显示**LoRA 下的剪枝率必须很小**。
  - 但注意：剪枝后的 BA 不再是低秩，需要以稠密 delta 形式存储，或者用 SVD 重新压回 rank r（会引入近似误差）。
- **预测遗忘？** Table 3 显示，按相对变化保留的元素恰恰是致遗忘的位置，所以相对变化对遗忘有预测力（基于 Llama3-8B、2 个任务）。**预测目标增益？** |ΔW| 本身对目标增益有预测力（magnitude 90% 剪枝后任务精度不降，Fig.2）。
- **可能误导**：全参数 FT 场景下效果大（因为损伤本身极端），LoRA 场景下 headroom 小得多；而且另一篇论文的复现结果相反（2605.20296）。必须让 evaluator 来裁决，不能当作默认开启的步骤。
- **headroom**：LoRA 上通用平均约 +2.5~5 点，任务约 −0.4~−0.8 点（Table 2，单 seed，2 个任务）。
