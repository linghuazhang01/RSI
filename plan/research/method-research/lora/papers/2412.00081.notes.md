## 研究问题
Task Arithmetic 把整个网络当扁平向量，只能用余弦相似度之类的粗粒度度量衡量任务间关系。作者转向**逐层任务矩阵** Δ_i^(l) = θ_ft_i^(l) − θ_pre^(l) 的 SVD，问：(1) 任务矩阵是否低秩，能否据此压缩？(2) 能否用不同任务奇异向量之间的重叠来定义并降低任务干扰？

## 做了什么 edit/merge 决策
- **TSV-C（压缩，§4.1, p.4）**：每个任务每层只保留 top-k 奇异分量（k 取层维度的 1/T），推理时已知/路由得到任务 h，只用该任务的低秩 Δ̂_h（Eq.7）。存储约为原模型的 2 倍，与任务数无关（p.6）。
- **TSV-M（合并，§4.2, Algorithm 1, p.4–6）**：
  1. 每层每任务 SVD：Δ_i = U_i Σ_i V_i^T，保留前 1/T 的奇异分量；
  2. 拼接 U = [U_1|…|U_T]，Σ = blockdiag(Σ_i)，V = [V_1|…|V_T]；
  3. 对 U、V 各做一次 SVD：U = P_U D_U Q_U^T，取 U_⊥ = P_U Q_U^T（即正交 Procrustes / 白化 X(X^TX)^{-1/2}，Prop.4.1 证明两者等价）；
  4. 重构 M̂ = U_⊥ Σ V_⊥^T，θ_MT = θ_pre + α M̂，α 默认 1.0。
  非矩阵层（如 LayerNorm）退化为普通 Task Arithmetic（p.12）。

## 驱动决策的信息
- **信号 1：每个任务矩阵的奇异值谱**（低秩性）。仅用权重；决定截断秩。但实际**不按谱自适应**，而是统一取 1/T（p.8 结论段明确承认是均匀秩）。
- **信号 2：Singular Task Interference（STI, Eq.6, p.4）**：
  STI({Δ_i}) = ‖(U^T U − I) Σ (V^T V − I)‖_1
  其中 U、V 是各任务奇异向量的拼接。U^TU、V^TV 的非对角块是不同任务奇异向量的内积，理想无干扰时为单位阵。仅用权重，**无需数据**。
  - 注意：STI 是**诊断/分析量**，算法里并没有直接最小化 STI 的目标函数；去相关是通过正交 Procrustes 一次性完成，STI 只在 Fig.6/8 中用于事后展示（p.7–8）。
- **信号 3：奇异值 Σ 本身**：在去相关后保持不变（M̂ = U_⊥ Σ V_⊥^T），因此各任务的"能量"保持，只改方向。
- **数据需求**：TSV-M 不需要验证数据输入或标签（Table 1, p.2）；TSV-C 需要额外存储且需要已知任务身份（或路由器）。
- **计算代价**（逐层）：T 次任务矩阵 SVD（d×m）+ 2 次拼接矩阵 SVD（U 为 d×(T·k)，V 同理）；零前向/反向。实验在一块 16GB 4060Ti GPU 上完成，超 64GB 内存时才用集群（p.13）。

## 决策方式
- **闭式规则**：截断秩固定为 1/T，正交化闭式，α=1。
- 基线（TA、Consensus TA 等）的 α 在 {0.0, 0.1, …, 3.0} 上按所有任务**验证集平均性能**选择（附录 B.2, p.13）。
- TSV-M 的 α：作者在 Fig.7（p.8）用 7 个 8 任务子集 × 3 个模型扫描 α ∈ [0.6, 1.5]，声称 α=1.0 始终最好，因此**不再用验证集调 α**（p.8, p.13）。【推断】这个"无需验证集"的结论本身是用 labeled 数据（测试或验证集，文中未区分）扫描得到的经验规律。
- TSV-C 的 k：使用 1/T；附录 D.2.6 / Fig.16 允许按存储预算选秩（p.18）。

- **ViT-B-16（Table 5）**：TA 79.6/75.9/70.8；仅低秩 79.6/74.9/70.0；仅去干扰 84.8/79.0/73.2；TSV-M 93.9/91.0/86.5。
- **ViT-L-14（Table 6）**：TA 88.6/84.0/78.1；仅低秩 87.9/83.4/77.2；仅去干扰 92.1/86.8/81.0；TSV-M 97.0/94.4/92.5。
- **结论**：单独低秩截断无益甚至有害；单独正交化有中等收益；二者有强交互作用（组合收益远大于两者之和）。作者用 Fig.5 + Theorem 6.1 解释：对全秩矩阵做 Procrustes 正交化引入很大近似误差，截断后再正交化误差更小（条件 k ≤ n(T−2√T)/T，T=10 时约 k ≤ n/3）（p.7）。
- **STI 与精度（Fig.8, p.8；Fig.13/15, p.16–17）**：TSV-M 相对 TA 的 STI 更低、精度更高。【推断】这只是两点（TA vs TSV-M）的相关性，不是对 STI 作为预测量的独立检验。
- **白化 vs SVD 实现（D.2.1, p.17）**：数学等价，数值上略有差异。

## 作者声明的局限
- 目前对所有任务使用统一秩（1/T），未来可用逐层学习秩或 Gavish–Donoho 最优硬阈值逐任务选秩（p.8）。
- TSV-M 的设计主要基于经验（降噪 + 正交化），干扰的形式化定义尚未建立，STI 是操作性定义，靠"最小化后性能提升"来验证（附录 E, p.18）。
- α=1 的结论是"纯经验的"（p.8）。

## 批判
- 【推断】**正文与表格数字不一致**：正文称"仅去干扰"带来 +3.1% 到 +6.1%（p.7），而 Table 4 显示 +7.4/+4.7/+3.6；"两者结合"的 +15.8 到 +17.5 与 Table 4 的总提升一致（92.3−76.5、84.3−66.8）。
- 【推断】Fig.7 热力图（p.8）里 α=1.0 并非总是最优：例如 ViT-B-16 子集 0 在 α=1.2 为 94.06，α=1.0 为 93.98；ViT-L-14 子集 3 在 α=1.1 为 98.87，α=1.0 为 98.65。差距很小，所以"α=1 足够"大致成立，但"始终最好"的表述偏强。
- 【推断】正交化会改变每个任务自己的方向：U_⊥ ≠ U，这等于对每个任务都做了扰动；该扰动在任务数很多（每任务秩只有 1/T）时才小。T 很小（如 2–3 个 adapter）时，Theorem 6.1 的条件 T>4 不满足，理论支持缺失。
- 【推断】全部实验是 CLIP ViT 视觉分类、全参微调、使用现成 checkpoint；没有语言模型、没有 LoRA、没有生成任务，也不测量对零样本通用能力的保留（只报 zeroshot 作为下界）。
- 【推断】Table 1 把 TA/TIES 标为需要验证标签，而 TSV-M 不需要，但 TSV-M 的 α=1 和 1/T 秩规则是在同一批 ViT benchmark 上观察得到的，迁移到新领域时仍需验证。
- 【推断】单任务情形（T=1）下，截断秩 = 全秩、拼接 U 本身已正交，TSV-M 退化为恒等操作，对"单 adapter 编辑"无作用。

## 对我们项目的启示
- **多任务干扰 / 遗忘**：TSV-M 的核心操作（把新 adapter 的奇异向量与旧 adapter 的奇异向量做 Procrustes 去相关）与我们的 `orthogonalize against old adapters` 算子高度对应。消融显示：**正交化是主要收益来源，但必须在低秩截断后做**——对 LoRA（本身秩 r 很小）而言天然满足"低秩"条件，这是一个积极信号。
- **给 agent 的信号**：
  1. **逐层 STI 或 U^TU/V^TV 非对角块范数**：新 LoRA 与旧 adapter（或与"保留能力"代理方向）之间的奇异子空间重叠，便宜（每层几次小 SVD）、无需数据，可作为"哪些层可能造成遗忘"的诊断；Fig.6 提示早期层重叠更高。
  2. **奇异值谱**：判断 truncate_rank 的空间；但 TSV 证据表明单独截断不改善合并（Table 4 第二行），不要指望截断本身减少干扰。
- **成本**：LoRA 情形下 ΔW=BA 的 SVD 可以通过 B、A 的 QR 在 r×r 小矩阵上完成，非常便宜。
- **会误导的地方**：STI 低 ≠ 保留好；论文只展示 TA vs TSV-M 两点对比。对我们来说，"保留"（IFEval/通用知识）并不对应某个已知的 task vector——旧能力在预训练权重里而非某个 adapter 中，因此需要别的方式得到"旧能力方向"（例如历史 adapter，或在保留数据上估计的激活/梯度子空间），TSV 本身不提供。【推断】正交化同时会改变新 adapter 的方向，可能牺牲目标任务增益，需要外部评估器把关。
