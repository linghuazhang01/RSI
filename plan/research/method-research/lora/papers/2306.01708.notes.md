## 研究问题
多个从同一预训练模型出发、各自微调的 task vector（τ_t = θ_ft − θ_init）在合并成一个多任务模型时互相干扰。作者认为干扰来源有两类（p.2）：(a) 冗余参数——对某任务无影响的小幅更新稀释了另一任务的有效更新；(b) 符号冲突——同一参数在不同任务中更新方向相反，简单平均会互相抵消。目标是在不额外训练的前提下减少这两类干扰。

## 做了什么 edit/merge 决策
Algorithm 1（p.4）与 §4.2（p.5）三步加一个缩放：
1. **Trim**：每个 τ_t 只保留幅值 top-k% 的元素，其余置 0（即重置回预训练值）。
2. **Elect sign**：逐参数选出合并后的符号 γ_m^p = sgn(Σ_t τ̂_t^p)，等价于"正方向总质量 vs 负方向总质量取大者"。
3. **Disjoint merge**：逐参数只对符号与 γ_m^p 一致的、非零的值求平均：τ_m^p = (1/|A_p|) Σ_{t∈A_p} τ̂_t^p。
4. **Scale**：θ_m = θ_init + λ·τ_m。

## 驱动决策的信息
- **信号 1：逐元素幅值 |τ_t^i|**（每个 task vector 内部排序，取 top-k%）。只需权重本身，**无需数据**。代价：每个任务一次 top-k 选择（排序/分位数），零前向/反向。
- **信号 2：跨任务的符号与幅值总量** sgn(Σ_t τ̂_t^p)。**无需数据**，逐元素求和。
- **信号 3：符号一致集合 A_p** 决定哪些任务参与平均（disjoint mean，忽略 0 值）。**无需数据**。
- **超参 k、λ**：要么在 labeled validation 上调（有验证集设定），要么用固定配方 k=20、λ=1（无验证集设定，p.6）。
- 对比基线所需信息（p.5–6）：Fisher Merging 需要每任务数据上计算对数似然梯度平方（反向传播）；RegMean 需要每层输入激活的 Gram 矩阵 X_t^T X_t（前向，存储与模型同量级）。TIES 本身只用权重。
- 附录 B.1 的增强版：用每任务 32 个 validation 样本少样本训练一个多任务 (IA)^3 模型，取其符号作为 elected sign（需要 labeled 数据+训练）（p.17）。

## 决策方式
- 本质是**闭式规则**（top-k 幅值 + 多数质量投票 + 掩码平均）。
- **有验证集设定**："✓ Validation" 行（Table 1, p.6）中，λ（以及 k）在每任务的 labeled validation 上选择；附录 C.5 列出了不同任务子集在验证集上选出的最优 λ，TIES 的最优 λ 多在 1.1–2.3 之间波动、甚至出现 3（p.23）。
- **无验证集设定**：固定 k=20、λ=1。这个配方是在 11 个 (IA)^3 模型上做网格搜索得到的：k ∈ {10,20,30}，λ 从 0.8 到 3.0 步长 0.1，最优 k=20，λ=0.9/1.0/1.1 等效，取 1（附录 C.4, p.22）。因此"无验证集"只是指在全参微调的 T5/ViT 新设定上没有再调，配方本身仍来自 PEFT 设定上的 labeled 验证集搜索（p.6）。
- Task Arithmetic 无验证集时用推荐 λ=0.4（p.6）。

## 关键结果（数字均来自原文）
- Table 1（p.6）有验证集：(IA)^3 上 TIES 66.4 vs Task Arithmetic 63.9 vs Fisher 62.2 vs RegMean 58.0；单任务微调 71.4，多任务训练 73.1。T5-Large：TIES 76.9 vs TA 73.3；ViT-B/32：73.6 vs 70.1；ViT-L/14：86.0 vs 84.5。
- Table 1 无验证集：ViT-B/32 TIES 72.4 vs TA 60.4（+6.6 相对最强基线）；T5-Base 上 TIES 69.7，比基线低 3.2（[-3.2]）——**固定配方在 T5-Base 上反而更差**（p.6）。
- Table 2（p.7）OOD（6 个 held-out 任务）：T5-Base TIES 35.3（+1.0），T5-Large 40.4（+4.4）。
- Fig.5（p.7–8）：合并 2 个任务时 TIES 与 TA 归一化精度都接近 1，Simple Averaging 下降约 10%；任务数增加时 TA 下降更快。
- Table 5 / §7.4（p.9–10）：用多任务模型的符号作为 oracle sign，(IA)^3 上达到 72.0，比 TIES 66.4 高 5.6，接近多任务训练的 73.1。
- Table 7 / B.1（p.17）：32 个样本、从均值初始化的少样本多任务模型给出的符号：67.7（+1.2）；从头训练：66.5（+0.1）。
- 附录 B.2（p.17–18）：λ 在考察范围内 TIES 精度范围约 68–75%，TA 约 55–75%，TIES 对 λ 更不敏感；k 增大时性能先降后饱和（Fig.8 右）。
- 附录 B.3（p.18）：合并同任务的 10 个 HF checkpoint，保留参数越多符号冲突越多，接近 80%。

## 消融
- **组件逐一移除（Table 6, p.10，在 validation 上报告）**：T5-base / (IA)^3
  - 完整 TIES：74.5 / 70.7
  - − Trim：73.0 / 70.6
  - − Elect：73.1 / 69.6
  - − Disjoint Mean：72.6 / 67.5
  - − Scale（λ=1）：72.0 / 65.5
  - 结论（作者）：缩放和 disjoint mean 最关键；**Trim 在 (IA)^3 上几乎无贡献（70.7→70.6）**，Elect 在 T5-base 上贡献约 1.4。
- **幅值重要性（Fig.3, p.4）**：每个 task vector 只保留 top-20% 幅值，平均性能与保留全部相当（单任务，11 个 (IA)^3 任务）。
- **符号重要性（Fig.7 / §7.2, p.9–10）**：以概率 p 翻转 top-20/30% 参数的符号，性能单调下降；翻转 bottom-80/70% 的符号影响很小。即"大幅值参数的方向"是关键信号。
- **干扰机理（Fig.6, p.8–9）**：简单平均会缩小参数幅值，且符号一致性越低缩得越多；Trim+disjoint mean 和 Elect+disjoint mean 都能保住幅值。注意这只是参数统计，不是性能消融。
- **Oracle 符号（Table 5, p.9）**：符号估计是剩余差距的主要来源（66.4→72.0）。

## 作者声明的局限（附录 A, p.17）
- 对权重插值何时有效缺乏理论理解；依赖共同初始化与相同架构；合并的多任务模型仍落后于多任务联合训练；不清楚如何挑选要合并的 checkpoint；多任务模型的符号优于 elected 符号，如何无多任务模型地估计符号是开放问题。
- 附录 B.2 指出 k 的曲线可能随 task vector 数值分布而变化（p.18）。

## 批判
- 【推断】"无验证集"配方实际上在 (IA)^3 上用验证集调过，然后迁移到全参微调；在 T5-Base 上迁移失败（−3.2），说明固定 k/λ 并不普适。
- 【推断】Table 6 消融在 validation set 上报告，而 λ 也是在 validation 上选的，存在选择偏差；Trim 的贡献在 PEFT 上几乎为零，"冗余参数干扰"作为性能因素的证据较弱，主要证据是 Fig.6 的幅值统计。
- 【推断】最重要的组件之一是 λ 缩放（−Scale 损失最大），而 λ 必须靠 labeled 验证集调；附录 C.5 显示最优 λ 随任务子集变化很大（1.1 到 3），说明这是数据依赖的决策。
- 【推断】正文 Table 1 里 T5-Base 无验证集 TA 为 73.2，附录 Table 9 为 73.9，两处不一致（p.6 vs p.20）。
- 【推断】所有实验是"合并 N 个任务、在这些任务上评估"，不测量对预训练模型通用能力的遗忘；OOD 实验（Table 2）是最接近"保留"的度量，但基数很低（T5-Base zeroshot 31.1）。
- 【推断】幅值 top-k 对 LoRA 不直接适用：LoRA 的 ΔW=BA 是低秩稠密矩阵，逐元素裁剪会破坏低秩结构；需在 ΔW 上做或改为奇异值层面。

## 对我们项目的启示
- **单任务增益 vs 多任务干扰 vs 遗忘**：TIES 针对的是多任务干扰。对我们的"新任务 LoRA + 历史 adapter"场景，sign election/disjoint mean 可以作为"新 adapter 与旧 adapter 合并"时的算子；但它不直接回答"新 LoRA 对通用能力的遗忘"。
- **给 agent 的信号**：(1) 逐元素幅值分布（top-k 覆盖多少能量）；(2) 新旧 adapter 的逐元素符号冲突率（Fig.4 那种统计），便宜、无需数据，可作为诊断特征；(3) 大幅值参数的方向最敏感（Fig.7），因此"翻转/抵消大幅值方向"的编辑应被视为高风险。
- **成本**：全部无需前向，只需 ΔW 的逐元素运算（对 8B 模型的 LoRA，先物化 ΔW 再 top-k，内存可接受）。
- **会误导的地方**：λ 是影响最大的旋钮且必须用 labeled dev 选，这正是我们外部评估器的角色；Trim 本身对 PEFT 几乎无效，不要指望单靠 magnitude prune 改善 retention。oracle sign 实验提示"正确方向"信息价值很高——【推断】我们可以用少量 retention 数据上的梯度符号作为"方向"信号，类似 B.1 的少样本符号估计。
