# LiNeS：Post-training Layer Scaling Prevents Forgetting and Enhances Model Merging（2410.17146）

## 元信息
- 标题：LiNeS: Post-training Layer Scaling Prevents Forgetting and Enhances Model Merging
- 作者：Ke Wang*, Nikolaos Dimitriadis*, Alessandro Favero, Guillermo Ortiz-Jimenez, François Fleuret, Pascal Frossard（EPFL / Google DeepMind / Geneva & Meta FAIR）
- 版本：ICLR 2025；arXiv:2410.17146v2，2025-02-28（p1）
- 阅读范围：全文 p1–p34。正文 p1–p10、参考文献 p11–p18、附录 p19–p34。p30–p34 是逐 checkpoint 和逐任务的图（雷达图、散点），提取后只剩坐标轴数字，无法读出具体数值；Fig.9（p26）的热力图数值提取出来了，但行列对应关系部分错位，正文没有引用其中的具体格子值。

## 研究问题
(i) 微调提升目标任务、却损害其他任务（灾难性遗忘）；(ii) 合并多个微调 checkpoint 时出现任务干扰。能否只做**训练后**的权重编辑，同时保住目标任务并恢复泛化（p1–p2）。

## 做了什么 edit/merge 决策（post-hoc）
- **纯 post-hoc**。对 task vector τ = θ_ft − θ_0 按层深度线性缩放：λ(ℓ) = α + β·(ℓ−1)/(L−1)，第一层乘 α，最后一层乘 α+β，θ = θ_0 + τ_LiNeS（Eq.1, p5）。
- 单任务去遗忘时取 α=γ、β=1−γ，只调一个 γ（p4, p6）。
- 多任务合并时，把 LiNeS 作用在合并后的 multi-task vector 上（TA / TIES / Consensus），α 用启发式公式 Eq.2 确定，只调 β（p7）。
- 层外参数（不在 residual block 里的参数）一律乘 α（伪代码 p20）。
- T5 只缩放 decoder（p8, 附录 C.5 p25）。

## 驱动决策的信息
- **信号：层深度这个先验**，不使用任何权重统计量。依据来自既有文献：浅层编码通用特征，深层编码任务特定特征（p2, p4）。缩放系数只取决于层号，与 τ 的数值无关。
- 多任务的 α 启发式：α = (1/N_models)·‖τ_sum‖/‖τ_MTL‖（Eq.2, p7），只用到 task vector 的范数，不需要数据。
- **数据需求**：
  - 缩放本身：无数据。
  - 选 γ（单任务去遗忘）：**需要带标签的验证集，同时覆盖目标任务和 control 任务**。在验证集上最大化 w_target·M_target + M_control，其中 M 是归一化准确率，正文使用 w_target=2（附录 C.1, p23）。也就是说，选超参时用到了"旧能力"的标注验证数据。
  - 选 β（多任务）：在 held-out 验证集上按多任务平均准确率网格搜索，TA 搜 10 个值、TIES 搜 15 个值、Consensus 搜 10 个值 × 剪枝阈值 2 个（B.2.1, p21）；作者强调网格大小与基线的常数缩放 λ 相同，没有增加搜索成本（p7–p8, p21）。
  - Model soups：固定 α=1，在验证集上从 11 个值中搜 β（B.3.2, p22–23）。
  - Rewarded Soups（LLaMA-2 7B）：出于计算原因固定 α=β=1，不调参（p9）。
- **代价**：每层一次标量乘法，O(#params)，没有前向、反向或 SVD。超参搜索的代价是每个候选值做一次完整验证评测（10–15 次）。

## 决策方式
- 闭式规则（线性层深调度）+ 在**带标签验证集**上做 1 维网格搜索。
- 单任务：γ 在验证集上按 2·M_target + M_control 选取（p23）。
- 多任务：β 在验证集上按多任务平均准确率选取，α 用公式固定（p7, p21）。

## 关键结果
- **单任务遗忘**（CLIP ViT-B/32，8 任务，在所有 target/control 组合上取平均；Table 1, p4）：预训练模型 target 48.3 / control 48.3；微调后 90.5 / 38.0；微调+LiNeS 90.3 / 48.0。即 target 只降 0.2，control 恢复约 10 点，几乎回到预训练水平。
- 20 任务基准：归一化 target 准确率 99.8%，归一化 control 准确率 97.9%（p5, Fig.2）。
- **LoRA 微调**（ViT-B/32，8 任务，Table 11, p29）：
  - r=16：84.4/44.2 → LiNeS 84.3/46.7
  - r=32：85.8/42.8 → 85.5/46.7
  - r=64：86.6/41.6 → 86.4/46.2
  - r=128：87.5/41.6 → 87.2/46.3
  - 规律：rank 越高 target 越高、遗忘越多；LiNeS 恢复 control 2.5–4.7 点，target 损失 ≤0.3。注意 LoRA 下 control 恢复到约 46–47，仍低于预训练的 48.3。
- **多任务合并**（Table 2, p7）：ViT-B/32 8 任务 TA 69.7→74.2、TIES 73.6→77.2、Consensus 74.5→77.6；ViT-L/14 20 任务 TA 74.0→77.1、TIES 75.6→79.6。
- **NLP**（T5-large，Table 3, p8）：7 NLP 任务 TA 71.9→76.4；8 QA 任务 TIES 63.0→66.0；11 NLP 任务 Consensus 67.5→67.5（+0.0）。
- Model soups（Table 4, p9）：uniform soup 79.99→80.47；greedy soup 81.01→81.16。
- LLM（LLaMA-2 7B，LoRA r=64，Reddit 摘要，两个 reward model）：Rewarded Soups+LiNeS 的 Pareto front 占优（Fig.4, p9–10），**只有图，没有数值，也没有测量遗忘**。
- 与回传训练层系数的方法对比（Fig.5, p10）：LiNeS 的层系数曲线接近 AdaMerging / aTLAS 学到的系数，但不需要训练（定性比较）。

## 消融（逐个隔离信号）
- **缩浅层 vs 缩深层**（Fig.1, p4）：缩浅层时 target 几乎不变、control 回到预训练水平；缩深层时 target 明显下降，control 恢复也更差。这是"层深度"信号最直接的证据（只有曲线，没有表格数值）。
- **缩放函数形状**（Table 6, p24，ViT-B/32 多任务）：linear / sqrt / quadratic 结果接近，例如 TA 8 任务 74.2/73.9/73.8，20 任务 63.4/62.4/64.6。quadratic 在任务多时偶尔略好，作者为简洁选 linear。
- **α 与 β 二维扫描**（Fig.9, p26；Table 8, p27）：最优点同时满足 α>0 且 β>0，即单纯常数缩放（β=0）或完全不保留浅层（α=0）都不是最优；启发式 α 加只搜 β 得到的配置接近二维网格最优，TA α=0.125、β=0.3；TIES α=0.21、β=1.4；Consensus α=0.21、β=0.9。
- **超参敏感性**（Fig.8, p26）：加 LiNeS 后验证准确率对 β 的敏感度低于基线对 λ 的敏感度。
- **T5 编码器/解码器**（Fig.7, p25）：只缩 decoder 能保住 target 并略微改善 control；缩 encoder 会伤 target。另外，在这个 NLP 基准上，微调后的 control 表现反而**高于**预训练（p25），说明"浅层=通用"的先验并非对所有架构成立。
- **对比训练时正则**（Table 10, p28，8 任务）：target/control 分别为 FT+LiNeS 90.3/48.0；LinLR 90.7/46.9；ExpLR 89.6/46.0；HalfFT（冻结前半）90.4/46.8；LastFT 85.6/46.6。post-hoc 缩放在 control 上优于逐层学习率衰减和冻结。
- **缺失的消融**：没有与"按层的 task vector 范数 / 权重统计量自适应定系数"做对比；没有在 LLM 上做单任务遗忘实验（只有 Rewarded Soups）。

## 作者声明的局限
正文没有单独的 Limitations 节。作者自己指出的边界条件：T5 需要只作用于 decoder（p25）；固定 γ 难以兼顾所有用户偏好，所以给出了不同 w_target 下的结果（Table 5, p23：w_target=1/2/5 时验证集归一化 target/control 分别为 99.8/101.9、100.0/101.5、100.2/100.8）。

## 批判
- 【推断】"浅层通用、深层特定"的证据几乎都来自 CLIP ViT；T5 encoder 就不符合（p25），而且 NLP 基准上微调后 control 并没有下降。对 decoder-only LLM 的数学/代码 LoRA，遗忘是否集中在浅层，论文没有任何证据。
- 选 γ 时使用了 control 任务的带标签验证集（p23）。所以"恢复 control"的结果部分依赖于有 retention 验证数据，并非完全零数据。这恰好对应我们 evaluator 中 λ×retention 那一项，但需要注意，论文报告的数字是"在 retention 数据上调过参"的结果。
- LoRA 实验只有 ViT-B/32；LLM 上没有任何遗忘数值。
- 每层只有 1 个系数且必须单调递增，表达力很低；Fig.5 显示学到的系数大致单调，但只是定性比较。
- 【推断】Table 1 的 control 恢复到 48.0 ≈ 预训练 48.3，可能意味着在这个设置下 control 损伤几乎全部来自浅层；在任务与 control 共享深层特征的场景（如数学 ↔ 通用推理），预期 headroom 会更小。

## 对我们项目的启示
- **可直接给 agent 的信号**：层深度（免费，无需数据）。我们的 per-layer scale 算子可以直接实现 LiNeS 的参数化：scale(ℓ) = α + β·ℓ/(L−1)，即每个 adapter 只有 2 个标量，非常适合程序化搜索。
- **预测遗忘？** 在 ViT 上很强（control 恢复约 10 点，Table 1）；在 LoRA ViT 上中等（+2.5~4.7，Table 11）；在 decoder-only LLM 上**没有证据**。建议 agent 把"深度单调缩放"当成一个低维先验族，交给 evaluator 判断，而不是默认它有效。
- **预测目标增益？** 论文显示浅层更新对 target 贡献小（Fig.1）；若对我们的数学/代码 LoRA 也成立，那么"砍浅层"是一条低风险的编辑路径。可以先用 per-layer drop 扫一遍来验证。
- **成本**：零前向；每个候选只需一次 evaluator 打分。论文只搜 10–15 个点，说明 1 维网格就够用。
- **可能误导**：T5 的反例（p25）提醒我们，模块类型（attention/MLP、encoder/decoder）可能比深度更重要；应同时给 agent "按模块类型缩放" 的自由度。
- **headroom 预期**：LoRA 下 control 恢复约 +2.5~4.7 点，target 代价 ≤0.3 点（ViT）。对 LLM 的 IFEval/MMLU，【推断】量级可能更小，需实测。
