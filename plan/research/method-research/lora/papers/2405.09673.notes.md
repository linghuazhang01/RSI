# 2405.09673 笔记：LoRA Learns Less and Forgets Less

## 元信息
- 标题：LoRA Learns Less and Forgets Less
- 作者：Dan Biderman, Jacob Portes, Jose Javier Gonzalez Ortiz, Mansheej Paul, Philip Greengard, Connor Jennings, Daniel King, Sam Havens, Vitaliy Chiley, Jonathan Frankle, Cody Blakeney, John P. Cunningham（Columbia / Databricks Mosaic Research）
- 版本：arXiv:2405.09673v2，2024-09-20；TMLR 08/2024（p.1）
- 阅读范围：全文 p.1–p.39（正文 p.1–14，参考文献 p.15–19，附录 A–I p.20–39，含全部补充表 S1–S16）。文本抽取正常；Fig.1–7、S1–S10 曲线只有 caption，数值依赖 Table S1–S13。

## 研究问题
在难的目标领域（代码、数学）、两种数据规模（CPT ≈20B token / IFT ≈100K 样本）下，LoRA 能否追上全参微调？LoRA 能在多大程度上减轻对基座能力的遗忘？learning–forgetting 权衡是否不同？全参微调学到的扰动 Δ 的秩有多高？

## 做了什么 edit / merge / 诊断决策
- **不做 post-hoc 编辑**。本文是一个训练期比较研究，决策旋钮都是**训练超参**：LoRA rank（16/64/256）、目标模块（Attention / MLP / All）、α、学习率、训练时长（epoch / token 数）。
- **诊断**：对全参微调的 W_pretrained、W_finetuned 和 Δ 做 SVD，度量“解释 90% 方差所需秩”，跨层、跨模块类型、跨训练 checkpoint 比较（§4.6, p.9–11, Fig.6, Fig.S7）。
- 与正则化（weight decay、attention dropout）比较遗忘（§4.5, p.9）。
- 生成多样性诊断：50 次生成中不同输出串的数量（p.9）。

## 驱动决策的信息
- **学习指标**（有标签目标评测）：HumanEval pass@1（50 次生成，T=0.2, top_p=0.95）；GSM8K（test 1,319 题，5-shot，T=0）（p.4）。
- **遗忘指标**（有标签源域评测）：HellaSwag、WinoGrande、ARC-Challenge 平均，基于 logits 的多选（p.4）。
- **谱信号**：rank needed to explain ≥90% variance，即最小 k 使 Σ_{i≤k}σ_i² / Σσ_i² ≥ 0.9【推断：“方差解释”按奇异值平方累计，论文未写公式】（p.10–11）。数据需求：无；成本：每矩阵一次 SVD（4096×4096 或 MLP 尺寸），对多个 checkpoint 重复。
- **多样性信号**：独特生成串数量，需生成（HumanEval 50 样本/题）（p.9）。
- 成本：每个配置需要完整训练 + 评测；学习率需穷举扫描（p.4）。

## 决策方式
- 网格扫描（rank × 模块 × α × 学习率 × 训练时长），人工读 Pareto 曲线选配置；最终给出经验建议（p.12）：IFT 用 LoRA 而非 CPT；显存允许时 All 模块 + r=256；α=2r；学习率在 [1e-5, 5e-4] 中取能稳定训练的最大值。
- 没有自动/学习式决策规则，也没有 post-hoc 选择。

## 关键结果（含页码）
- 目标性能（Table S1–S8, p.27–28；正文 p.5–6）：
  - Code CPT 20B token：LoRA r=256 HumanEval 0.224；全参 0.263；全参 4B token 已达 0.218（p.5, Table S1）。
  - Code IFT：epoch 4 r=16 为 0.358、r=64 为 0.417、r=256 为 0.498；全参 epoch 8 为 0.497（p.6, Table S5）。
  - Math CPT：LoRA r=256 峰值 0.203（16B）；全参峰值 0.293（20B）（p.6, Table S3）。
  - Math IFT：LoRA r=256 峰值 0.634（epoch 8）；全参 0.642（epoch 4）；r=64 epoch 4 达 0.624（p.6, Table S7）。
- 遗忘（同上表）：
  - Code CPT 20B：全参 0.545 vs LoRA r=256 0.617（p.6, Table S2）。
  - Code IFT：全参 0.414 vs LoRA r=64 0.509（p.6；Table S6 中这两个值都在 epoch 16）。
  - Math IFT epoch 16：LoRA 0.567 vs 全参 0.559（p.6, Table S8）——数学上高秩 LoRA 遗忘接近全参。
  - Code IFT 遗忘随训练时长显著恶化：LoRA r=256 从 epoch 2 的 0.659 降到 epoch 8 的 0.552；而 HumanEval 在 epoch 4 达峰 0.498 后回落到 0.437（epoch 8）（Table S5/S6, p.28）。
- 正则化对比：weight decay（5e-5, 1e-4）和 attention dropout（0.05, 0.1）学得和忘得都和全参差不多；LoRA r=256 学得同样多但忘得更少（p.9, Fig.4）。
- 谱：Wq（第 26 层）微调后、基座、Δ 三者谱都缓慢衰减，解释 90% 方差需约 2000/4096 个奇异向量（p.10）；Fig.S7 caption 说三者都需 rank>1500（p.30）。最早 0.25B token checkpoint 的 Δ 秩已是典型 LoRA 秩的 10–100 倍；Δ 秩随数据增长；MLP 秩高于 attention；首末层秩低于中间层（p.10–11, Fig.6）。
- α：r=256 Magicoder 4 epoch 上 α=512 在所有学习率下均好于 256 或 32（p.11）。
- 吞吐：LoRA 约降低 15% 吞吐；小 batch 时峰值显存约降 40%（p.38）。

## 消融（隔离信号）
- **rank**：rank 是 learning–forgetting 权衡的“旋钮”，提高 rank 学得多也忘得多（p.6–7, Fig.3）。
- **目标模块**：只训 Attention 劣于 MLP 和 All，All 的增益主要由 MLP 驱动（p.11–12, Fig.7）→ MLP 是 LoRA 持续学习的主要位置（作者用“potential evidence”措辞）。
- **训练时长**：遗忘随时长恶化，且目标性能常在中途达峰（Table S5–S8）。
- **领域偏移**：代码遗忘多于数学；OpenWebMath（英文句子多）遗忘最少（p.6）；数学 IFT 低秩够用被归因于领域偏移小（p.6）。
- 缺失：没有对 LoRA 产物做任何 post-hoc 截断/缩放实验，也没有把谱指标与遗忘做相关性分析——谱分析仅用于解释“为什么 LoRA 学得少”，只做了 code CPT（p.13 自认）。

## 作者声明的局限
- 谱分析：全参找到高秩解并不排除低秩解存在；重建权重所需秩可能高于下游任务所需秩；只对 CPT 做了 SVD，IFT 下全参的 Δ 可能没那么高秩（p.13）。
- 模型规模效应未研究（只 Llama-2-7B）（p.13）。
- 没比较 LoRA 变体（p.12）；未研究训练 embedding 层的混合方案（p.21）。
- HumanEval 字符串级多样性不敏感（p.9）；MT-bench 只有 80 题、方差高（p.24）。

## 批判
- 【推断】遗忘指标只是 HellaSwag/WinoGrande/ARC-C 三个基于 logits 的多选题平均，不覆盖指令遵循（IFEval 类）与生成格式；在 base 模型（非 instruct）上测，和我们“instruct 模型 + IFEval 保持”的场景差距大。
- 【推断】“90% 方差秩”是全局能量指标，2410.21228 已说明有效秩类指标不足以解释遗忘差异；因此本文谱分析对“该截断到多少秩”几乎没有直接指导意义——它说明的是全参 Δ 不低秩，不是 LoRA Δ 中哪些方向有害。
- 【推断】单种子、单模型；Pareto 结论数据集依赖强（作者自承代码 LoRA 占优、数学全参占优，p.7）。
- 正面：Table S1–S8 提供了非常干净的“训练时长 × rank”网格，足以说明中期 checkpoint 往往同时有更高目标分和更少遗忘（Code IFT），这是对“与中期 checkpoint 插值”算子有用的经验证据。

## 对我们项目的启示
- **训练时长/中期 checkpoint 是强信号**：Code IFT 中 LoRA r=256 在 epoch 4 目标分最高（0.498），之后目标和保持同时下降（Table S5/S6）。→ agent 应能访问中期 checkpoint，并使用“interpolate with mid-training checkpoints / 选早停点”这类算子；evaluator 的目标 dev 能直接定位这个拐点。
- **秩旋钮 = 权衡旋钮**：rank 越高学得越多、忘得越多（p.6–7）。post-hoc `truncate_rank` 理论上能沿这条曲线往回走，但本文**没有**验证 post-hoc 截断等价于低秩训练——需要我们自己实验。
- **模块类型信号**：MLP 承载大部分增益（p.12）；对“drop module / per-module scale”算子，先验应是 MLP adapter 对目标增益更关键，attention adapter 可能是更便宜的裁剪对象（【推断】，本文未测遗忘的模块分解）。
- **领域偏移大小预测遗忘量**：代码 > 数学（p.6）。对我们 math vs code pilot，预期 code 的 retention 压力更大，λ 权衡需按任务调。
- **不建议给 agent 的信号**：全局“90% 方差秩”/有效秩——便宜但与遗忘的关联本文未验证，2410.21228 认为其不足；可能误导。
