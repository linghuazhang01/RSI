# O-LoRA：Orthogonal Subspace Learning for Language Model Continual Learning（2310.14152）

## 元信息
- 标题：Orthogonal Subspace Learning for Language Model Continual Learning
- 作者：Xiao Wang, Tianze Chen, Qiming Ge, Han Xia, Rong Bao, Rui Zheng, Qi Zhang, Tao Gui, Xuanjing Huang（复旦大学）
- 版本：arXiv:2310.14152v1，2023-10-22（p1）；代码 github.com/cmnfriend/O-LoRA（p2 脚注）
- 阅读范围：全文 p1–p14（正文、Limitations、附录 A.1–A.5、Table 6–9）。文本提取正常，个别表格列对齐错位但可读。

## 研究问题
语言模型按任务序列持续学习时如何减少灾难性遗忘，同时满足：不存旧数据（rehearsal-free）、参数开销小、推理时不需要 task id、保留对未见任务（MMLU）的泛化（p1–p2, Table 1 p4）。

## 做了什么 edit/merge 决策（训练时，不是 post-hoc）
- **训练时**方法。每个新任务 t 新开一组 LoRA {A_t, B_t}，冻结此前所有任务的 LoRA {A_i, B_i | i<t}，并在训练损失中加入"新 LoRA 子空间与旧 LoRA 子空间正交"的正则（p4, Eq.7）。
- 只在 W_q、W_v 上挂 LoRA（p4）。
- 为避免显存膨胀，可以把旧 LoRA 的 A_iB_i 合并回 W_init（Eq.9, p4）——这是唯一的"合并"操作，是无条件的求和，没有任何选择性决策。
- 推理时所有 LoRA 叠加使用，不需要 task id（p2）。

## 驱动决策的信息
- **信号：旧/新 LoRA 列空间的重叠**。记 W_init + AB，A∈R^{d×r}、B∈R^{r×k}；作者把 A_t 的列张成的子空间 U_t 视为第 t 个任务"梯度子空间"的近似（Eq.3–4, p4）。
- **重叠度量**：O_{i,t} = A_iᵀ A_t（r×r 矩阵，Eq.6），正交损失 L_orth(A_i, A_t) = Σ_{j,k} ‖O_{i,t}[j,k]‖²（Eq.8, p4），即 A_iᵀA_t 的 Frobenius 范数平方。**没有对 A 做归一化或正交化**，所以该量同时受列向量范数和夹角影响【推断：模型可通过缩小 A_t 的范数来降低该损失，论文没有讨论这一点】。
- 总目标：Σ log p(y|x) + λ1 Σ_{i<t} L_orth(A_i, A_t)（Eq.7, p4）。
- 只约束 A（输出侧/列空间），不约束 B；也没有用旧任务的梯度、Fisher 或激活。
- **数据需求**：不需要旧任务数据；只需要当前任务的标注训练数据以及旧 LoRA 的 A_i 权重。
- **代价**：每步多算 (t−1) 个 r×r 的 A_iᵀA_t，相对前向/反向可忽略；作者称"不产生额外训练开销"（p5）。不需要 SVD。

## 决策方式
- 端到端学习（正则化梯度下降），没有闭式求解，也没有搜索。
- **在什么数据上调了哪些超参**：λ1（正交损失权重）以及附录才出现的 λ2，按任务序列、甚至按单个任务分别设置：Order 1–3 全部 λ1=0.5、λ2=0；Order 4–6 的 λ1 在 0.02/0.5/5 之间、λ2 在 0–0.5 之间逐任务变化（A.1, p12）。正文没有定义 λ2【推断：可能是对新 LoRA 的另一项正则，原文未说明】。论文没有说明这些值依据哪个验证集、以什么指标选出；Large-number-of-tasks 基准每类保留 500 个样本作验证（p5）【推断：很可能用这部分数据调参，但未明说】。
- LoRA rank 用 Table 5 做了扫描（T5-base，r=2/4/8/16，p8）。

## 关键结果（目标增益与遗忘）
指标只有 Average Accuracy：最后一个任务训练完后在所有任务上的平均准确率（p5）。**没有报告逐任务遗忘（BWT），也没有单独报告新任务增益。**
- Table 2（T5-large，p6）：标准 CL 基准平均 AA：O-LoRA 75.8，IncLoRA 66.4，SeqLoRA 43.7，LFPT5 72.7，MTL 上界 80.0；15 任务长序列平均：O-LoRA 69.6，IncLoRA 61.2，LFPT5 69.2，ProgPrompt 77.9，PerTaskFT 78.1。
- Table 3（LLaMA-7B，先 Alpaca 指令微调，再在 CL Order 1 上持续学习，p7）：MMLU zero-shot：LLaMA-7B 34.4、Alpaca-LoRA 37.5、Alpaca-LoRA-CL 23.3、Alpaca-inc-LoRA-CL 28.6、Alpaca-OLoRA-CL 33.6；CL 准确率：46.7 / 33.1 / 76.8。
  - 留意：即使用了 O-LoRA，MMLU 仍比 Alpaca-LoRA 起点低 3.9 点（37.5→33.6），也低于原始 LLaMA-7B 的 34.4，说明通用能力的遗忘只是减轻，没有消除。
- Table 4（p8）：不同规模的平均 AA：T5-base 74.7、T5-large 75.8、T5-XL 78.6、LLaMA-7B 76.1。
- Table 9（p14）：MMLU 分学科结果，O-LoRA 在 math 上 21.6，低于 inc-LoRA 的 23.4 和 LLaMA 的 27。

## 消融（逐个隔离信号）
- **有无正交项**：IncLoRA 等价于 λ1=0（每任务新开 LoRA，冻结旧 LoRA，不加正则）。T5-large 标准 CL 66.4→75.8，长序列 61.2→69.6（Table 2, p6）；LLaMA 上 MMLU 28.6→33.6、CL 33.1→76.8（Table 3, p7）。这是最干净的一组消融，说明在"冻结旧 LoRA + 新开 LoRA"的基础上，正交约束本身带来了主要收益。
- Fig.3（p7）：λ1=0.5 与 λ1=0 相比，学新任务后旧样本预测损失的变化分布更集中在小值（只给直方图，没有数值）。
- Fig.4（p8，T5-base）：加正交约束后各层隐藏状态的变化更小；作者观察到高层变化大、低层变化小（定性）。
- Rank（Table 5, p8）：r=2/4/8/16 的平均 AA 为 73.0/73.3/73.1/74.2，差别很小。
- **缺失的消融**：没有比较其他重叠度量（如归一化余弦、主角度、约束 B 或约束 BA 乘积）；没有在固定 λ1 下单独比较"冻结旧 LoRA"与"正交化"各自的作用；没有扫描 λ1 的敏感性曲线。

## 作者声明的局限（p9）
- 在上百个任务的复杂场景中的表现尚未验证。
- 训练时仍需要 task identity，才能为每个任务分配不同的 LoRA；任务无关（task-agnostic）的训练留作未来工作。

## 批判
- 【推断】O_{i,t}=A_iᵀA_t 没有归一化，正交损失可以通过缩小 ‖A_t‖ 来降低（把尺度推给 B），因此它并不严格度量子空间夹角；论文没有报告训练后的主角度。
- 【推断】只约束 A 的列空间（输出方向），而遗忘通常与输入方向上旧任务激活所在子空间有关；用"旧 LoRA 列空间"代理"旧任务梯度子空间"是一个假设（p4 称为 hypothesize），文中没有直接验证（例如与真实梯度子空间对比）。
- 【推断】实验任务是分类/短答案（AG News、Yelp 等），每个任务的 LoRA 很可能确实低秩且彼此可分；对数学、代码这类与通用能力高度共享子空间的任务，正交约束可能直接损害目标增益——论文没有报告目标任务的单独准确率，这一代价不可见。
- 【推断】λ1/λ2 逐任务调节（p12），而选择依据没有披露，实际调参成本和泛化性存疑。
- 通用能力的保留只在 MMLU 一项上测量，没有指令遵循（IFEval）一类指标。

## 对我们项目的启示
- **可以给 agent 的信号**：新 adapter 与历史 adapter 的列空间重叠，即 ‖A_histᵀ A_new‖_F²（建议改用归一化版本，如主角度余弦或 ‖Q_histᵀ Q_new‖_F²，其中 Q 由 QR 分解得到）。计算极便宜（r×r），不需要数据。
- **预测力**：论文只证明"训练时强制低重叠"能减少对**旧 LoRA 任务**的遗忘；没有证明重叠度能预测对**预训练通用能力**（IFEval/MMLU）的遗忘，而后者是我们 retention 指标的主体。我们的场景里只有一个新 LoRA 和若干历史 adapter，"旧任务"更多是 base 模型的通用能力，而 base 没有 LoRA 子空间可供正交。【推断】需要换一个参考子空间（例如 base 权重的主奇异子空间，或通用数据上的激活子空间）。
- **post-hoc 等价操作**：我们算子库里的 orthogonalize / project_out 正是 O-LoRA 的 post-hoc 版本，即把 A_new 投影到历史 A 的正交补上。论文**没有**做过 post-hoc 投影实验，所以没有证据表明事后投影能保住目标增益；投影会删掉与旧任务共享的有用方向，可能损失目标增益。建议把它作为候选算子，但由外部 evaluator 判断，不要硬编码。
- **可能误导的地方**：重叠度低不等于不遗忘（仍有 3.9 点 MMLU 下降，Table 3），重叠度也会被尺度操纵。
- **headroom**：训练时正交的效果为 AA +9.4（IncLoRA→O-LoRA，T5-large）。post-hoc 版本的潜在收益未知，需要我们自己测。
