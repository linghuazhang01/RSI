- 作者：Xisen Jin, Xiang Ren（USC）, Daniel Preoțiuc-Pietro, Pengxiang Cheng（Bloomberg）
- 发表：ICLR 2023；文本为 arXiv:2212.09849v6（2025-05-21）(p.1)
- 阅读范围：全文 p.1–19（正文 p.1–9，参考文献 p.10–13，附录 A 推导 p.14，附录 B 数据/训练 p.15–16，附录 C 敏感性 p.16–17，附录 D 置换匹配 p.17–19）。文本抽取基本正常；Figure 3/4/5/6 只有坐标轴残片，曲线数值不可读（只能用正文描述）。

## 研究问题
多个从同一预训练 LM 出发、在不同私有数据（non-i.i.d. 分区 / 不同领域 / 不同任务）上微调的模型，在**拿不到训练数据**时，如何在参数空间合并成一个模型，使其在各个域内表现好、且有更好的 OOD 泛化（p.1–2）。合并函数应高效、闭式（p.2）。

## 做了什么 edit/merge 决策
- 对 Transformer 中**每个 linear 层独立**求一个合并后的权重矩阵 W_M（逐层闭式解）；embedding、bias 等其他参数用简单平均（p.4, Algorithm 1）。
- 附带：在已知 OOD 验证表现时，贪心挑选要合并的模型子集（Incremental merging，p.8, Fig.6）——这是一个"选哪些模型参与合并"的决策，用的是带标签的 OOD 验证集。

## 驱动决策的信息
- **信号**：每个模型 i、每个 linear 层 j 的输入激活 Gram 矩阵（论文称 inner product matrix）G_i^(j) = X_i^(j)ᵀ X_i^(j)，X 是该层的输入特征（p.4）。
- **公式**：线性回归视角，最小化合并模型与各个体模型在各自训练输入上的输出 ℓ2 差（Eq.1, p.3），闭式解
  W_M = (Σ_i X_iᵀX_i)⁻¹ Σ_i (X_iᵀX_i W_i)（Eq.2, p.3）。
- **正则化（α）**：直接用 Eq.2 在某些架构上得到退化模型，因此把 Gram 矩阵非对角元乘 α：G̃ = αG + (1−α)diag(G)（Algorithm 1, p.4）。附录 A 证明这等价于加正则项 tr[(W−W_i)ᵀΛ_i(W−W_i)]，Λ_i = γ·diag(X_iᵀX_i)，α = 1/(1+γ)（p.14）。
- **解释**：对角元主要对行做重加权（神经元重要性），非对角元做行间线性组合；若 Gram 为对角阵，退化为按神经元重要性重加权；若所有模型 Gram 相同，退化为简单平均（p.4）。
- **所需数据**：每个模型自己训练分布上的**无标签输入**（只需前向得到各层输入）。不需要标签。合并时只用 Gram 矩阵，不用原始数据（p.4）。对线上无统计量的模型，需要少量训练样本来计算（p.8–9）。
- **成本**：所有 linear 层的 Gram 矩阵可在**一次前向**中得到（用 PyTorch forward hook，p.16）；比 Fisher 便宜，因为 Fisher 需要额外反向（p.4）。合并时每层需对 d_j×d_j 矩阵求逆（文中未单独报时间）。主实验用至多 1,000 个 batch（batch size 16）（p.6, p.16）。
- **内存**：Σ_j d_j²（d_j 为每个 linear 层输入维度）；作者称对 Transformer 而言与参数量、与 Fisher 量级相当（p.4）。

## 决策方式
- **闭式解**（逐层矩阵求逆），无需训练、无需迭代（p.3–4）。
- 超参：α 主要设 0.9，T5-base 设 0.1（p.6）。α 的取值是通过敏感性实验（Fig.5，在 in-domain/OOD 测评上）选的，文中没有声明在独立验证集上调；【推断】α 实际上是看评测表现挑的，T5 与其他模型取值差别大，说明需要逐架构调。
- 子集选择（Fig.6）是用**带标签的 OOD 验证集**按个体 OOD 表现排序后贪心加入（p.8）。

## 关键结果
- **Non-i.i.d. 分区（GLUE，RoBERTa-base，Table 1, p.6）**：8 任务平均 Avg f = 71.76，Simple 74.22，Fisher 75.25，RegMean 75.27；RegMean 与 Fisher 相近，略优于 Simple。
- **两两合并（Emotion，Fig.3, p.6–7）**：相比 Simple，RegMean 把相对性能下降从 55% 降到 12%（RoBERTa-base），从 85% 降到 15%（DeBERTa-large）（p.7）。
- **合并全部域模型，in-domain（Table 2, p.7）**：
  - Emotion RoBERTa-base（Same/Diff head）：Simple 21.31/0.00，Fisher 28.27/24.36，RegMean 38.73/32.56，Ensemble 27.21/26.82，Domain-Specific 51.02，MTL 47.75。
  - Emotion DeBERTa-large：Simple 2.96/0.00，Fisher 10.88/20.16，RegMean 38.31/18.83（Diff head 下 Fisher 略好）。
  - NER DeBERTa-large：Simple 55.37，Fisher 51.01，RegMean 85.51，MTL 90.12。
- **OOD（Table 3, p.8）**：Emotion-heldout T5-base RegMean 39.58 > Best f 37.54；NER-CoNLL DeBERTa RegMean 80.43，MTL 80.60。NER 上所有合并方法乃至 MTL 的 OOD 都不如 Best 单模型（p.8）。
- **不同任务合并（GLUE 8 任务，Fig.4, p.7）**：RegMean 明显优于 Simple 和 Fisher（只有图，数值不可读）。

## 消融
1. **Gram（完整）vs 只用对角 vs 无 Gram**：α=0 时 Gram 变对角，RegMean 只重加权行，"类似简单平均"（p.8）；Fig.5a 显示 α 在 0.1–0.9 间基本稳定，α=1.0（不缩放非对角）在 T5-base/DeBERTa 两两合并时突然退化（p.8）。合并多个 T5 模型时 in-domain/OOD 都在 α=0.1 达最高，并随 α 增大缓慢下降，OOD 下降稍大（p.8）。→ 说明：**非对角元（层输入协方差结构）有用但必须被收缩**；完全对角（≈Simple）明显更差（以 Table 2 的 Simple 为参照）。【推断】Fig.5 曲线数值无法从文本读出，"α=0≈Simple"是作者的定性描述。
2. **样本数 N（Table 6, p.16；合并 5 个 RoBERTa-base emotion 模型）**：N（batch 数，每 batch 16）=1: in-domain 37.42 / OOD 20.55；10: 40.09/22.09；100: 40.62/22.64；1,000: 38.73/22.61；5,000: 40.56/22.78。作者结论：性能随 N 提升，约 N=100 饱和（p.16）。注意 N=1（16 条样本）已远好于 Simple 的 21.31（Table 2）——【推断】Gram 信号极便宜、对样本数不敏感。
3. **正则化形式（Table 8, p.16；T5-base Emotion 两两合并平均 in-domain F1）**：对角加常数 β=0.01/0.1/0.2/0.5 → 28.24/33.74/39.13/34.70；相对缩放非对角 α=0.1 → 40.32。相对缩放更好，作者归因于不同层/模型/数据输入尺度差异大（p.16）。
4. **合并哪些模型（Table 7, p.16–17）**：两两合并的 OOD 依赖于所选模型对；合并 OOD 最好的两个个体（TEC+ISEAR）得到最好 OOD（31.21）。
5. **置换匹配（附录 D, p.17–19）**：共享预训练初始化下权重无置换（OT 得到恒等置换）；activation-based 匹配得到非平凡置换，但应用后性能远低于不匹配的简单平均。

## 作者声明的局限
- 需要 Gram 矩阵（Fisher 同理需要 Fisher 信息）；对线上没发布这些统计量的模型，需要少量训练样本计算（p.8–9）。
- Gram 矩阵可能泄露训练数据信息，需要量化隐私泄露（p.9）。
- 只考虑同架构、同预训练初始化（p.3）；未来工作：不同初始化/架构、大规模序列合并（p.9）。
- 预训练模型影响大：T5 简单平均也能成功，DeBERTa-large 难合并（p.8）。

## 批判
- 线性回归推导只对单层成立：逐层独立求解时，层 j 的输入 X^(j) 来自各**个体模型**的前向，而合并后模型的上游层已经变了，输入分布与 Gram 统计不一致——【推断】这是"局部最优、全局不保证"的近似，作者未讨论层间误差累积。
- α 需逐架构选（0.9 vs 0.1），没有在独立验证集上选取的流程描述【推断：存在用测试表现选超参的风险】。
- 实验全为编码器/T5-base 级分类与 NER，规模 ≤ DeBERTa-large；没有生成式 LLM、没有 LoRA 低秩更新【推断：对 LoRA ΔW = BA 的情况，Eq.2 可直接作用于全秩 W 或 ΔW，但合并结果一般不再低秩】。
- 目标是多模型**多域/多任务融合**，而不是"单任务增益 vs 保持旧能力"；不过公式天然可以加入一个"base 模型"作为被合并的一员（用通用数据的 Gram）——作者没这么做。
- "数据无关"有一定误导性：需要每个模型训练分布上的前向激活，只是不需要标签。

## 对我们项目的启示
- **与遗忘的关系（最直接）**：RegMean 的目标函数 = 让合并模型在每个模型自己的输入分布上输出不变。把"旧能力"视作一个成员（base 模型或旧 adapter，Gram 用通用/指令遵循数据激活计算），把"新任务 LoRA"视作另一成员（Gram 用 math/code 数据激活），即得到一个闭式的"在旧分布上保持输出、在新分布上保持新行为"的 adapter 编辑——这正对应我们的 retention vs target 权衡。λ 可以通过给两类 Gram 加权实现【推断】。
- **应预计算的信号**：每层（至少 q/k/v/o/up/down 等 LoRA 目标模块）的输入 Gram 矩阵，分别在 (a) 目标任务数据、(b) retention 代理数据（IFEval 风格指令、通用知识文本）上算。成本：一次前向/每个数据集；Table 6 表明约 100×16 条样本即饱和，16 条已有大部分收益——对 8B/27B 很便宜。内存：Qwen3-8B 的 hidden 4096、MLP 中间维更大（down_proj 输入维度大，Gram 也大）——【推断】可只存 LoRA 目标模块的 Gram，或存其低秩投影（如 Gram 在 LoRA A 子空间的投影 A G Aᵀ，r×r）以大幅降内存。
- **对算子库的映射**：它给出了 "interpolate / task arithmetic" 的数据感知闭式版本；"orthogonalize / project_out against old adapters" 可以改为"在旧分布 Gram 意义下的投影"（即只在旧输入不激活的方向改权重）——这与 Gram 解释（对角=神经元重要性，非对角=方向组合）吻合。
- **注意可能误导之处**：(1) α 必须收缩（α=1 会崩），agent 不应直接用原始 Gram 求逆；(2) 逐层独立近似忽略层间耦合，组合很多层编辑后需要外部评估器复核；(3) 论文证据全是同规模微调模型合并，未验证"一个强 base + 一个小 LoRA"的不对称场景。
