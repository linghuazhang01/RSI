# AlphaLoRA: Assigning LoRA Experts Based on Layer Training Quality — 阅读笔记

## 元信息
- 标题：AlphaLoRA: Assigning LoRA Experts Based on Layer Training Quality
- 作者：Peijun Qing, Chongyang Gao, Yefan Zhou, Xingjian Diao, Yaoqing Yang, Soroush Vosoughi（Dartmouth、Northwestern）
- 版本：arXiv:2410.10054v1（2024-10-14）（p.1）；EMNLP 风格双栏短文，文本本身未写会议名。
- 阅读范围：全文 p.1–13（正文 p.1–9，局限 p.9，参考文献 p.9–11，附录 A–D p.12–13）。双栏文本被横向交错抽取（左右栏同一行混排），但可读；Fig.2–6 数值不可读。

## 重要定位
**AlphaLoRA 是训练前（training-time）的结构分配方法，不是 post-hoc 编辑/合并方法。** 它在 LoRA-MoE 训练**之前**，根据**预训练权重 W0** 的谱统计决定每层放几个 LoRA expert，然后正常训练。本笔记的重点是提取它关于 "HT-SR α 作为层质量信号" 的说法与证据。

## 研究问题
LoRA-MoE 通常每层均匀放置相同数量的 LoRA expert，存在冗余；MoLA 用人工分组（如 2468）分配。能否用 Heavy-Tailed Self-Regularization（HT-SR）理论，**无需训练、无需数据**地按层"训练质量"分配 expert 数（p.1–2）。

## 做了什么 allocation 决策
- 每层 expert 数 s_i（i=1..m），总和固定为 T（如 160）（p.4）。
- 每个 expert 是 rank 8 的普通 LoRA，加在 Wq/Wk/Wv/Wo/Wgate/Wdown/Wup 七个矩阵上，Top-2 路由 + 负载均衡损失（p.5, p.13）。

## 驱动决策的信息
- **信号：PL_Alpha_Hill**（层的谱幂律指数）。
  1. 对层内每个预训练权重矩阵 W_i 计算相关矩阵 X_i = W_iᵀW_i 的特征值，得到 ESD（p.3–4）。
  2. 对 ESD 的重尾部分拟合幂律 p(λ) ∝ λ^(−α)，λ_min<λ<λ_max（Eq.4, p.4）；α 越小越重尾。
  3. 用 Hill 估计：PL_Alpha_Hill = 1 + k / Σ_{i=1}^{k} ln(λ_{n−i+1}/λ_{n−k})（Eq.5, p.4），k 用 Fix-finger 方法选（使 λ_min 位于 ESD 峰值处）（p.4）。
  4. 层内各矩阵的值取平均作为层值（p.4）。
- **解释（作者的假设）**：重尾越明显（α 越小）层越"训练充分"；欠训练层（α 大）捕获的特征少，需要更多 expert（p.4，援引 Zhou et al. 2024 关于给欠训练层更大学习率的结论）。
- **映射**：s_i = round( v_i^β / Σ_j v_j^β × T )（Eq.6, p.4），β 控制分配的离散程度；四舍五入后若总和≠T，按"缩放值与整数值之差"逐一加减修正（Eq.7, p.4）。
- **所需数据**：**无**（只用预训练权重）。不需要任何输入、标签。
- **成本**：每个权重矩阵一次特征分解（或 SVD）；7B 模型 32 层×7 个矩阵。文中**未报告计算时间或内存**。【推断】对 4096×4096 / 4096×11008 级矩阵的 SVD 在 GPU 上是秒到分钟级，远低于训练。

## 决策方式
- **闭式启发式映射**（Eq.6–7），无训练、无搜索——但有两个超参：
  - β：在 {2.0, 2.5, 3.0} 上做"小规模超参扫描"（p.12）；文中**未说明用哪个集合选**（验证集还是测试集）。
  - T（总 expert 数）：为了与 MoLA 公平比较而设定（p.6）；作者在局限中承认最优 T 由实验结果决定（p.9）。
- direct fine-tuning 中还对训练 epoch（10/15/20）做网格搜索（p.12），同样未说明选择集合。

## 关键结果
- **参数量**：可训练参数 105,635,840，占基座的 1.5%（p.6）。
- **Direct fine-tuning（Table 2, p.6；T=160，8888 为 256）**：平均分
  - LLaMA-7B：8888 82.61 / 5555 81.84 / 2468 82.83 / **AlphaLoRA 83.48**
  - LLaMA-2-7B：8888 85.26 / 5555 84.14 / 2468 84.59 / AlphaLoRA 84.97（低于 8888）
  - Mistral-7B：8888 88.28 / 5555 87.65 / 2468 88.32 / **AlphaLoRA 89.16**
  - 相比 5555 提升 1.64 / 0.83 / 1.51；相比 2468 提升 0.65 / 0.38 / 0.84（p.6）。
- **MetaMathQA 指令微调 → 零样本数学（Table 3, p.7）**：平均 LLaMA 55.77 / 55.31 / **56.89**；LLaMA-2 60.17 / 60.76 / **61.84**；Mistral 73.86 / 74.99 / **75.58**（依次 5555 / 2468 / AlphaLoRA）；比 2468 平均高 1.58（p.7）。
- **分配形状**：中间层 α 较小（训练更好）→ 分到更少 expert，高层和低层更多，整体呈松散的 "M" 形；Mistral 低层需要更多 expert（Fig.3, p.6）。
- **不同 T（Table 5, p.13；Mistral 数学）**：T=80 时 AlphaLoRA（GSM8K 69.44，MultiArith 97.66）已不弱于 2468@160（67.20 / 97.00）；作者称 80 expert 的 AlphaLoRA 超过 160 expert 的 MoLA-▽，参数少 50%（p.8）。

## 消融（α 是否真的是好的层质量信号）
1. **PL_Alpha_Hill vs 其它谱指标（Stable_Rank、Alpha_Hat）vs MoLA-▽（Tables 6–8, p.13；LLaMA-2）**：
   - GLUE：MRPC/COLA/RTE — MoLA-▽ 83.48/86.87/86.28；Stable_Rank 84.34/84.56/86.64；Alpha_Hat 84.11/86.86/84.83；AlphaLoRA 84.23/86.67/87.36。
   - QA：S.QA/C.QA/O.QA — MoLA-▽ 92.36/78.95/79.60；AlphaLoRA 92.71/78.37/80.80。
   - 数学：GSM8K/SVAMP/AddSub/MultiArith — MoLA-▽ 50.11/56.40/48.86/87.66；Stable_Rank 48.22/55.20/48.61/88.50；Alpha_Hat 49.81/56.70/46.08/88.50；AlphaLoRA 50.41/57.00/48.60/91.33。
   - 作者结论：PL_Alpha_Hill 在两种设定下都优于其它谱指标（p.7）。但逐项看差距多在 1 点以内，Stable_Rank 在 MRPC 更好、MoLA-▽ 在 COLA 和 C.QA 更好。
2. **α 分配 vs 均匀分配**：vs 5555（同 T）提升 0.83–1.64（Table 2）；vs 8888（多 60% expert）在 LLaMA-2 上反而低 0.29（85.26 vs 84.97）。
3. **β 敏感性**：Fig.6（p.13）只展示不同 β 下的分配形状，**未给出 β 对性能的影响数值**。
4. **缺失的关键消融**【推断】：没有"随机分配 / 反向分配（α 小的层给更多 expert）"对照；没有直接验证 α 与"层对任务的重要性"（如逐层剪除 LoRA 的性能变化）的相关性；无方差/多种子报告。因此"α 预测层重要性"只有通过下游分配结果的**间接**、小幅证据。

## 作者声明的局限
- 不同任务上效果可能有差异，增加不确定性（p.9）。
- 最优总 expert 数 T 由实验结果决定（p.9）。

## 批判
- 证据强度弱：所有提升在 0.4–1.6 点量级，无标准差、无多种子；β 与 epoch 的选择集合未说明【推断：可能在测试集上选】。
- α 计算在**冻结的预训练权重**上，是模型固有属性，与下游任务无关——同一套分配用于所有任务；这与"层对某个任务重要与否"在概念上不同。论文实际上检验的是"按基座层质量分配容量"，不是"按任务需求"。
- "M 形"结论（中间层训练更好）与 MoLA 的"高层需要更多 expert"部分一致；AlphaLoRA 相对 MoLA-▽ 的增益（0.38–0.84）小于相对均匀的增益，说明大部分收益来自"非均匀 + 高层多"这一粗粒度先验【推断】。
- HT-SR 的"α 小 = 训练好"在不同架构上的普适性没有在本文中被检验，引用 Zhou et al. 2024。
- 没有任何遗忘/保持实验。

## 对我们项目的启示
- **它不是 post-hoc 信号来源，但给出了一个"零数据、廉价"的逐层先验**：对 base 模型（Qwen3-8B/27B）每个模块的 W0 做一次 SVD 得到 PL_Alpha_Hill，可作为 agent 的静态层级特征（与任务无关、可预计算一次、可复用）。
- **与我们的算子映射**：AlphaLoRA 的逻辑是"欠训练层（α 大）更需要/更能吸收新容量"。【推断】对遗忘问题，可以反过来假设："训练充分的层（α 小）承载更多已学知识，对其的 LoRA 改动更可能造成遗忘"——这提示一个可测试的策略：对 α 小的层做更强的 scale-down / truncate_rank / project_out。但本文**没有任何证据**支持该遗忘方向的推论，必须在我们的 retention 评估上验证。
- **更直接的变体**【推断】：把 HT-SR 指标算在**训练后 LoRA 的 ΔW=BA** 或 W0+ΔW 上，观察 α 的变化（ΔW 是否让层的谱变得"过重尾/过拟合"）——相关工作（如 AlphaPruning, Lu et al. 2024，p.10 参考文献）用 α 做逐层剪枝比例分配，比 MoE 分配更接近我们的 prune / truncate 算子。
- **风险**：(1) 信号与任务无关，无法区分"对数学重要"与"对指令遵循重要"的层；(2) 证据增益很小且缺随机/反向对照，不应作为主信号，只适合作为 agent 程序里的低成本特征或先验，最终由外部评估器裁决；(3) 对 LoRA ΔW（rank 很低，只有 r 个非零奇异值）直接拟合幂律在统计上不可靠【推断】。
