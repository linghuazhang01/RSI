## 研究问题
从理论上解释 LoRA 的两个经验性质：(1) 抗灾难性遗忘；(2) 独立训练的 adapter 可以合并。并据此给出一个有理论依据的、免训练的合并系数规则。

## 做了什么 edit / merge / 诊断决策
- **理论**：多分类线性分类 + LoRA（W_pre + BA）+ ℓ2 正则 λ，在“近正交任务几何”假设下刻画全局最优 adapter（Thm 3.1, p.5–6）：高正则时 adapter=0；中间正则时 adapter 的前 K̄ 行对齐微调数据的硬间隔 SVM 解；低正则时方向无简单闭式。
- **遗忘/适应的间隔刻画**（Thm 3.2, p.7）：Forget(λ)=γ_pre·(1 − ρ_pre/√(Θ_λ²+ρ_pre²))，Adapt(λ)=γ_ft·Θ_λ/√(Θ_λ²+ρ_pre²)，其中 Θ_λ=‖B*A*‖_F，ρ_pre=‖W_pre‖_F。即遗忘完全由 **adapter 范数与预训练权重范数之比** 控制。Cor 3.1：并集间隔在平衡点处最大，值为 (1/γ_ft*² + 1/γ_pre²)^(−1/2)（p.7）。
- **合并**（Thm 3.3, p.8）：W(α)=W_pre+Σα_i B_i A_i；最优 α_i = C(W_pre; D_pre) / C(B_i A_i; D_i)（未归一化间隔之比）。
- **MaLoRA（Algorithm 1, p.8）**：
  1. 在预训练域验证集上算 W_pre 的平均间隔 C̄_pre；
  2. 对每个任务 i，在其验证集上算 W_pre + B_iA_i 的平均间隔 C̄_i；β_i = C̄_pre / C̄_i（若 C̄_i ≤ 0 则 β_i=0，丢弃该任务）；
  3. 在验证集上网格搜索全局缩放 s*，返回 W_pre + s*·Σβ_i B_iA_i。

## 驱动决策的信息
- **信号：平均 logit 间隔** C̄(W; D) = 平均每个样本的（正确类 logit − 最大错误类 logit）。理论用最小间隔 C；实践中因数据不可分、最小间隔可能为负且对难样本敏感，改用平均间隔作代理（p.8）。
- 数据需求：**有标签验证集**——预训练域的验证集 D_pre^val + 每个任务的验证集 D_i^val（p.8, Algorithm 1）。实验中每域按分层抽 10% 做验证集（p.52）。
- 成本：每个域验证集一次前向；作者报告 margin 计算成本为单次验证 pass 的 1.05–1.48 倍，且与候选 scale 数无关（p.54）。加上 s 的网格搜索（每个候选一次验证评估）。端到端 972.6 s vs TA 950.3 s，开销约 2.35%（p.10, Table 10 p.54）。
- 理论上隐含的第二个信号：**‖ΔW‖_F / ‖W_pre‖_F（范数比）** 决定遗忘程度（Thm 3.2）——零数据，可直接从权重算。

## 决策方式
- 每任务相对权重：**闭式规则**（间隔之比）。
- 全局缩放 s：**验证集网格搜索**（沿用 Task Arithmetic 的做法，p.9）。
- 正则 λ：理论给出最优点；实验中与 50 点对数网格搜索对比（p.49）。

## 关键结果（含页码）
- **合并基准**（Table 1 p.10；Table 5/6 p.52，10 个种子）：平均归一化精度 Soup 92.94、TA 93.15、TIES 92.96、DARE-TIES 93.05、DARE-Linear 92.87、MaLoRA 93.32（±0.55）；相对精度下降 MaLoRA 6.68 最小，TA 6.85。所有方法区间 92.87–93.32（p.9–10）。
- 分基准：Terra Incognita 上 MaLoRA 65.75±2.31（TA 64.46±2.65）；PACS 上 MaLoRA 96.69 低于 TA/TIES 的 97.52 和 DARE-TIES 97.57（Table 5, p.52）。
- **线性探测（CIFAR-100）**：理论预测的 (α1, α2) 与 50×50 网格搜索的经验最优“接近”（Fig.1, Fig.5；只有图，无数字，p.9, p.51）。
- **正则化最优点**（Table 4 p.51）：ViT、ResNet 理论最优 λ 在经验最优 1.8 倍以内；ConvNeXt 在 K̄∈{10,20} 时在 1.2 倍以内；CLIP 经验最优比预测大 1.8–4.4 倍（p.49）。例：ResNet-50 K̄=20 经验 0.002184 vs 理论 0.002121；ConvNeXt K̄=5 经验 0.000647 vs 理论 0.006709（约 10 倍差，作者 1.2 倍的说法只覆盖 K̄=10,20）。
- 近正交性经验支持：CIFAR-100 特征类间余弦均值约 −0.002，类内 0.23–0.27（Table 3, p.49）；多域基准跨域相关 −0.060 到 0.060，但 PACS 同类同域 0.376、Terra 0.312 偏离较大（Table 9, p.54）。

## 消融（隔离信号）
- **没有真正隔离“间隔加权”贡献的消融**。关键缺失：MaLoRA = 间隔比 β_i + 全局 s 搜索；与之最可比的是 TA（统一 α + 同样的 λ 搜索）。两者差距 93.32 vs 93.15，而每个方法的标准差约 0.53–0.58（Table 5, p.52）——差距在噪声内。【推断】这说明在这些基准上，相对权重几乎不重要，真正起作用的是全局 scale 的验证集搜索。
- 正则化 λ 扫描（Fig.4, Table 4）验证“适中 λ 最优”的非单调关系，可视为对 Thm 3.2 的检验，但不是对合并信号的消融。
- LoRA 层位置：仅在最后四层的 q/v 上加 LoRA，说是“初步层扫描消融”选出的最佳放置（p.52），未报告数字。
- 没有比较 β_i 用最小间隔 vs 平均间隔、或用 loss/精度代替间隔的版本。

## 作者声明的局限
1. 依赖简化假设：近正交任务结构、微调数据类别平衡（p.10）。
2. 理论是线性分类；非线性模型上的实验只是经验支持（p.10）。
3. 理论刻画的是训练集上的间隔，没有泛化/测试风险保证（p.10）。
4. 合并实验目的不是 SOTA（p.9–10）。
5. 微调任务的类别必须是预训练类别的子集（p.3）。

## 批判
- 【推断】场景与我们差距很大：分类（有 logit 间隔可定义）、ViT-B/16 与 XLM-RoBERTa Base、LoRA 只加在最后四层 q/v、每个 adapter 还带自己的分类头且合并时头也加权求和（p.53）。生成式 LLM 的“间隔”需要重新定义（如 per-token 正确 token logit − 最大其他 logit），作者没有讨论。
- 【推断】“遗忘”在本文里是**同标签空间**下预训练数据的间隔下降，且微调类别是预训练类别的子集；与我们“数学/代码训练损害 IFEval 和常识”的遗忘不是同一种。
- 【推断】Thm 3.2 中遗忘完全由 Θ_λ/ρ_pre 决定，是近正交假设（Wpre x̄ = 0 且 BA x = 0）的直接后果；真实 LLM 中目标数据与保留数据高度不正交（共享语言、格式），该结论最多是定性启发。
- 【推断】Table 1 的提升在 10 种子标准差内，结论“matches or outperforms”是准确的，“outperforms”部分缺统计检验。
- 正面：给出了一个**几乎免费的、可解释的相对权重规则**，且与 TA/TIES/DARE 计算开销相当（p.54）。

## 对我们项目的启示
- **信号 1（零数据）：adapter 范数比 ‖ΔW‖_F / ‖W_0‖_F（逐层/逐模块）**——理论上它直接控制遗忘与适应的权衡（Thm 3.2）。便宜，可让 agent 用来决定 per-layer scale 的初值或排序；但在非正交的真实 LLM 中是否预测遗忘需我们自己验证（本文没在 LLM 上测）。与 2410.21228 的对齐度信号可以互补：范数大小 vs 方向是否“入侵”。
- **信号 2（需少量有标签数据）：验证集上的平均 logit 间隔**，对当前 adapter 与历史 adapter 都计算，用比值定插值/合并的相对权重。成本仅一次前向；对“interpolate with history adapters / task arithmetic”算子是一个合理的、有理论依据的默认权重。【推断】生成任务中可用答案 token 的平均 logit 差作代理。
- **信号 3：全局 scale 的验证集搜索**——本文实际证据表明它比相对权重更重要（MaLoRA≈TA）。这与我们 evaluator 驱动的搜索天然一致：agent 可以先固定方向（由间隔比或均匀），再让 evaluator 扫全局 scale。
- **可能误导**：把“adapter 范数小 ⇒ 遗忘少”当作硬规则——在非正交场景下方向（是否与保留任务子空间重叠）可能比范数更关键；本文的近正交假设恰好抹掉了方向的作用。
- 对“正交化 / project_out”算子：本文的理论正是在“任务正交”下合并无干扰，提示 `orthogonalize against old adapters` 有理论动机，但本文没有实验检验主动正交化。
