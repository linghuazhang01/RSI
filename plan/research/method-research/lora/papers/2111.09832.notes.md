# Merging Models with Fisher-Weighted Averaging — 阅读笔记

## 元信息
- 标题：Merging Models with Fisher-Weighted Averaging（Fisher merging）
- 作者：Michael Matena, Colin Raffel（UNC Chapel Hill）
- 版本：arXiv:2111.09832v2（2022-08-26），页脚标 "Preprint. Under review."（p.1）【该论文后发表于 NeurIPS 2022，但文本本身未写明】
- 阅读范围：全文 p.1–16（正文 p.1–9，参考文献 p.10–13，附录 A–F p.14–16，含 Table A1–A4）。文本抽取基本正常；Fig.2–7 只剩坐标轴，具体柱/曲线数值不可读；表格下标（标准差）被抽成紧贴数字的形式，如 "73.25.1" 表示 73.2±5.1。

## 研究问题
把"合并"看作近似最大化多个模型参数后验的联合似然：简单平均 = 用各向同性高斯近似后验（isotropic merging）。能否用更好的后验近似（Laplace 近似，精度矩阵 = Fisher 信息）得到更好的合并，并把合并用作梯度式迁移学习（中间任务训练、DAPT）的廉价替代（p.1–3）。

## 做了什么 edit/merge 决策
- **逐参数**加权平均：每个标量参数的合并值是各模型该参数值按 (λ_i × 该参数 Fisher) 加权的平均（Eq.4, p.4）。
- **模型级系数 λ_i**（λ_i ≥ 0，Σλ_i = 1）决定每个模型的整体重要性（p.3）。
- 场景：(1) 同任务多 checkpoint 的 ensembling（p.5）；(2) WiSE-FT 鲁棒微调——预训练模型与微调模型插值（p.5–6）；(3) 目标模型 + donor 模型的中间任务迁移（p.6–8）；(4) 微调模型 + DAPT 模型（p.8）。
- 不可合并参数（任务专属 head）保持不变，只合并共享 body（p.5）。

## 驱动决策的信息
- **信号**：每个模型的**对角 Fisher 信息** F̂_θ = (1/N) Σ_i E_{y∼p_θ(y|x_i)} (∇_θ log p_θ(y|x_i))²（Eq.2, p.4）。注意 y 从**模型自身预测分布**采样/求期望（"经验 Fisher"之外的真 Fisher），x_i 取自该模型的训练集。
- **合并公式**：θ*^(j) = Σ_i λ_i F_i^(j) θ_i^(j) / Σ_i λ_i F_i^(j)（Eq.4, p.4）。
- **理论意义**：Fisher 在众数处等于 Hessian；且 E_x[KL(p_θ‖p_{θ+δ})] ≈ ½ δᵀF δ，所以 Fisher 衡量"改动参数对输出的影响"（p.4）。全 Fisher 需 O(|θ|²) 内存，所以用对角近似（p.4）。
- **数值处理**：若某参数在所有模型上 Fisher 都接近 0，则默认取"目标模型"的值；作者称这个默认选择影响很小（p.4）。
- **所需数据**：每个模型训练分布的**输入**；**不需要标签**（y 从模型预测采样或分类数少时精确求和，p.4）。中间任务实验用至多 4096 条训练样本（p.7）；DAPT checkpoint 用 131,072 条、每条从 logits 采 1 个样本（p.15）。
- **成本**：需要 N 个**逐样本梯度**（每样本一次前向+反向），作者称大致等于在 N 个样本上训练的成本（p.4）。FLOPs 估算（BERT-base, RTE）：微调 10 epoch ≈ 5.5e14；合并公式 ≈ 4.0e8；在验证集评估 ≈ 2.0e12；估计 Fisher ≈ 9.1e13；总体 Fisher merging 比微调便宜约 6×，isotropic 约 275×（p.8）。Fisher 只需算一次可复用（p.8）。
- **内存**：对角 Fisher 与参数量同大小（p.4）。

## 决策方式
- 合并本身是**闭式**（Eq.4）。
- **λ 是在带标签验证集上网格搜索的**：中间任务实验 50 点网格，用前 2048 个验证样本的分数选（p.7）；DAPT 实验 75 点网格，用**前 2048 个测试样本**的 F1 选（p.15）——【推断】后者是在测试集上选超参，存在乐观偏差。Ensembling 则固定 λ_i = 1/5（p.5）；WiSE-FT 扫 λ_1 从 0 到 1、步长 0.1，画出整条 IID-OOD 曲线（p.6）。
- 因此在迁移场景里，**真正决定效果的标量 λ 是由有标签验证集搜索得到的**，Fisher 只决定逐参数的相对权重。

## 关键结果
- **Ensembling（Fig.2, p.5–6）**：BERT-base 在 RTE/MRPC/SST-2 各 5 个 HF checkpoint；Fisher merging 在所有情况下显著优于 isotropic，并与输出集成相当，推理便宜 5×（具体柱值不可读）。
- **WiSE-FT 鲁棒微调（Fig.3, p.6）**：ViT-B/16，5 个 OOD 集；Fisher 给出更好的 IID–OOD 权衡；在使平均 OOD 最好的 λ_1 处，Fisher 的 IID（ImageNet）准确率比 isotropic 高约 1%（p.6）。
- **中间任务（RTE 目标，BERT-base，Fig.4 & Table A1/A2, p.7, p.16）**：未合并 RTE 63.7±1.7；MNLI donor 下 Fisher 73.2±5.1 vs isotropic 72.2±4.0；QNLI donor：Fisher 66.5 vs isotropic 66.8；SQuAD donor Fisher 66.6。梯度式中间任务训练 MNLI→RTE 为 77.4±1.6（Table A3），即 MNLI donor 时合并不如梯度训练（p.7）。作者称合并总是有帮助，而梯度式中间任务训练在某些 donor 上有害（p.7）。
- **RoBERTa-large（Fig.6, p.8）**：在 MNLI→RTE 模型上再 Fisher 合并，最大增益 2.2 点，来自与另一个 RTE checkpoint 合并（p.8）；顺序梯度式多中间任务训练明显变差，作者归因于灾难性遗忘（p.8）。
- **DAPT（Table 1, p.9）**：ChemProt / ACL-ARC / SciERC — Unmerged 82.7/70.5/81.0；Fisher 83.1/73.2/81.3；Isotropic 82.8/72.5/81.7；Fine-tuned（从 DAPT 微调）82.5/71.5/81.6。SciERC 上 isotropic 反而略高于 Fisher。

## 消融
1. **Fisher vs isotropic（Fisher 信号是否有用）**：
   - Ensembling：Fisher 全面显著更好（Fig.2, p.5）。
   - WiSE-FT：Fisher 权衡曲线更好（Fig.3, p.6）。
   - 中间任务（Table A1 vs A2）：差距大多很小，MNLI donor 处最大（73.2 vs 72.2），个别 donor（QNLI、SST-2 等）isotropic 持平或略高；标准差（MNLI 时 ±5.1 / ±4.0）比差距还大【推断：中间任务场景下 Fisher 的优势统计上不显著】。
   - DAPT：混合，SciERC 上 isotropic 更好（Table 1, p.9）。
2. **Fisher 样本数（Table A4, p.16；MNLI donor→RTE）**：行为 MNLI Fisher 样本数，列为 RTE Fisher 样本数。256/256 → 72.7；全量（392702 / 2490）→ 73.4；最高格 32768/2490 → 73.5；isotropic（0 样本）72.2，原 RTE 63.7。作者结论：只用 256 样本仅轻微下降（72.7）且仍优于 isotropic（p.8）。→ Fisher 带来的总增益（vs isotropic）约 0.5–1.3 点，而**合并本身（选对 donor + 调 λ）**带来约 8.5 点（63.7→72.2）。【推断】在该实验中，λ 与 donor 选择比 Fisher 权重重要得多。
3. **数值默认值的选择**：作者称影响小（p.4），无表。
4. 无 "λ 固定 vs 搜索" 的直接消融。

## 作者声明的局限
- Fisher 是局部性质，参数相距较远时可能不准，因此只考虑同初始化（p.4）。
- 对角近似；KFAC 等更好的 Fisher 近似留作未来工作（p.4, p.9）。
- 主要只合并成对模型，更多模型留作未来（p.6）。
- 任务头无法合并，可能导致 head 输入分布偏移（p.5）。
- DAPT 增益比原论文小，归因于只用公开数据、预训练步数少（p.8）。

## 批判
- **λ 选择用了带标签验证集（甚至测试集，p.15）**，而论文叙事重点是 Fisher；【推断】报告的"合并有效"很大程度来自 λ 网格搜索。
- 增益差距常小于标准差（Table A1/A2 的 RTE 列）；未做显著性检验。
- 对角 Fisher 忽略参数间相关；RegMean（2212.09849）在后续实验中显示 Fisher 在多域合并时常差于 Gram 方法，并可能使合并模型接近某个单一模型（RegMean p.7）。
- 中间任务场景本质是"单目标任务增益"，WiSE-FT 场景才是"新任务 vs 原任务保持"的权衡；后者只在视觉 ViT 上做，无 LLM 证据。
- 使用模型自身预测采样 y 计算 Fisher：对生成式 LLM，需对每个 token 采样或用完整词表期望，成本更高【推断】。

## 对我们项目的启示
- **对遗忘最相关的实验是 WiSE-FT（p.5–6）**：预训练模型 + 微调模型插值，Fisher 加权让同一 OOD 水平下 IID 更高约 1%。对应我们"base（retention）+ 新任务 LoRA"的插值算子：可以把 interpolate 改为"Fisher 加权插值"，base 的 Fisher 用 retention 数据（IFEval 类指令、通用知识）计算，LoRA 模型的 Fisher 用目标任务数据计算。也与 EWC 同源（p.8–9），即保护对旧分布输出敏感的参数。
- **应预计算的信号**：对角 Fisher（在 LoRA 参数或 LoRA 目标模块的 ΔW 上），分别在目标 dev 输入、retention 代理输入上。成本：每样本一次前向+反向；Table A4 表明 256 样本即可得到大部分收益——对 8B 可行。可作为 magnitude prune 的替代剪枝分数（按 Fisher×Δθ² 剪），或作为"哪层对 retention 敏感"的层级汇总信号。
- **可能误导之处**：(1) 增益主要来自 λ 的有标签搜索，而非 Fisher；我们的外部评估器本来就承担这个角色，所以 Fisher 的增量价值可能有限。(2) 对角 Fisher 在多模型、跨域合并中弱于 Gram（见 RegMean 对比）。(3) Fisher 是在一个点上估计的，LoRA 训练后 ΔW 与 base 的距离可能使"局部"近似失效【推断】。
- **定位**：中间任务增益（目标任务提升）与 WiSE-FT（保持旧能力）两类证据都有，但前者统计上弱；建议把 Fisher 作为 Gram 之外的二级信号，并在我们的评估器上直接比较 "Fisher 加权插值 vs 标量插值"。
