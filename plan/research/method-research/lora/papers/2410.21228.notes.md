# 2410.21228 笔记：LoRA vs Full Fine-tuning: An Illusion of Equivalence

## 元信息
- 标题：LoRA vs Full Fine-tuning: An Illusion of Equivalence
- 作者：Reece Shuttleworth, Jacob Andreas, Antonio Torralba, Pratyusha Sharma（MIT CSAIL）
- 版本：arXiv:2410.21228v3，2025-10-22；NeurIPS 2025（p.1）
- 阅读范围：全文 p.1–p.29（正文 p.1–9，参考文献 p.10–14，附录 A–O p.15–29）。文本抽取基本正常；图内容（Fig.1–23）只有 caption，曲线数值不可读，下文数字全部来自正文和 Table 1–4。

## 研究问题
LoRA 与全参微调在下游精度相当时，学到的解是否等价？二者在权重谱结构上有何差别？这种差别是否**因果地**导致 LoRA 的遗忘（以及持续学习中的退化）？

## 做了什么 edit / merge / 诊断决策
1. **诊断**：定义并计数“intruder dimensions”（入侵维度）——微调后权重 SVD 的高排名奇异向量中，与所有预训练奇异向量余弦相似度都很低的那些（Def. 3.1, Alg. 1, p.4）。
2. **post-hoc 编辑（因果干预）**：对每个权重矩阵中排名最高的 intruder 奇异分量的奇异值乘以 λ：W = W0 + ΔW + (λ−1)·u_i σ_i v_iᵀ（p.8, Eq. in §5；附录 G p.19–21）。λ=0 即删除，λ=1 不变，λ>1 放大。对照：缩放该 intruder 的“邻居”（一个奇异值相近、与预训练对齐的奇异向量）（p.8, p.20）。
3. **模型选择建议**：作者提出一种“无数据”的模型评估：两个下游表现相当的模型，选 intruder 更少者（p.9）。
4. 持续学习：每个任务后把 LoRA merge 进权重再重新初始化 LoRA，观察 intruder 累积（p.8–9）。注意这一步是训练流程，不是编辑决策。

## 驱动决策的信息
- **信号 1：intruder 计数 / 识别**
  - 公式：对微调后矩阵 W_tuned 做 SVD 得 U_t；对每个 j ≤ k，若 ∀i：cos(U0[i], Ut[j]) < ϵ，则 Ut[j] 是 intruder（Alg. 1, p.4；注意算法只比较**左**奇异向量 U）。模型级数值为所有矩阵求和（p.5）。
  - 超参：k（检查前 k 个奇异向量，主实验 k=10）、ϵ（相似度阈值，Fig.4 扫 ϵ；附录 I 固定 ϵ=0.5 扫 k）（p.5, p.23）。
  - 数据需求：**无**（纯权重）。
  - 成本：每个矩阵 2 次 SVD（W0 与 W_tuned，全尺寸 m×n），外加 k×n 的余弦矩阵；无前向/反向。W0 的 SVD 可缓存。【推断】对 8B 模型约数百个矩阵的满秩 SVD，GPU 上可在分钟级完成，但论文未报告耗时。
- **信号 2：λ 的取值**——由**有标签**的下游测试精度 + 预训练分布上的 loss（LLaMA2：预训练分布随机样本的 LM loss；RoBERTa：pseudo-loss，p.16）共同评估，扫 λ∈{0.1,0.3,0.5,0.7,0.9}（Table 3/4, p.20），附录 G.2 扫 λ∈{0,0.25,0.5,0.75,1.0,1.5,2.0}（p.20）。每个 λ 需一次完整评测（LLaMA2-7B 测试精度+遗忘评测约 45 分钟/单 A100，p.16）。
- 遗忘指标：LLaMA2 用 HellaSwag/WinoGrande/ARC-C 平均（p.6, p.16），缩放实验中则报告预训练 loss（PTL）。

## 决策方式
- intruder 识别：**闭式阈值规则**（ϵ, k 人工设定）。
- 缩放强度 λ：**全局统一 λ 的网格扫描**（所有矩阵同一个 λ，只动每个矩阵的 top-1 intruder），无逐层自适应，无学习、无搜索。作者并未给出自动选 λ 的规则，只是事后报告 λ=0.7/0.9 几乎不掉精度（p.8）。

## 关键结果（含页码）
- 相关性：RoBERTa（MNLI, r=8, 学习率扫描）intruder 数与预训练 pseudo-loss 的 Spearman ρ=0.971，p≪0.001；LLaMA2-7B 跨 epoch ρ=0.59，p=0.0006（p.7, p.18–19）。intruder 数与测试精度无显著相关：RoBERTa ρ=−0.3381（p=0.218），LLaMA2 ρ=−0.3178（p=0.0869）（p.7）。
- 缩放干预（Table 4, p.20，LLaMA2-7B；TA=测试精度相对变化%，PTL=微调引起遗忘的相对减少%）：
  - MetaMath r=256，λ=0.3：TA −0.1，PTL −33.3；λ=0.5：TA +1.8，PTL −25.2（亦见 p.8, p.19）。
  - MetaMath r=16，λ=0.3：TA −15.0，PTL −46.5；λ=0.7：TA −2.7，PTL −28.2。
  - Magicoder r=16，λ=0.7：TA −0.1，PTL −13.2；Magicoder r=64，λ=0.9：TA +2.2，PTL −1.4。
- Table 3（p.20，RoBERTa）：QQP r=8，λ=0.7：TA −0.0，PTL −33.2；λ=0.1：TA −3.3，PTL −52.0。MNLI r=1，λ=0.1：TA −18.7，PTL −13.3（低秩 + 强缩放代价大）。
- 作者总结：λ=0.5 时 RoBERTa 测试精度下降总小于 2%，遗忘下降为两位数百分比（p.19）。
- 学习率越大 intruder 越多、遗忘越多；大学习率下 LoRA 甚至比全参遗忘更多（p.7, Fig.7）。α=8 比 α=2r 产生更多 intruder、更低有效秩、更多遗忘（p.7, p.22, p.27）。
- 持续学习（RoBERTa 六任务顺序 MNLI→QQP→SST-2→SIQA→WinoGrande→FEVER）：所有秩的 LoRA 退化快于全参，低秩最严重（p.8–9, Fig.9/17）。
- 有效秩：α=2r 时 r=768 有效秩总在 100 以上；α=8 时 r=768 一直低于 50；全参有效秩一直在 400 以上（p.22）。（注：p.27 又称 α=2r 时 r=768 有效秩“above 768”，与 p.22 自相矛盾，可能是笔误。）

## 消融（隔离信号）
- **intruder vs 邻近预训练奇异向量**（关键对照，p.8, p.20–21, Fig.12）：缩小 intruder → 遗忘降、精度基本不变；缩小奇异值相近的预训练方向 → 遗忘反而上升、精度下降更多。这说明效果来自“方向是否与预训练对齐”，而不是“任意缩小一个大奇异值都无害”。
- **放大 intruder（λ>1）**：λ=1.5 时精度基本平、遗忘大增（p.20）→ 支持 intruder 的奇异值大小对任务非必需。
- 只训 B（冻结正交 A）显著减少高排名 intruder（Fig.10, p.16）→ BA 乘积参数化是成因之一。
- 秩：r 足够高（LLaMA2 math r=2048）intruder 消失，曲线接近全参（p.6）。随机种子影响可忽略（附录 N, p.27/29）。数据集越大 intruder 越多（r=8），r=1 饱和（附录 J, p.24）。
- 有效秩被作者明确判定**不足以解释**行为差异（p.6）——即“谱集中度”这个全局信号弱于 intruder 这种对齐型信号。
- 缺失的消融：没有比较“缩放 intruder” vs “统一缩放整个 ΔW”或“截断 LoRA 秩”在相同精度下的遗忘；没有对 ϵ、k 在缩放实验中的敏感性分析（缩放实验用的 ϵ 未明说）。

## 作者声明的局限
- intruder 是经验观察，成因多因素（学习率、α、BA 乘积）（p.6）。
- 主要研究原始 LoRA，变体只做初步实验，留待未来（p.3, p.28–29）。
- 计算受限：LLaMA2-7B 未自训，使用 Biderman et al. 公开 checkpoint（p.16）。
- λ=0 不能恢复到预训练模型（并非所有矩阵都有 intruder、r>1 时可能多个 intruder、SVD 正交约束会牵动所有向量）（p.20–21）。
- 代码任务中全参与 LoRA 的 intruder 分布相似，作者归因于大领域偏移（p.23）。

## 批判
- 【推断】“遗忘”在缩放实验中主要用预训练 loss（PTL）度量，而不是下游 OOD 任务分数；PTL 下降 33% 不等于 IFEval/知识类任务恢复 33%。LLaMA2 预训练数据并未公开，“预训练分布随机样本”具体是什么文本没有交代（p.16）。
- 【推断】报告的是相对“微调引起的遗忘”的百分比减少，若原始遗忘本身很小，绝对收益可能有限。
- 【推断】只缩放 top-1 intruder、全局单一 λ，是非常粗的编辑；最优 λ 在不同设置下差异很大（MetaMath r=16 λ=0.3 掉 15% 精度，而 r=256 只掉 0.1%），说明需要**有标签目标 dev**来定 λ，无数据选择并不完整。
- 【推断】Alg.1 只用左奇异向量 U，ϵ 阈值在高维下需小心（附录 D 指出 n 维中与正交基的最大余弦下界为 1/√n）。对 Qwen3-8B 隐维 4096，1/√4096≈0.016，阈值选择对计数影响大。
- 相关性数据点少（RoBERTa 单任务单秩的学习率×epoch 扫描），ρ=0.971 的普适性存疑。
- 持续学习实验中每任务重训分类头，测量的是表征保持，不是生成式指令遵循。

## 对我们项目的启示
- **给 agent 的信号**：每个 LoRA 模块的 ΔW（或 W0+ΔW）SVD 后，每个 top-k 奇异方向与 W0 奇异基的最大余弦（“对齐度”）及其奇异值。零数据、只需 SVD，便宜；是论文中**与遗忘相关、与目标精度不相关**的信号（ρ=0.971/0.59 vs 不显著，p.7），正好适合作为“retention 风险”先验。
- **对应算子**：我们库里的 SVD reweight / truncate_rank 可实现“intruder 定向缩放”：只对 intruder 方向乘 λ（0.5–0.9 区间在论文中多数情况精度损失小，p.20），而不是统一 scale。值得让 agent 有一个 `scale_intruders(eps, k, lam)` 原语或至少能计算对齐度。
- **不能单独用**：λ 的选择仍需目标 dev 检验（低秩时强缩放会伤目标，Table 4 r=16）；遗忘指标是 PTL 而非 IFEval，需要我们自己的 retention evaluator 验证可迁移性。
- **潜在误导**：intruder 计数依赖 ϵ、k；目标任务（代码）领域偏移大时全参也有类似分布（p.23），信号可能失效。对“正交化旧 adapter / project_out”类操作，本文提示的应是“与 W0 主方向的关系”，而不仅是与旧 adapter 的关系。
- 持续学习/多 adapter 叠加中 intruder 会累积（p.9），提示我们在 history adapter 插值/合并时监控累计 intruder 数可能是廉价的遗忘预警。
