# 2610.09835 笔记：A Deafening Silence: Catastrophic Forgetting Lives in the Output Embeddings of Tokens the Data Never Speaks

## 元信息
- 标题：A Deafening Silence: Catastrophic Forgetting Lives in the Output Embeddings of Tokens the Data Never Speaks
- 作者：Jonghyun Han, Younghoon Song, Jongyoul Park（Seoul National University of Science and Technology；Korea Institute of Land & Infrastructure Safety Technology）
- 版本：arXiv:2610.09835v1，2026-10-07，preprint（p.1）
- 阅读范围：全文 p.1–p.24（正文 p.1–10，参考文献 p.10–11，附录 A.1–A.14 及 Table A1–A21 p.12–24）。文本抽取基本正常；Fig.2a 的柱状图数值被抽成乱码（p.4），但相同数字在 Table A3（p.13）中可读。标题小型大写被拆成“D EAFENING S ILENCE”等，不影响内容。

## 研究问题
无原始数据（data-free）的持续预训练/微调中，遗忘**在哪些参数**发生、**为什么**？能否只针对该位置干预，从而在不损失目标学习的前提下减少遗忘？post-hoc 编辑是否可行？

## 做了什么 edit / merge / 诊断决策
1. **因果定位（训练期冻结）**：把参数分为输入嵌入 / 输出嵌入 / body 三个 site，再按 Adam 二阶矩 √v̂ 分三档（<1e-6, 1e-6–1e-5, 1e-5–1e-4），训练时一次冻结一组，度量“causal share”=冻结该组带来的遗忘减少（§4.1, p.4–5, Table A3 p.13）。
2. **训练期干预**：只对 output projection 把 Adam 的 ϵ 从 1e-8 提到 1e-4（§5.1, p.7）。等价工具：冻结 c(t)<1000 的行、逐步 gating（仅当 token 出现在 batch 才更新）（p.7, Table A8）。
3. **预训练前风险诊断**：vocabulary deficiency（只需分词计数）预测遗忘排序和该在哪个 site 干预（p.3, p.7, A.3）。
4. **post-hoc 编辑（负结果）**：对“缺席行”漂移做 SVD，按比例 α 减去 shared（top-1）方向；整行 reset 到 base；分量消融；以及 WiSE-FT 式整体插值回 base（§5.4, p.9；A.6, A.14, p.16–18, p.23–24）。

## 驱动决策的信息
- **信号 1：token 曝光计数 c(t)** = token t 作为目标在新语料中出现次数；K=1000 为“欠曝光”阈值（p.3）。**Vocabulary deficiency** = 旧域评测位置中目标 token 欠曝光的、按出现次数加权的比例（p.3）。数据：新语料 + 旧域评测语料，只需分词，**无需训练、无前向**。数值例：Pythia 分词下 Korean 63.2%、code 55.9%、math 33.9%（p.13）。
- **信号 2：Adam 二阶矩 √v̂**（逐坐标），用于分档冻结和解释 ϵ 的选择性：输出嵌入中位数 1.1e-8–7.8e-8，body 中位数 5.5e-6–4.2e-5（p.7, Table A21 p.23）。需要训练过程中的优化器状态，**post-hoc 的 LoRA 产物通常没有这个信息**。
- **信号 3：漂移几何**：D = W_after − W_base 限制在缺席行（c(t)=0），SVD 后 top-1 能量占比 σ1²/Σσi²（p.16）。需要 base 和微调后权重；一次 SVD（行数例如 85,143）。
- **信号 4：预测方向** −h̄：新语料一次前向得到末层平均隐状态；与经验 top-1 方向的 |cos| 在 Qwen/Korean 为 0.40（坐标缩放后 0.50），Pythia-1.4B/math 0.647，未达作者预注册阈值 0.7（p.17）。
- 遗忘度量：旧域验证语料上的 loss 增量（nats）；学习度量：新域验证 loss 降低（Eq.3–4, p.4）。对 Pythia/OLMo 直接采样 D_old，对闭源 base 用代理语料（p.4）。

## 决策方式
- 干预本身是**闭式规则**：output 参数组 ϵ=1e-4，无需逐模型调参（ϵ 扫描 Table A5 p.14 只在 3 个 Pythia 上做）。
- 是否/在哪干预：**基于 deficiency 的阈值启发式**——高 deficiency 用 output ϵ；低 deficiency（遗忘在 body）改用 replay 或学习率缩放（p.7）。
- 学习率：标准网格扫描，按目标学习选峰值（p.3）。
- post-hoc 编辑：**对 α 做网格扫描**（α∈[0.25,0.5] 为最佳，p.23）。

## 关键结果（含页码）
- 定位：冻结 √v̂<1e-6 的输出嵌入在 5 个稳定设置中消除 31.3–51.0% 遗忘，目标学习变化 +0.1% 到 +5.2%；同档输入嵌入 −1.5% 到 +1.4%（p.5）。同档 body −1.3% 到 +2.7%（p.5）。
- 主结果（Table 5, p.8）：output-only ϵ 在 7 个稳定设置中消除 39.4–67.9% 遗忘；如 Qwen2.5-0.5B 0.629→0.202 nats（67.9%，学习 +5.4%），OLMo-2-1B 1.137→0.689（39.4%），Pythia-12B 0.101→0.035（65.3%）。
- 与 replay 组合：Qwen/Korean 1% replay + ϵ 达 79.8%（独立性预测 78.0%）；OLMo 74.4% vs 预测 64.8%（Table 6, p.8）。
- 基线（Table A6, p.14，Qwen/Korean）：L2-to-base λ=100 减 64.3% 但学习 −15.4%；KL-to-base β=0.1 减 96.5% 但学习 −95.3%；LoRA r=16 减 12.0%、学习 −27.1%；底层冻结 −2.5%（更差）。
- LoRA + 放开输出头：遗忘从 0.1210 升到 2.8204 nats（23 倍），output ϵ 去除其中 91.1%（p.8, Table A17 p.21）。TinyLlama（非 tied）16.3 倍，ϵ 去除 92.4%（p.20）。
- **post-hoc 编辑（Table 7, p.8；p.9；p.23–24）**：
  - 按 α 减去缺席行 shared 方向：最佳恢复仅 +0.7%（OLMo）、+2.5%（Qwen）、+4.6%（Pythia-1.4B）；α=1 全删时目标学习 −133.6%、−18.7%、−7.7%。
  - 六个 checkpoint 上最佳恢复只从 +1.7% 到 +2.5%（p.9）。
  - 1% replay 下整行 reset：tied 最多 +3.5%，untied 0%；完全 reset 恢复为负且随训练单调恶化（−12.3% → −68.7%）（p.9, p.23）。
  - **但 WiSE-FT 式整体插值回 base 不是 <5%**：Qwen/Korean α=0.95/0.9/0.8/0.7/0.5 分别恢复 11.4%/22.1%/41.0%/57.0%/81.0% 遗忘，代价是 1.0%–29.9% 目标学习；Pythia-1.4B/math 恢复 14.0%–100.5%，学习 +0.5% 到 −24.3%（p.24）。作者把这两组排除在主比较外：它们早于 replay-free 实验，带 1% replay，且每格只有一个 checkpoint（p.24）。
- 分量消融（Table A14, p.19）：删 residual 使遗忘放大 1.6×/1.7×/2.4×，学习只降 0.9–1.8%；删 shared 方向遗忘几乎不变（0.98×–1.10×），学习降 7.7%–133.6%（p.17–18）。
- 能力基准（Table A12, p.18，与主设置条件不同）：Pythia-6.9B 五任务平均 untouched 65.88，默认 ϵ 62.67，ϵ=1e-5 为 65.36。

## 消融（隔离信号）
- **位置 vs 参数量**：同质量 body 冻结只减 0.4–12.3%（Table 2, p.5），说明是位置而非数量起作用。
- **选择准则 vs 质量**：冻结 96.6% 输出嵌入时，随机 mask 减 66.4%（学习 −4.4%），按计数 mask 减 68.2%（学习 −0.2%），ϵ 减 72.1%（学习 +0.3%）（Table A9, p.16）→ “质量买保持，准则决定代价”。
- **Qwen 随机行 vs 最低 √v̂ 坐标**：12.1%（学习 −4.5%）vs 42.7%（学习 +1.7%）（p.13）。
- **weight decay** 开关不影响（Table A7, p.15）。**input-only ϵ** 为阴性对照，−0.5%（Table A18, p.22）。
- **数据 vs 训练模式**：Alpaca（无新词表）share 落在 MLP；KoAlpaca 落在输出嵌入（Table 4, p.6）。冻结 MLP 在 KoAlpaca 上减 8.2–47.8% 遗忘但损失 16.3–26.3% 学习（p.6）。
- **body ϵ 在 Alpaca**：Qwen 减 35.6% 且学习 −0.3%（免费）；Pythia-1.4B 减 32.5% 但学习 −6.7%（不免费）（Table A16, p.20）。
- **post-hoc 编辑的选择性程度**：整行恢复最有害 > 删 shared 子空间居中 > 均匀插值是唯一非灾难性前沿（p.24）。

## 作者声明的局限
1. 预训练前诊断只预测**排序**，跨模型绝对量 Spearman 0.60，未达预注册 0.7（p.9, p.14）。
2. 分布内（body）防御是初步的，只在两格中的一格免费（p.9）。
3. 设置内部不均匀：Pythia-410M/Korean 6 个种子中 2 个几乎无恢复且损失学习（p.9）。
4. 规模对比只在 Pythia；ϵ 扫描只在三个 Pythia；能力检查早于主网格、在不同条件下（p.9）。
5. adapter 消融只有一个秩（r=16）和两个基座（p.9）。
6. 机制依赖逐坐标自适应优化器，Muon 不适用（p.9）。

## 批判
- **“post-hoc 编辑恢复 <5%”需要严格限定**：该结论只针对**选择性**编辑输出嵌入漂移行（shared 方向按 α 删除、整行 reset），并且在 replay-free 的全参训练里。附录 A.14（p.24）自己显示均匀插值回 base 可恢复 11.4%–81.0%，只是要付学习代价（1.0%–29.9%），作者的论点是这条前沿“低于 ϵ 的免费点”。摘要的说法容易被误读为“post-hoc 一律无效”。【推断】对我们项目真正相关的是：**选择性编辑可能破坏补偿结构，而整体缩放/插值是平滑可调的权衡**。
- 【推断】规模小（主网格≤1.4B，最大 12B 只有 Pythia）、token 预算小（40M），遗忘全部用 loss（nats）度量；与 instruct 模型的 IFEval 类保留不在一个尺度上。
- 【推断】主机制依赖“新语料缺少大量词表 token”（Korean 注入）。对 Qwen3-8B 做数学/代码 LoRA（输出头默认冻结、不训练 embedding），这一机制大概率不起作用：论文自己显示 LoRA 冻结头时遗忘 0.1210 vs 全参 0.6285（Table A17）。在我们的场景遗忘应主要在 body，而论文指出 body 坐标混合了漂移与新知识（p.9, §5.5）。
- 【推断】学习率按“目标学习峰值”逐格选择，导致跨行不可比（作者在 A.1 也承认，p.12），一些对比的分母被放大（Korean 格的 lr 用 0.6% 学习换约 4 倍遗忘）。
- 很多数字要依赖附录交叉阅读；作者对自己的阴性结果（预注册失败、410M 双峰）报告透明，可信度加分。

## 对我们项目的启示
- **直接机制大多不适用**：我们是 LoRA，输出头/embedding 冻结；本文“输出嵌入漂移”机制的前提不成立。但它提供了两条可迁移的教训：
  1. **选择性 post-hoc 编辑可能有害**：漂移与“补偿”共处一个张量，挑方向删除（例如 project_out top-1 漂移方向、行 reset）会破坏补偿（删 residual 遗忘放大 1.6×–2.4×，p.17–18）。→ agent 使用 `project_out` / `orthogonalize` 这类选择性算子时，evaluator 必须严格把关；“看起来是漂移的主方向”≠“有害方向”（删 shared 方向遗忘几乎不变而目标学习大跌）。
  2. **均匀插值回 base（≈ 全局 scale LoRA）是平滑前沿**：α 从 0.95 到 0.5 恢复 11.4%–81.0% 遗忘、代价 1.0%–29.9% 学习（p.24）。这对应我们的 global/per-layer `scale` 和与 base 插值算子，可作为 agent 的默认安全基线，并用 evaluator 的 λ 来选点。
- **可给 agent 的便宜信号**：目标语料 vs 保留域语料的 token 计数分布（vocabulary deficiency），零成本，只能做**排序**预测；对数学/代码（Pythia 分词下 33.9%/55.9%）提示代码遗忘风险更高（与 2405.09673 一致）。
- **不建议依赖**：Adam √v̂ 信号（post-hoc 不可得，除非我们保存优化器状态——【推断】若 pilot 自己训练 LoRA，可以选择保存 v̂，届时可作为“哪些坐标是单向漂移”的信号，但需重新验证其在 LoRA A/B 空间的意义）。
- 若未来允许 agent 改训练配置（不只是 post-hoc），本文给出的教训是“预防优于修复”。
