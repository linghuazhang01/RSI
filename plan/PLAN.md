# 计划：模型自己改自己（RSI × 模型编辑）

2026-11-18 · 两篇论文 · 闭环图见 [rsi_loop.svg](rsi_loop.svg)

- **A 自量化**：模型给自己做量化，量化后的自己接着量化自己。代码在 `edit_code/`。
- **B 自写 LoRA**：模型写代码给自己生成 LoRA，合并后的自己接着写。代码在 `lora_code/`。
- **正经 RSI，不冻结**：改造者就是被改对象，就是当前模型 M_t；产出的 M_{t+1} 接任下一代改造者。

---

## 1. 数据

规则：**循环只看训练集，benchmark 只做留出评测。** 每个领域只用一个训练集（2026-11-19 定）。

| 领域 | 训练集 | 抽样池 / 验收集 | 留出评测集 |
|---|---|---|---|
| 数学 | DAPO-Math-17K | 15,314 / 1,000 | MATH-500、GSM8K test、AIME 24+25 |
| 代码 | TACO-verified（参考解都跑过测试；先例 EvoTrainer、ReVeal） | 9,806 / 1,000 | HumanEval+、MBPP+、LiveCodeBench |
| 知识 | TriviaQA train | 70,725 / 3,000 | GPQA-Diamond、MMLU-Pro（2,000）、TriviaQA（2,000） |
| 指令遵循 | RLVR-IFeval（24 种 IFEval 类约束，可判分） | 13,954 / 1,000 | IFEval 271、IFBench 300（领域外） |
| 工具调用 | Seal-Tools train | 11,019 / 1,000 | Seal-Tools test、API-Bank test、BFCL |

- **验收集动态切分**：数据文件里每个训练集只是一个整体的抽样池；每次运行开始时，`data/scripts/draw.py` 按配置里的 `gate_n` 从池里切出固定验收集，写到运行目录 `draws/gate/`，之后每代都用这一份。切分只由 `gate.seed`（20261118）和各领域的 `gate_n` 决定，所以验收集大小相同的运行，验收集完全一样，和实验种子无关。改大小只要改配置，不用重切数据。
- **每代抽样**：从验收集以外的池子里抽（数学 / 知识 / 指令 / 工具 2,000，代码 1,000；`n`）。可以跨代复用：先抽没用过的，用完后按最久未用的顺序复用；训练过或展示给编辑者看过的题不再当信号。
  - A：全部作信号，另抽 256 段作 KL / 校准文本；
  - B：目标领域 80% 作 train 题（edit 第 0 代训练 raw LoRA；其余只给激活统计）、20% 作信号，其余领域各 400 题作保留探针；
  - 代内分两阶段评测：每个候选先跑 200 题，前 3 名再跑完整一批。
- 配置：`data/draw/paper_{a,b}.yaml`（`gate_n`、`n`、`gate.seed`、`seed`）。
- 训练集在切分前已对全部留出集去污染（精确匹配 + 13-gram 近似重复）。
- 数据依据和条数见 `plan/research/DATA_CONFIG.md`，实现见 `data/README.md`。

## 2. RSI 怎么走（两篇共用）

```
第 t 代：
  1. M_t 读诊断表，写程序 → 生成候选
  2. 候选在本代抽到的训练题上打分（先 200 题筛，前 3 名跑完整一批），分数和错例回给 M_t，M_t 改程序（A ≤24 次，B ≤32 次）
  3. 最好的候选交给固定验收集（≤3 次）
  4. 通过 → M_{t+1}，接任改造者；不通过 → A 保留 incumbent，B 保留当前模型（edit 第 0 代兜底用 raw LoRA）
  5. M_{t+1} 在留出集上评测（只记录，不回传）；再测改造者能力 E_{t+1}
```

**判断是不是真的在"自我改进"**：看改造者能力 E_t，用一个固定不变的任务来测，并用对照组拆开来源：
- **当前模型 M_t vs 冻结的 M_0** 当改造者：差值 = 权重被自己改过带来的变化；
- **带搜索记录 vs 不带**：差值 = 经验积累带来的变化。

**种子**：只跑单种子 42（抽题、改造者采样、评测解码都用 42；数据切分固定用 20261118）。置信区间用按题目的配对 bootstrap。

**反馈规则**：
- 不用模型自评；判分全部确定性（精确匹配、单元测试、规则检查）。
- 门槛相对第 0 代。
- 先用 M_0 重复跑 3 次测出噪声带，比噪声小的变化不算改进。
- 程序只能读训练数据，拿不到信号题和验收题的内容。

## 3. A：自量化（Qwen3.8 27B）

| 项 | 内容 |
|---|---|
| 每代做什么 | 冻结的改造者 M_0 写量化方案（每组模块的比特、group size、量化器），**从原始权重量化自己的一份拷贝**；比当前最好的量化（incumbent）好才替换（2026-11-19 修订） |
| 体积 | 所有代同一个；默认 = 统一 4 bit GPTQ（词嵌入和输出层 8 bit）的大小，它也是起点 Q_0（2026-11-20 由 3 bit 改为 4 bit，比特可以往上下两边换，操作空间更大） |
| L1 反馈 | 和 incumbent 在同样的题上逐题比（2026-11-20：保持率 = 候选 / incumbent，配对差，incumbent 对、候选错的例题；不再给 M_0 打分）；相对 BF16 的 KL（400 段文本）；大小；免费分析工具 `hessian_table` / `group_error`（`compare` 2026-11-23 已删除） |
| L2 验收 | 大小 ≤ 体积，且在验收集上逐题配对比 incumbent 好：平均提升 ≥ 0.005，至少一个领域显著变好、没有领域显著变差；否则保留 incumbent，连续 2 代没有提升就停 |
| 主要结果 | 固定体积下验收分和留出分随代数的曲线；追回的差距 =（最终 − Q_0）/（M_0 − Q_0） |
| 对照 | 不带经验（`archive.enabled=false`）；不冻结改造者（由当前 incumbent 来写，`loop.editor=current`） |
| 基线 | 统一量化、KL 背包求解、KL + 行为背包求解、EvoPress、GAMMA |

## 4. B：自写 LoRA（Qwen3.8-27B，和 A 用同一个模型）

| 项 | 内容 |
|---|---|
| 每代做什么 | M_t 写程序得到 LoRA，通过验收后**合并进自己的权重**，得到 M_{t+1} |
| 三种方式（`method.mode`，2026-11-21） | **scratch（默认）**：从零写 LoRA，不训练；**weights**：直接编辑权重（任意秩的结构化修改：通道 / 模块缩放、稠密加入低秩方向、往原模型权重拉回），每个候选写出改动的权重并起一个 vLLM 服务评测，不训练；**edit（保留）**：第 0 代训练一次 raw LoRA，之后每代编辑它。没有 SFT 基线和 free 模式，改造者在任何模式下都没有训练 / 梯度工具 |
| 程序能用的工具 | 对 LoRA 的缩放、丢弃、截断、intruder 缩放、剪枝、RegMean、正交化、合并；不用梯度的构造（奇异方向缩放、激活方向、秩 1 编辑）；任何模式都没有训练 / 梯度工具 |
| 任务序列 | T1 SQuAD 知识注入 → T2 数学 → T3 代码（→ T4 DAPO 难题） |
| L1 反馈 | 目标任务信号切片分数（和当前模型比；edit 第 0 代另和 raw LoRA 比）；保留领域上相对 M_t 的逐 token KL 和分数；写入前对、写入后错的样例；LoRA 范数和 intruder 分数 |
| L2 验收 | 只送信号题上赢了当前模型的候选；目标：edit 第 0 代 ≥ raw − ε，之后和 scratch 在验收集上和当前模型逐题配对，平均提升 ≥ min_gain 且置信区间下界 > 0（2026-11-20，和 A 一致）；每个保留领域 ≥ 第 0 代 − δ；已学任务不掉超过 δ。都不过时 edit 第 0 代合并 raw，其余保持原样 |
| E_t | 固定任务：为原始基座在 Seal-Tools 上写一个 LoRA（同一模式），看 Seal-Tools test 和 BFCL |
| 分支 | 原模型 / raw LoRA（仅 edit）/ 自己写的 LoRA / 非 LLM 搜索。核心指标 ΔE_write = 自己写 − 参照分支（edit：raw；scratch：原模型） |
| 对照 | 冻结改造者 M_0；不带搜索记录；edit / scratch 两种模式互为对照 |
| 基线 | 非 LLM 随机搜索（edit：随机编辑 raw；scratch：随机无梯度构造）、SLoRA、TIES、CMA-ES、规则组合（不再有 SFT 基线和它的前沿） |

## 5. 顺序和判断

| 阶段 | 做什么 | 继续的条件 |
|---|---|---|
| A-P0 / B-P0 | 测噪声带；BF16 模型能否写出合法方案；B 的 raw LoRA（edit）是否有提升、遗忘是否大于噪声 | 至少一边有约 1 分以上的空间 |
| A-P1 / B-P1 | 单代：LLM 方案 vs 基线 | 同预算下不输最强基线 |
| A-P2 / B-P2 | 3–4 代递归 + 全部对照 | E_t 曲线和对照能拆清来源 |
| A-P3 / B-P3 | 跨家族模型、更细的预算 / 更多代 | — |
